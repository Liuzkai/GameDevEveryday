## 主线 1：搬家与运费（本周最大结构性收获）

七天的主题排在一起，是一张**运费表**：

| 日期 | 搬的是什么 | 从 → 到 | 运费（原文数字） |
|---|---|---|---|
| 11-02 | 数据格式 | L3G-World 的 latent → 光栅化器；TopX 的骨架文件 → 动作网络；Fight WM 的视觉代理 → 战斗规则 | "接口税"：翻译步骤数决定成本；NeRF 2020 的教训是**接口一旦定死，十年不动** |
| 11-03 | 时间形状 | "抖多久" → "衰减多快的积分" $W=5\tau$ | **六个参数里没有"时长"**；实时唯一买不到的是 anticipation（需要未来） |
| 11-04 | 不变量 | 局部生成器必须**共享**的量（WFC 的 $K$-valid / IW 2026 的 phase） | 地板 $\varepsilon\ge\frac{1-\max_sp_s}{(2r+P+1)(P-N+1)^2}$；mending 只到 18% |
| 11-05 | 参照系 | 外部刻度 → 内部状态（时间戳→相位、帧号→共享拓扑、欧氏→热扩散） | **换参照系不是免费的：它把"测量"问题换成"定标"问题**（Dirichlet 边界 / 锚定帧 / 单调损失） |
| 11-06 | 尺子 | 分数 → 报告；指标 → 数据集 | **只给分数会让结果变差**（0.585 → 0.543）；**离散量不能靠损失压** |
| 11-07 | 决定权 | 资产 → 消费点（逐顶点 / 每采样 / 每关节每帧） | **决定 4%，交接 26%（6.5×）**；REACT 交接 17.6%；纹理那篇差 0 步 ⇒ **敢不报成本** |
| 11-08 | 账本 | 一堆约束 → 一个可加标量 | **可加性付三笔账**（重复计数 ≤3 / 只在局部 / 不可撤销） |

**这张表里最硬的一条**：**运费的大小 ≈ "输出格式与下游要的东西之间差几步转换"。**

- 差 **0 步**（纹理上采样：输出就是 texel）→ 不报成本也成立；
- 差 **1 步**（REACT：四元数 → 矩阵）→ **17.6%**；
- 差 **1 步**（Hoppe：动态拓扑 → 三角带）→ **26%**，是决策本身的 **6.5 倍**；
- 差 **1 步**（DC-SQEM：中轴面片 → 骨架树）→ **这一步至今没有方法，只能靠启发式剪枝**——所以"直接生成骨架"（RigNet / FlowRig）把主流抢走了。

> **所以"要不要做某个优化"的正确问法不是"它快多少"，是"它的输出下游吃不吃得下"。** 吃不下的部分，最后都会以"每帧重建"或"离线转格式"的形式回来收费。

## 主线 2：三种"决定不了"的分层（本周唯一走到判据的线）

七天里有四天在不同领域撞到同一个问题，而答案的形状完全一致：

| 领域 | 局部决定不了的是什么 | 为什么决定不了 | 谁必须提前定 |
|---|---|---|---|
| WFC / IW 2026（11-04） | 全局一致性 | 局部合法 ≠ 整体可满足 | **上游**：$K$-valid 生成器要携带 invariant / phase / 一方向约束 |
| Hoppe 1997（11-07） | "该多细" | 判据需要**屏幕**，而顶点不知道相机 | **消费点**：每帧逐顶点求值 |
| 中轴 → 骨架（11-08） | "该留哪几条分支" | 中轴给结构，不给语义 | **人的意图**（"能接住动作"） |
| 生成内容评测（11-06） | "对不对" | 评价标准不在内容里 | **外部原则表**（物理/协调/可用三层） |

> **四种答案，四种"上游"：几何上游（约束）、时间上游（相机）、语义上游（意图）、规范上游（原则）。** 本周第一次把"局部决定不了"这件事拆成这四类——**在此之前它只是一个直觉。**

## 本周的判断修正（写下来免得下次再错）

1. **🔴 "误差可跨物体相加"这句是错的，改成"可加 ≠ 可比"。** QEM 的世界空间平方距离**可加**（同一物体内、可塞进堆、可随时停），但**跨物体不可比**（一栋楼与一把刀差三个数量级）。要进预算表必须**投影到屏幕**。已在 [[Level of Detail]] 页改正并加了一张三层表。
2. **🔴 "小段 = 空批"彻底作废（上周已判一次，本周再证一次）。** 本周批次条数：11-02（4 条）→ 11-03（19）→ 11-04（2）→ 11-05（7）→ 11-06（11）→ 11-07（周日无新段）。**条数与命中率无关，只与"作者攒批的节奏"有关。**
3. **⚠️ 标题的可信度需要单独打折。** P-MGS 标题卖"感知优先"，消融说"解耦"值 2.5 倍；GRF 标题卖"Transformer 渲染"，实测输光栅化 5.9 dB。**规则：先读消融表，再读摘要。**
4. **⚠️ "经典线优先作者主页"这条已够格写进规则**（第 6 例：Garland 1997 从 `mgarland.org` 一次 200，784 KB / 8 页；同期 ACM DL 仍是 403）。
5. **流程缺口复发一次**：**11-07 的运行没有写自动化记忆**（Run #60 缺失，今天才补）。**"写 memory"必须放在 `git commit` 之前的强制检查项**——这条 11-03 已经记过一次，**说明"记下来"不够，得变成清单项。**
