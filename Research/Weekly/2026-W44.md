## 本周一句话

> **这一周只做了一件事：把"一个数"拆成"一条分布"。**

## 主线 1：把一笔账拆成两笔（本周最大结构性收获）

这条线从 10-29 起连续四天，最后收在 11-01。

| 日期 | 论文 | 一笔账 | 拆成哪两笔 | 能不能兑换 |
|---|---|---|---|---|
| 10-29 | [[2026-10-26-Liu — WorldPager Zero-Stall Tiered Memory for Long-Horizon World Models\|WorldPager]] | 内存 | **驻留**（装不下）+ **流量**（搬不完） | ❌ 两堵墙，堵的地方不同（21→341 chunk 是位置墙，与内存无关） |
| 10-29 | [[2026-10-27-Kaushik — Hexels Compact Hexagonal Primitives for Scene Rendering\|Hexels]] | GS 质量 | **表达**（dB）+ **覆盖**（blends/px） | ❌ 10.47→2.48 是**纯形状效应**，与颜色场几乎无关 |
| 10-29 | [[Zwicker — Surface Splatting (2001)\|Surface Splatting]] | 核 | **重建**（高斯）+ **带限**（$+I$） | ❌ 带限是核里的一个加数，不是后处理 |
| 10-29 | [[2026-10-26-Wu — BoxWorld Let World Engines Control and Video Generators Render\|BoxWorld]] | 世界模型 | **规则**（离散、可执行）+ **外观**（连续、生成） | ❌ oracle 也救不了（LingBot + oracle 仍 16.2）——缺的不是信息，是"条件分支"这个原语 |
| 10-30 | [[2026-10-30-Böttcher — Total Deformation-based MPM for Perfectly Elastic Solids\|Böttcher]] | 每步成本 | **传递次数**（2→6）+ 其余 | ✅ **这一对可兑换**（3× ≈ 6/2，2.76 倍全花在往返上） |

**唯一一组可兑换的**（Böttcher 的传递次数）恰好说明规则：**只有当两半是同一个量的不同计法时才能兑换**；一旦两半性质不同（字节 vs 带宽、形状 vs 颜色、离散 vs 连续），汇率就不存在。

**这条对 SABC 表的直接含义**：现在那张表把"预算"当成一个总量往下分。而本周五篇论文都在说——**总量常常不是你能动的那个数，能动的那个是它沿某条轴怎么分布**（时间步长 / 时间采样 / 接触空间 / 空间前沿 / 编辑面积）。

## 主线 2："状态该不该存" → 判据 → 收口

这是本周唯一一条**从提问走到判据、再走到统一命题**的线。

```text
10-30  提问：这个中间产物要不要留下来？
       判据：能不能从当下的输入重算？
         ✅ 能   → 存它是纯负债（Böttcher 的 F：宁可付 2.76× 也不积分）
         ❌ 不能 → 它才是记忆（MLT 的一条路径 / Liao 的依赖图 / Liu 的矛盾证据）
       下半句：存下来能做什么，取决于它可被局部修改几次

10-30  补丁：任何"复用/简化"方案，都有一个它到不了的地方，
       必须有一条补它的通道（遍历性 / Bi-WoS / 零能惩罚 / 生成端）

11-01  收口：判据不是"哪个更省"，是"下游要问几个问题"
         → 存答案（Ward 1988 / lightmap / DDGI 探针）：一个答案，便宜，不能改
         → 存证据（Jensen 1996 光子 / WoMM 事件记录 / HairDeck 卡片集合）：很多答案，贵，能改
         → 存算子（PRT 2002 / RADIANT 2026）：换灯便宜，换几何贵
```

**三篇 2026 年的 WoS 工作，恰好把"存"的三档走完了**（这条也是 11-01 才看清的）：

| 论文 | 存什么 | 换什么变了要重算 |
|---|---|---|
| [[2026-09-15-Grid-Free Monte Carlo for Time-Dependent Diffusion\|时间依赖 WoS]] | 不存 | 什么都得重算 |
| [[2026-10-30-Liao — From Walks to Skeletons A Reusable Transport Architecture\|Walks to Skeletons]] | **轨迹图**（这次计算的产物） | 边界值 / 几何编辑 |
| [[2026-10-30-Liao — Walk on Multiscale Media Compiling Editable and Composable Transport Medium Prefabs\|WoMM]] | **介质预制件**（下次计算的前提） | 材料 / 方向 / 热容 |

**"被存的东西正在从'结果'往'前提'方向走"**——这是本周最值得记住的一句结构判断。越靠前提，可复用范围越大，构建越前置，**失效也越来越不取决于样本量、而取决于表示层**（WoMM 的事件库 64→256 误差非单调，就是证据）。

## 主线 3：预算语言从"一个数"扩到"九种计价对象"

[[Budget Units]] 这一周被改了三次，是本季改动最频繁的一页：

```text
10-22  （W43 末）四种：容量 / 成本 / 精度 / 时间
10-28  七种：+ 时间采样（前六种能摊销，第七种不能）
10-30  八种：+ 传递次数（"成本差 = 趟数比"是最干净的预算论证形式）
11-01  九种：+ 编辑面积（WoMM Table 4：0.8% → 36.2×，100% → 1.8×）
```

**第九种和前八种有一个性质上的不同**：前八种都是"这次要花多少"，**编辑面积是"改一次要花多少"**——它描述的不是一次计算的成本，是**一次修改的成本**。**这是"预算"第一次从"渲染预算"变成"迭代预算"**，而后者才是美术/TA 每天真正在付的账。

**并且它有一个 30 年前的先例**（11-01 经典）：Jensen 1996 写"必要的光子数与场景物体数无关，与**通量的复杂度**有关"，而实际取值"**由可用内存倒推**"。**预算量由变化复杂度决定、由资源上限倒推**——这条 1996 年就写对了。

## 主线 4："块"成为 2026 年系统论文的共同单位

三篇互不相关的系统论文，用的是同一个词：

| 论文 | 块是什么 | 块之间怎么耦合 |
|---|---|---|
| [[2026-10-20-Ma — WorldStream Streaming Interactive 3D Worlds with Hierarchical Planning and Persistent State\|WorldStream]]（10-28） | 编译单元（瓦片） | **双前沿**：语义前沿在前，实现前沿只编译马上要用的 |
| [[2026-10-26-Liu — WorldPager Zero-Stall Tiered Memory for Long-Horizon World Models\|WorldPager]]（10-29） | 内存单元（chunk） | **持久记录**（KV 存盘），漏块靠 stale-set 将就 |
| [[2026-10-30-Liao — Walk on Multiscale Media Compiling Editable and Composable Transport Medium Prefabs\|WoMM]]（11-01） | 输运单元（prefab） | **端口**：块内消元成 $S_\kappa$，块间装配成骨架 |

**三者的共同点：块内自成一体，块间的接口被显式定义。** 而差异正好是"接口有多厚"：

```text
WorldStream   接口 = 记录（几何是可再生资源，记录才是资产）   最厚
WorldPager    接口 = KV 缓存（位姿是输入 ⇒ 访问集可先验）      中
WoMM          接口 = 端口上的转移概率（一个 p×p 小矩阵）        最薄
```

**这对引擎的含义**：世界分区（World Partition）现在切的是"区域"，切完彼此靠流送半径硬凑；**如果给每个分区定义"端口"，块间耦合就能写成一次矩阵装配**——这是"分块 GI / 分块物理"可能的正确定义，也是本周提出但**尚未验证**的一个猜想。

## 个人认知进展

- **本周新增一个可复用的提问**：**"这个量是被积分出来的，还是被计算出来的？"**（Böttcher 判据的通俗版）——前者会漂、误差随运行时长累加；后者不会。这条能直接拿去审任何"上一帧缓存"的设计；
