# GS 图解 1 — 协方差与椭球：高斯的形状说明书

> 一句话：每个高斯 = 一团**椭球形的彩色烟雾**；协方差矩阵 = 这团烟雾的**形状说明书**。

## 一个高斯 = 一团椭球形的雾

![[GS_高斯椭球解剖图.html]]

- "高斯"描述的是**浓度分布**：中心最浓，向外按钟形曲线衰减，没有硬边界
- 为什么是椭球不是球：墙面要**压扁的薄片**去贴、发丝边缘要**拉长的细条**、斜面要**歪的朝向**——球只有"大小"一个自由度，椭球有"三根轴各多长 + 整体朝哪歪"

## 协方差矩阵 = 先拉、再转

![[GS_协方差矩阵分解_先拉再转.html]]

- 任何合法协方差矩阵都能分解：**Σ = R·S·S·Rᵀ** —— 拿一个标准圆球，先沿三根轴各拉一个倍数（S），再整体转到目标朝向（R）
- GS 只存 **7 个数**（3 缩放 + 4 旋转四元数），用到时拼回矩阵
- 工程理由：直接优化 9 个矩阵元素，可能改出"轴长为负"的怪物——那就不是椭球了（数学上叫失去**正定性**）。存缩放+旋转等于给优化器上保险：怎么调都是合法椭球

## 渲染：协方差被"拍扁"上屏幕

![[GS_渲染三步_投影排序混合.html]]

- **splatting（甩溅）**：每个 3D 椭球沿相机方向拍扁成屏幕上的一个 2D 椭圆
- 拍扁也是矩阵乘法：**Σ′ = J·W·Σ·Wᵀ·Jᵀ**（J = 投影变换，W = 相机旋转）——视角一变，每个椭圆的形状跟着变
- 然后按深度排序、从远到近 alpha 混合成像素

## 数学 ↔ GS 对照表

| 线性代数概念 | 在 GS 里干什么 | 人话 |
|---|---|---|
| 高斯分布 | 每个基元的浓度场 | 一团中心浓、边缘淡的雾 |
| 协方差矩阵 Σ | 存椭球的形状 | 形状说明书 |
| 特征分解 Σ=R·S·S·Rᵀ | 参数化成 3 缩放 + 4 旋转 | 先拉、再转 |
| 正定性 | 保证是合法椭球 | 轴长不能为负 |
| Σ′=J·W·Σ·Wᵀ·Jᵀ | 投影到屏幕 | 把 3D 形状拍扁成 2D 椭圆 |
| 深度排序 + alpha 混合 | 合成最终像素 | 几十万个半透明椭圆从远到近糊层 |

## 训练侧一句话

渲染结果和真实照片对比，误差反向传播，微调每个高斯的**位置 / 缩放 / 旋转 / 不透明度 / 颜色**；形状不对付的还会被分裂、克隆、剪枝——详见 [[GS 图解 2 — 排序瓶颈、管线冲突与密度控制#Gap 3 · 自适应密度控制 = 训练时的发射器管理|图解 2 的 Gap 3]]。

## 桥

屏幕上每个 2D 椭圆 ≈ 一个半透明"粒子"，排序混合与 VFX 半透明粒子的 overdraw / 排序问题**同构**——工程难点全部在 [[GS 图解 2 — 排序瓶颈、管线冲突与密度控制]]。
