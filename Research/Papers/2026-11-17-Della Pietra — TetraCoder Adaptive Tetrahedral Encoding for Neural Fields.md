# TetraCoder: Adaptive Tetrahedral Encoding for Neural Fields

## TL;DR

**它让"隐式 → 显式"这一步不再有采样误差，办法不是把采样做密，是让场本身变成"可以直接解方程"的形状。**

$$\text{四面体内重心插值}\;\Rightarrow\;\text{特征场分片仿射}\;\Rightarrow\;\text{ReLU 解码仍是分片仿射}\;\Rightarrow\;\{x:g(x)=0\}=\{x:a_C^\top x+b_C=0\}$$

**最后一步是解析求解，不是采样。** 所以"零等值面"与"提取出的网格"之间**没有间隙**——这是它区别于 [[Lorensen 1987 — Marching Cubes A High Resolution 3D Surface Construction Algorithm|Marching Cubes]] 与 [[2026-11-17-Ohrhallinger — FOMOS Feature-Oriented Meshing of SDFs|FOMOS]] 的根本处：那两条路都在"逼近"曲面，这条在"解"曲面。

## Problem

神经场有两种用法，需求正好相反：

| 用途 | 想要什么 | 隐式（SDF / 密度） | 显式（网格） |
|---|---|---|---|
| 空间查询（碰撞、求最近点、体积渲染） | 任意点求值 | **快** | 慢 |
| 表面采样（光栅化、仿真、DCC） | 拿到三角形 | 要提取，慢且有误差 | **快** |

所以"两种表示之间的高效转换"本身就是一个有价值的目标。而转换的**精度上限由编码方式决定**——这一点在文献里长期被当成实现细节。

论文把现有编码的取舍列成一张表（§1）：

| 编码 | 优点 | 致命处 |
|---|---|---|
| **多分辨率哈希网格**（Instant-NGP / NeuS2） | 细节效率极高 | ① 哈希碰撞让远处区域互相耦合；② **三线性插值不是分片仿射** ⇒ 解析提取根本不成立 |
| **四面体多分辨率哈希**（TetraSDF） | 重心插值保住了分片仿射 | **多层网格之间的四面体要互相求交** ⇒ 提取代价随层数爆炸 |
| **固定四面体化** | 简单 | 训练中不能改空间划分 |
| **基于网格的编码**（NeuMesh 系） | 可编辑 | 依赖已重建的表面 |

**空位很明确：既要分片仿射（能解析提取），又要单层（不用跨层求交），还要能自适应（该密的地方密）。**

## Historical Context

这条线的历史其实是"**插值规则决定可提取性**"的历史，只是很少被这样叙述：

```
1987  Marching Cubes     规则网格 + 三线性插值 ⇒ 只能采样提取，分辨率是唯一旋钮
1995  MC33               修歧义，仍是采样
2019  DeepSDF            神经 SDF 出现，但表面仍靠 MC 采
2020  Instant-NGP        哈希网格：容量问题解决了，插值规则没变
2022  NeuS / NeuS2       SDF + 体积渲染，提取仍走 MC
2023  TetraSDF           四面体哈希 ⇒ 分片仿射成立，但多层要互交
2024  ReLU 场解析提取    识别网络的分片仿射区域（[2,20,34] 一系）
──────────── 2026 ────────────
      TetraCoder：单层 + 自适应 + 无哈希 ⇒ 解析提取不再有跨层代价
```

**关键洞察来自一个很小的观察**：三线性插值在 cell 内部是**三线性**（含 $xyz$ 交叉项），不是仿射；而四面体内的重心插值是**严格仿射**的。**这一个插值规则的选择，决定了后面能不能"解"而不是"采"。**

## Previous Work

四族，按论文的划分：

1. **空间编码**：Fourier 特征（治谱偏置）→ 稀疏体素/八叉树/块分解（把容量放到需要处）→ 多分辨率哈希（省存储）→ permutohedral / 四面体哈希（保分片仿射）→ 点支撑场 / 点云四面体化（跟着几何走）。
2. **神经重建与新视角合成**：NeRF / 占据 / SDF（NeuS 系）；显式基元（体素 / 3DGS / surfel / 平面高斯）。
3. **表面表示与解析提取**：MC / DC / Marching Tetrahedra；可微等值面（把提取嵌进优化）；ReLU MLP 的解析提取（识别仿射区域）。
4. **可编辑神经场**：网格代理变形 → 四面体代理 → cage → 把几何与外观码存在网格顶点上（NeuMesh）。**共同点：编辑依赖一个额外的控制结构。**

**TetraCoder 对第 4 族的回答是最激进的一条**：**编码器自己就是编辑域**，不需要额外的 cage 或代理网格。

## Core Idea

### 一个式子撑起全部

四面体 $\tau$ 的四个顶点 $v$，把其中一个的位置换成查询点 $x$，得到子四面体 $\tau_{v\leftarrow x}$。重心权重就是**体积比**：

$$\lambda_v=\frac{V(\tau_{v\leftarrow x})}{V(\tau)},\qquad e(x)=\sum_{v\in\mathrm{vert}(\tau)}\lambda_v f_v$$

两个性质由此而来，且都能一行证完：

- **连续性**：跨面时对顶点的权重为 0，剩下三个权重恰好退化成该面上的重心坐标 ⇒ 两侧插值出同一个值。
- **分片仿射**：固定 $\tau$ 时，分子里的体积都有固定底面（$v$ 的对面），高度随 $x$ 仿射变化，分母是常数 ⇒ 每个 $\lambda_v$ 是 $x$ 的仿射函数 ⇒ $e(x)=A_\tau x+b_\tau$。

**再叠一个 ReLU MLP 解码器**：仿射 ∘ ReLU ∘ 仿射 仍是分片仿射。于是把每个四面体按 ReLU 的激活模式切成凸胞 $C$，在每个 $C$ 里

$$g(x)=a_C^\top x+b_C\;\Rightarrow\;\{x\in C:g(x)=0\}=C\cap\{x:a_C^\top x+b_C=0\}$$

**一个平面与一个凸胞求交，就是多边形；三角化它，就是网格。** 没有采样、没有步进、没有插值误差。

### 无哈希 ⇒ 局部性是可证的

$$\Delta e(x)=\lambda_v\,\Delta f_v$$

改一个顶点的特征，只影响包含它的那些四面体。**哈希碰撞不存在，所以"改这里、远处跟着变"这件事在结构上不可能发生。** 这一条直接支撑了编辑实验（Table 4：改 20% 区域，未改区域的 2D MSE 0.048 vs 哈希的 0.536，**约 11×**）。

### 自适应：三个操作，一个分数

$$\mathrm{score}(\tau)=\frac{\mathrm{diam}(\tau)}{|S_\tau|}\sum_{x\in S_\tau}\Big\|\frac{\partial\mathcal L_{\text{fit}}}{\partial e(x)}\Big\|_1$$

- **加密**：分数高（体积大且梯度强）就插入顶点，新特征初始化为 $f_{new}=e_{old}(p_{new})$（**插入不改变当前场**，这是很讲究的一手）。
- **剪枝**：梯度长期很小、且特征接近邻居均值的顶点被删。
- **移动**：顶点位置用 Adam 直接优化（特征跟着顶点走，**不增加参数**）。

插入与剪枝会触发**全局 Delaunay 重建**；移动只定期刷新连接性。

## Key Contribution

1. **把"插值规则"提升为一个一等设计变量**：三线性 vs 重心的差别，不是精度差别，是"能不能解析提取"的**可行性差别**。
2. **单层自适应替代多层哈希**：既避开了跨层四面体求交，又避开了哈希碰撞——**两个问题一次解决，代价是"容量必须靠自适应给"**。
3. **编码器即编辑域**：不需要 cage / 代理网格，顶点移动就是形变，特征扰动就是改色，且局部性可证。
4. **一个干净的等值面提取对照**（图 3）：在同一冻结场上，解析提取的 SSDF 比 DC 在 $4096^3$ 跑 2.5 小时还低**约两个数量级**。

## Why It Works

因为它把"表示"和"提取"这两件事**共享了同一个数学结构**。

传统管线里，场是"任意函数"，提取是"采样 + 拟合"，两者之间必然有一层近似。TetraCoder 让场**只属于一个受限函数类**（分片仿射），而**这个类的零等值面恰好有闭式解**。于是提取不是"近似",而是"换个写法描述同一个对象"。

> **判据：当你想让两个表示之间"无损转换"，最省力的做法不是把转换做得更准，是让两个表示共享同一组自由度。** 分片仿射场与三角网格，本质上是同一个对象（一个复形 + 每格一个仿射函数）的两种记法。

## Limitations

### 论文自陈的三条（§5 结论末段）

1. **不支持 4D 动态场景**。
2. **解析提取只支持单一 LOD**（多层 LOD 的解析提取列为未来工作）。
3. **单向**：还没证明能从提取出的网格反推 SDF（"bidirectionality of the implicit-explicit link"）。

### 读原文才看清的五条

4. 🔴 **"解析"不等于"便宜"。** 图 3 的同一张冻结 Lego 场上，TetraCoder 的解析提取用了 **49.263 s**（TetraSDF L 是 6.179 s，但它的 PSNR 只有 23.5 dB、CD 是 12.1×10⁻³）。**提取代价跟"ReLU 激活胞的数量"走，不跟分辨率走**——场越复杂（激活模式切得越碎），要解的平面越多。T2 里 0.446 s 的漂亮数字来自"8 维特征 + 3×12 的小解码器"，**不能外推到 T3 的配置**。
5. 🔴 **"无采样误差"是相对于"它自己学到的那个场"**。场本身是 L1 拟合 + Eikonal 正则的产物，与真值曲面的偏差依然存在——**误差没有消失，只是从"提取"这一步搬到了"拟合"这一步**。这个区分很重要：论文的"exact correspondence"说的是"网格 ↔ 场"，不是"网格 ↔ 真值"。
6. **消融不是单调的。** Table 5（D=加密 / P=剪枝 / M=移动）：

   | D | P | M | CD（×10⁻³） | PSNR |
   |---|---|---|---|---|
   | ✗ | ✗ | ✓ | 7.185 | 31.57 |
   | ✗ | ✓ | ✗ | 7.929 | 31.20 |
   | ✗ | ✓ | ✓ | **9.036** | 31.56 |
   | ✓ | ✗ | ✓ | 6.534 | 33.17 |
   | ✓ | ✓ | ✗ | 7.094 | 33.23 |
   | ✓ | ✓ | ✓ | **3.926** | **33.26** |

   **没有加密时，"剪枝 + 移动"比"只剪枝"更差（9.036 vs 7.929）**——自适应的三个操作是耦合的，不是各自加分。这提醒所有"加一个自适应模块"的设计：**先确认你有没有给容量，再谈要不要搬容量。**
7. **规模小**：Stanford 五个模型、NeRF Synthetic、DTU。没有大场景、无界场景、室外场景；没有与 MC 在**同等三角形预算**下的画质对照。
8. **T1 的方差极大**：Albert +9.5 dB，Summer +0.24 dB、Girl +0.18 dB。**"显著优于哈希"只在个别图上成立**，"参数更少"倒是四张图都成立（这才是稳的那一条）。
9. **Delaunay 全局重建的成本没单独报**：插入/剪枝都触发，训练循环里到底占多少不清楚。

## Game Development Relevance

**说实话：这篇现在离"能用"还有距离，但它的方向正好压在游戏资产管线的痛点上。**

| 场景 | 现状 | 这篇提供什么 |
|---|---|---|
| 神经场（NeRF/3DGS 重建的资产）→ 网格 | 靠 MC 采，稠密且质量差 | 解析提取，网格与场严格对应 |
| **SDF 资产的局部编辑** | 要重新训练或重新烘 | 改顶点特征即改局部，泄漏可证（11× 优于哈希） |
| 四面体光线追踪 | 研究阶段 | 邻接行走定位（图 2），不需要 BVH |
| **LOD** | — | 论文明确说**还没有**多 LOD 的解析提取（这正是"神经资产的 Nanite"缺的那一块） |

**它对本库的意义在概念侧**：[[Microgeometry]] 那一页的结论是"编译的边界是局部性"。TetraCoder 是一次**把编译边界往外推**的尝试——它证明了"只要表示选对，编译（训练）到提取这一步可以是无损的"。**但轮廓、透射、过滤仍然非局部，所以这条边界没有消失，只是挪了一格。**

## Unreal Engine Relevance

- 无直接对应。最接近的是"把神经重建资产导入引擎"这条链（目前靠第三方工具导出 OBJ/FBX）。
- 可借鉴的**工程形态**：四面体网格 + 每顶点特征，在引擎里就是一张 StructuredBuffer + 邻接表；邻接行走（adjacency walk）是 GPU 上做体积求交的标准手法，**与光栅化管线并行存在，不冲突**。
- **短期不现实**：需要重训一个场景级表示，且没有 LOD、没有动态。

## Learning Value

1. **表示的自由度结构，决定了它与其他表示之间能不能"无损转换"。** 这是本库 [[Decoupling Geometry and Appearance]] 那条线的延伸：**解耦的极限不是"分得开"，是"两边本来就是同一个东西"。**
2. **"自适应"的三个操作是耦合的**（消融第 6 条）。加模块之前先问：容量给了吗？
3. **"精确"要问清是对谁精确**：对场，还是对真值？论文的 exact 是对场。
4. **一个可以抄的初始化技巧**：插入顶点时用 $f_{new}=e_{old}(p_{new})$，**保证插入不改变当前场**——于是加密是"纯增益"，不会破坏已收敛的解。这与 FOMOS 的"ε-采样细化只在违例处插点"是同一种克制。

**读图**：三个面板都是同一只兔子，右上角插图是**二维类比**。左（Hash Encoder）：规则方格，查询点 $x$ 落在四个格点之间，三线性插值——**跨 cell 的插值不保仿射**。中（TetraSDF）：把每个方格切成固定的三角形（三维就是四面体），重心插值 ⇒ 分片仿射，但**多层之间要互交**。右（TetraCoder）：网格本身是**不规则的**（自适应三角化），顶点可以移动，且只有一层。**这张图把"插值规则"和"空间划分"两件事画成了两个独立的自由度——这正是全文的骨架。**
（出处：Della Pietra et al. 2026, Fig. 1）

### 图 3 — 解析提取时间 vs 场误差

![[Research/Files/Pictures/Della Pietra 2026 — 图3 解析提取时间与场误差.png]]

**读图**：横轴是提取时间（对数，$10^0$–$10^4$ s），纵轴是 SSDF（对数，$10^{-8}$–$10^{-3}$，越小说明网格越贴合场）。蓝点是网格类方法（MC / MT / DC），随分辨率指数上升；红点是 TetraSDF L；绿点是 TetraCoder。**两个绿点的位置**：一个在 6.179 s（PSNR 23.5、CD 12.1×10⁻³，容量不足），一个在 49.263 s（PSNR 35.1、CD 3.20×10⁻³）。**这张图最该记的是"解析法也有一条自己的时间-质量前沿"，而不是"解析法一定快"。**
