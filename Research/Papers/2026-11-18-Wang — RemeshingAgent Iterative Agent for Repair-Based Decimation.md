# RemeshingAgent: An Iterative Agent for Repair-Based Decimation of Generated Building Meshes

## TL;DR

**三角形预算可以分解，而其中有一项跟"你要多准"完全无关。**

$$F_{\min}\asymp\max\Big(\underbrace{c_1A_{\text{curv}}/\varepsilon_{\text{abs}}}_{\varepsilon^{-1}},\ \underbrace{c_2A_{\text{crease}}/\sqrt{\varepsilon_{\text{abs}}}}_{\varepsilon^{-1/2}},\ \underbrace{4n_{\text{sig}}}_{\varepsilon^{0}},\ \underbrace{c_4g}_{\ } \Big)$$

前两项是经典的逼近论（曲面越松、容差越大，三角形越少）。**第三项 $4n_{\text{sig}}$ 的指数是 0**——**它有 8,223 个连通分量，就至少需要 32,892 个三角形，跟你接受多大误差一点关系都没有**。

于是"熔毁"（melting：删部件、焊薄墙、破容差）不是算法缺陷，是**几何性质**。**在低于 $F_{\text{comp}}$ 的预算下，不存在任何满足修复契约的网格**——任何算法都一样。**而理论强制的第一步动作是"先清洗"，不是"换个更好的简化器"。**

**一句可带走的**：**任何"简化到 X%"的任务，先分解预算，看哪一项对 $\varepsilon$ 的指数是 0。有零阶项的时候，调容差是白调。**

## Problem

AI 生成的建筑网格处在一个荒唐状态：**表面看起来完整、几何看着也对，但内部是碎的**——10³–10⁴ 个连通分量，大量非流形薄墙（图 2 左：8,223 个分量、2,227 条非流形边）。要把 90 万–150 万面压到 0.5%–1%，所有"保拓扑"的简化器都会熔毁。

已有的解释都不够：

| 已有理论 | 覆盖 | 不覆盖 |
|---|---|---|
| 经典逼近论（Fejes Tóth 1948 / Glasauer–Schneider 1996 / Ludwig 1994） | 光滑凸体、平面曲线：$\Theta(\sqrt{\int|K|\,dA/\varepsilon})$ | **碎片化的分段光滑曲面**——恰恰是生成资产的样子 |
| 保拓扑简化器（QEM 1997 / 渐进网格 1996 / 顶点聚类） | 保持输入连通性 | 输入本身就连通性破碎时，"保持"等于保持破碎 |
| 重建式（voxel hull / alpha wrap / 生成式 remesher） | 从采样重建 | 预算律不同（契约 B），且先验会在地板处封顶 |
| 城市级 LOD 框架（Biljecki 2015 等） | 规定每层放什么 | **不规定"最低能做多低"** |

**缺口是一句定量的话：这个网格最少需要多少个面。** 没有它，"熔毁"只能靠试。

**这条线的空白很具体**：逼近论只管"光滑的东西要多少面"，而**生成资产是"一堆光滑碎片"**。碎片的行为不由曲率决定，由**件数**决定。

## Core Idea

三步，每步都从"熔毁"这个现象往回推：

**① 熔毁是几何性质，不是算法性质。**
论文用 $12 \times 8$ 的 QEM / 聚类扫描（八档预算，10% → 0.1%）证明存在**两段式结构**（图 6）：干净网格上误差是幂律（指数 0.13–0.40，$\text{corr}(\log A,\log\text{budget})=0.95$）；碎片化网格上误差出现**地板**（指数 ≈ 0），只在分量项 $4n_{\text{sig}}$ 开始主导时才继续下降。**两个算法族行为完全一样** ⇒ 这不是算法问题。

**② 所以"清洗"是理论强制的，不是经验技巧。**
推论 3.3：一个分量若是 $\varepsilon$-可删的（每点都落在保留曲面的 $\varepsilon\,\mathrm{diag}$ 内），删掉它不破坏 $\varepsilon$-逼近。**"尘"按构造就是可删的**（它是原壳的碎片）。于是清洗把 $n_{\text{sig}}$ 从 $n$ 降到 $n_{\text{sig}}\ll n$，$F_{\text{comp}}$ 跟着降。**顺序固定：删尘 → 焊接 → 再简化。**

**③ 剩下的参数由"验证闸门"演化出来。**
理论给的是方向，不是参数（焊接阈值、保留比例、每步删多少）。于是把整份 remeshing 策略当成可训练对象：一个 **Clean–Execute–Verify–Reflect** 循环，只有**在留出集上严格变好**的编辑才被接受。

## Technical Approach

### 预算律（定理 3.1）

$$F_{\min}\asymp\max\big(c_1A_{\text{curv}}/\varepsilon_{\text{abs}},\ c_2A_{\text{crease}}/\sqrt{\varepsilon_{\text{abs}}},\ 4n_{\text{sig}},\ c_4g\big)$$

其中 $A_{\text{curv}}=\int_{S_{\text{smooth}}}\sqrt{|K|}\,dA$，$A_{\text{crease}}=\sum_j\int_{C_j}\sqrt{\kappa}\,ds$，$g$ 是总亏格。

**三个指数（$\varepsilon^{-1}$、$\varepsilon^{-1/2}$、$\varepsilon^{0}$）让这个分解可辨识**——这是论文最漂亮的一处设计：不是"我猜预算由这几项组成"，而是"这三项对 $\varepsilon$ 的响应不同，所以能从数据里把它们分开"。

对建筑（以平面为主、低亏格）：
$$F_{\min}\asymp\max\big(c_2A_{\text{crease}}/\sqrt{\varepsilon_{\text{abs}}},\ 4n_{\text{sig}}\big)$$

**于是出现一个悖论式的推论**：经典分析会预测"建筑几乎可以免费简化"（平面多、曲率小），**而漏掉的分量项才是所有实用简化器熔毁的原因**。

### 分量悬崖（定理 3.2）

若预算 $F<F_{\text{comp}}:=\sum_{k=1}^{n_{\text{sig}}}\max(4,\ c_1A_{\text{curv}}(S_k)/\varepsilon_{\text{abs}})$，则**不存在**任何 ≤ $F$ 面的网格同时满足 $\varepsilon$-逼近与同胚。

证明是纯组合的：分量之间分离超过 $2\varepsilon\,\mathrm{diag}$ ⇒ 它们的 $\varepsilon$-邻域不相交 ⇒ **没有一个三角形能同时服务两个分量** ⇒ 每个闭合壳自己付自己的地板（≥ 4 个面）。**与算法无关，与统计无关。**

![[Research/Files/Pictures/Wang 2026 — 图3 分量悬崖的计数论证.png]]
**读图**：把"最少面数"画成一道加法。输入分解成若干"显著分量"（S1–S4），每个至少 4 个面；四条价格条加起来就是阈值 $F_{\text{comp}}$。**预算低于它时，唯一的可能是"整个放弃某个分量"**——图里被叉掉的是烟囱。**这就是熔毁的解剖图：它不是"变糙"，是"少了一件东西"。**（图 3，Wang 2026）

### 契约的一个关键定义动作

$S^*$ 不是观测到的真值，是**声明的"焊接闭合"**：把 $S$ 在缝尺度 $\delta_0$（默认 0.1% 对角线）上焊起来的那个面。于是：

> 焊接与去尘**按定义就是"向 $S^*$ 修复"**，不是"改变拓扑"。

**这一步既是论文成立的关键，也是它最软的地方**——见 Limitations 第 1 条。

### 智能体

- **技能文档 $s=(P,E,R)$** 是唯一可训练状态；几何引擎与 LLM 都是冻结的。
- 每轮：规划器采 $B$ 个候选 → 子模选择取多样子集 → 在隔离的只读副本上跑 → 打分 $G=\sum w_i g_i$（面数 0.30 / 流形 0.15 / 形状保持 0.20 / 平面性 0.05 / 锐边 0.20 / 紧凑度 0.10）→ **严格接受**（$r_{\text{sel}}(\tilde s_k)>r_{\text{sel}}(s_k)$，否则精英保留）。
- **被拒编辑进缓冲区**当负反馈；epoch 边界由 meta-reflector 写长期指引。
- **工具层**：LLM 提议新算子，每个过可行性探针，再由普通闸门裁决——**没有任何闸门被放松过**。

### 部署形态

**retrieval replay**：训练完不是让 LLM 现场推理，而是把成功管线存进经验库，推理时 KNN 检索 + 回放。**CPU 11.7 s/网格，零 LLM 调用**。完整采集循环 4.3/12.2 min，训练一次约一天。

## Key Contribution

1. **首个"修复式简化"的预算律**，并给出可辨识的指数结构（$\varepsilon^{-1}$ / $\varepsilon^{-1/2}$ / $\varepsilon^{0}$）。
2. **分量悬崖定理**：把"熔毁"从经验观察变成**有精确位置的预测**。这是全文最有迁移价值的一条。
3. **一个"不回归"的自我演化纪律**：闸门分 8.8358 → 8.9811（+0.145，5 次接受），**19 个验证网格全部变好**（最小 +0.021），72 组里零回归。
4. **工程数字**：0.5% 预算下 Chamfer **0.0015**（24/24 成功），重建管线 0.005–0.009，LATO.2 0.003–0.011，裸 QEM / 聚类 0.05–0.18（熔毁）。盲目研究 216 组配对判断 **168:48**（8/9 被试，$p=0.0195$）。

## Why It Works

**因为"清洗"这个动作改变的是 $n_{\text{sig}}$，而 $n_{\text{sig}}$ 是乘在 4 上的。**

这句话可以换个说法：**三角形预算是可加的，连通分量数是可乘的**。你把容差放松一倍，前两项各降 $\sqrt2$ 或 2；你把分量从 8,223 降到 1，第三项降 8,223 倍。**同一个预算里，一个是"渐近"，一个是"开关"。**

而"先清洗"之所以必须是第一步而不是最后一步，是因为**清洗会改变后面所有步骤的分母**：焊掉之后，剩下来的每个壳才有资格拿到 ≥4 个面；不焊，你就得为 8,223 个壳各付 4 个面，然后剩下的预算连一个壳都做不好。

**同一条逻辑解释了"清洗承担了大部分效果"这个尴尬的实验结果**：conservative clean + QEM 只到 1/24，固定激进配方到 19/24，智能体到 24/24。**真正值钱的是"清洗 + 一个还行的配方"（19/24），智能体只在最后 5 个网格上赢。** 作者自己写了：*"cleaning carries most of the effect"*。

## Limitations

1. **$S^*$ 是声明的，不是观测的。** 把目标面定义成"焊接闭合"，于是"焊接 = 修复"永远成立。**这是一个定义上的胜利，不是几何上的。** 若真实的建筑本来就有意分成多个独立件（栏杆、雨棚、烟囱），焊掉它们就是**真的改变了拓扑**，而论文的契约看不出来——它自陈 *"outputs are not certified structural geometry"*。
2. **理论是渐近的**，0.5–1% 预算下只声称"区域结构"（两段式、悬崖位置随 $F_{\text{comp}}$ 移动），不声称常数正确。拟合出的 $\hat c\in[1.1\times,2.4\times]$——**只有量级**。
3. **必要性是分布特定的。** 表 1 摊得很清楚：在 Hunyuan3D 的破碎训练集上，裸 QEM 只有 **1/24**；但在独立来源的 20 个德国城市建筑上，**裸 QEM 是 20/20**。也就是说 —— **这个方法在"AI 生成的碎网格"上是必需的，在"结构良好的建筑"上是多余的**，而激进清洗在后者身上还会**自己造成失败**（QEM 卡在 2/20，剩 76 万/66 万面）。**这是一个诚实但致命的边界。**
4. **人评是在训练集上做的。** 168:48 用的是 24 个训练建筑；20 个测试建筑被作者自己描述为"视觉上不可区分"。**所以"感知更好"这件事没有在留出数据上被证明。**
5. **数字校准不跨域。** 把训练好的配方搬到 9 个非建筑网格：程序性知识（先清洗再简化）能迁移（7/9 网格非流形 ≤3 条边），**但绝对预算搬不动**（回放把输出钉在 2,000 面地板上，与尺度无关）。**负迁移是真的**：薄壁玩具鸭上，建筑经验给出 2,716 条非流形边，而空库只有 332 条。
6. **工具层是空的。** 六个候选算子，0/8 采纳，最好增益 0–3%（中位 1%）。作者判为"这个参数空间已耗尽"——**换句话说，"自我演化"目前只在 prompt/权重层面有效，没有长出新工具。**
7. **消融是单次运行**（canonical 补了三个种子，8.983 ± 0.011）。去掉闸门是唯一变差的干预（−0.086，17/24 接受含负增益），**这恰好说明"闸门"是全部机制里唯一承重的那根**。

## Game Development Relevance

**这是本库第一篇直接讲"AI 生成资产怎么变成游戏可用资产"的论文**——而这条管线在 2026 年是真实存在的（Hunyuan3D → 引擎）。

**① 那条定理可以直接搬进 LOD 评审。**
任何"把这个模型压到 1%"的需求，先做一次分解：

| 项 | 怎么估 | 对容差的态度 |
|---|---|---|
| 曲率项 $A_{\text{curv}}/\varepsilon$ | 曲率积分 / 目标边长 | 放松容差**有用** |
| 折痕项 $A_{\text{crease}}/\sqrt\varepsilon$ | 硬边总长 / $\sqrt\varepsilon$ | 放松容差**有用，但只到 $\sqrt{}$** |
| **分量项 $4n_{\text{sig}}$** | **数连通分量** | **完全无用** |
| 亏格项 $c_4g$ | 洞的个数 | 完全无用 |

**"数一下这个模型有几个连通分量"是 30 秒能做完的动作，而它能预测"这个 LOD 会不会掉东西"。**

**② "熔毁"在引擎里的名字叫"自动 LOD 把栏杆删了"。**
UE / Unity 的自动 LOD 在低档位上删小件、焊薄墙，正是本文定义的熔毁。**判据：如果预算低于 $4n_{\text{sig}}$，掉的不是精度，是部件。** 而美术的判断通常是"看起来少了点什么"——**现在有个可算的数字能提前告诉他们少的是什么。**

**③ 最重要的工程动作是"先清洗"，而它在引擎里没有对应的按钮。**
DCC 侧的"Merge by Distance + 删除松散几何"就是清洗，但它从来不被当成 LOD 流程的**第一步**，而是被当成"模型有问题时的抢救"。**本文说它是理论强制的**——顺序错了，后面全是白做。

**④ 反过来的用途：判"这个资产值不值得修"。**
如果 $4n_{\text{sig}}$ 已经超过预算，那么**修不如重做**。这条能挡掉大量"在碎模型上反复调 LOD 参数"的无效工时。

## Unreal Engine Relevance

- **Auto LOD / Simplygon 的失败模式就是本文的熔毁**：低档位删小件、焊薄壁。本文给了一个**事前**判据（数分量）而不是事后验收（看渲染）。
- **Nanite Fallback Mesh** 同理：fallback 是在"不需要 Nanite 的平台上"的简化网格，如果源网格是碎的，fallback 会掉件。**在导入时就数一次分量，比在打包后发现问题便宜。**
- **HLOD（World Partition / Hierarchical LOD）**：城市级 HLOD 把多栋楼合成一个代理，分量数会**先涨后降**——本文的账在这里是"每栋楼各付各的 4 个面，合成之后才可能共享"，**合并的收益可以直接用 $4n_{\text{sig}}$ 的差值估**。
- **不能直接用的是"智能体"那一层**：LLM 规划器（MiniMax-M3）不参与推理，部署形态是检索回放。**能抄的是纪律（验证闸门 + 拒绝缓冲 + 精英保留），不是架构。**

```

1994-96 Ludwig / Glasauer 曲率积分形式                      —— 只对光滑体
  ↓
1996  Hoppe               渐进网格：保拓扑，但没回答"最低多低"

  ↓
2000s-2010s              顶点聚类 / alpha wrap / voxel hull：重建式，换契约
```

**这条线此前所有的公式都假设"物体是一件"。** 一旦物体是"一堆件"，预算律里就多出一个不随 $\varepsilon$ 变的常数项——**而这一项在生成式资产普及之前不会有人写下来**，因为手工建模的资产天然是连通的。

## Relationships

### Based On

- **Garland & Heckbert 1997（QEM）** —— 被比较、被熔毁的那个基线。
- **Fejes Tóth 1948 / Glasauer–Schneider 1996 / Ludwig 1994** —— 前两项（曲率、折痕）的出处。本文的新东西是**第三项**。
- **Jungerman–Ringel 1980** —— 亏格项 $c_4g$ 的最小三角剖分。

### Extends

- [[Mesh Simplification]] —— 把"误差度量"扩展到"**预算律**"：不只问"这一步删得对不对"，还问"最低能做多低"。
- [[Level of Detail]] —— 给 LOD 链补一个**下界**：此前 LOD 只规定"每层放什么"，没规定"最后一层最低是多少"。

### Related

- [[Isosurface Extraction]] —— 反向的同构：那一页问"给一个场，要多少三角形才能逼近它"（$\propto 1/\mathrm{lfs}^2$），本页问"给一堆碎片，要多少三角形才能保住它"（$\propto n_{\text{sig}}$）。**两者都是在数"自由度该花在哪"，一个按特征尺寸，一个按件数。**
- [[Budget Units]] —— 一个新的计价对象：**连通分量**。它与库内已有的十种都不同：**它不随"内容多少"变，随"内容碎不碎"变。**
- [[Automated Content Evaluation]] —— 同一族问题：怎么用可算的量替代"看起来对不对"。本文的闸门是一个六维加权分，而它的权重来自一次校准（初次校准因平面性权重过高而接受了退化薄片）。

### Followed By（可预期）

- 把预算律用到**非建筑**的生成资产（角色、道具、植被）——本文自己承认数字校准不跨域，但**结构**（$4n_{\text{sig}}$ 这一项）应该跨域成立。
- 与**生成侧**联动：如果生成器知道"分量数会被罚"，它可能直接生成连通性更好的网格。**这比事后修复便宜一个数量级。**

## Learning Value

1. **"简化到 X%"这个需求本身是错的问法。** 正确的问法是"这个模型的预算律里，哪一项在主导"。**主导项是分量项时，任何参数调整都是在两个失败模式之间移动。**
2. **理论的价值在于"提前知道会失败"**，而不是"证明我的方法好"。本文最有用的一句是"低于 $F_{\text{comp}}$ 不存在解"——**它让"放弃"变成一个有理有据的决定。**
3. **验证闸门是自我演化里唯一承重的部件**（去掉它 −0.086，其余干预都只是变慢）。**要抄"self-evolving agent"，先抄闸门，别抄 prompt 技巧。**

## Notes

- **这篇的价值不在"agent"，在"定理 3.1 的第三项"。** 智能体那部分是工程包装（LLM 规划 + 闸门 + 检索回放），可迁移性一般；而 $4n_{\text{sig}}$ 是**可以今天就拿去用的判据**。
- **它同时是本库第一条"AI 生成资产 → 游戏可用资产"的直接证据链**：Hunyuan3D 生成的 0.9–1.5 M 面建筑 → 0.5% 预算 → 商用 remesher 对比。**这条链此前在库里只有零散的"生成"和零散的"LOD"，没有接起来过。**
- **那个"$S^*$ 是声明的"值得单独记**：它是本库见到的第二例"用定义把定理变真"（第一例是 [[2026-11-13-Leonard — Real-Time Volumetric Light Transport Inference without a Path|HaloRT]] 的"取消估计量"）。**判据：看到"我们定义参考面为…"，就要问"这个定义排除了哪些真实情况"。** 这里排除的是"本来就有意分开的部件"。
- **人评 168:48 只覆盖训练集**，而测试集"视觉不可区分"——**这意味着在真实的新资产上，这套方法的感知收益还没有被证明**。它证明的是"在训练分布上更好"，这与论文标题里的 "Generated Building Meshes" 是对得上的（生成式建筑有共同的病理），但不能外推。
