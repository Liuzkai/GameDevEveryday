# NeRF (2020) —— 存的是查询接口，不是样本

> ECCV 2020。Ben Mildenhall / Pratul Srinivasan / Matthew Tancik / Jon Barron / Ravi Ramamoorthi / Ren Ng。
> **一句话**：它没有存图像、没有存点云、没有存网格——**它存了一个函数** $F_\Theta:(\mathbf x,\mathbf d)\mapsto(\mathbf c,\sigma)$。任何一个视角的画面，都是这个函数沿光线被查询一遍的结果。

## TL;DR

- **这是本库缺席最久的一块地基**：3DGS 及其三十多篇变体全在这条线上，而 **Radiance Fields 一直没有自己的页面**——今天补上；
- **它的存储形态是第四种**：Ward 1988 存**答案**（辐照度），Jensen 1996 存**证据**（光子），PRT 2002 存**算子**（传输矩阵），**NeRF 存的是"场"——一个可以任意查询的连续函数**。**四者的区别不在压缩率，在"什么问题不用重算"**；
- **两个工程动作撑起了它**：**位置编码** $\gamma$（把坐标抬到高频基上，否则 MLP 学不出细节：PSNR 31.01 → 28.77）与**分层采样**（把查询预算花在有内容的地方：31.01 → 30.06）；
- **成本要按"查询次数"记**：一张 800×800 的图 = 64 万条光线 × (64+128) 个采样点 ≈ **1.5–2 亿次网络查询**，V100 上 **约 30 秒一帧**。**说"渲染一张图"等于没说，"1.5 亿次查询"才是账**；
- **它的死穴从第一天就写清楚了**：**逐场景优化**（1–2 天）、**静态**、**光照烤进权重**（不能改光）。三年后 3DGS 用"显式图元 + 光栅化"把前两条各砍掉一个数量级——**这就是本库整条 GS 线的起点**。

## Problem

从一组已知相机参数的图片，合成任意新视角的画面。传统路线是**先重建几何、再渲染**：多视图立体 → 网格/点云 → 光栅化。中间那一步（离散几何）既是瓶颈也是误差源：**表面提取会丢高频、会错、会有洞，而渲染质量的上限被几何精度锁死**。

而体渲染路线（volumetric）天然绕开"表面"：它只需要一个**沿光线的密度与颜色场**。问题是——**这个场怎么表示？**

| 表示 | 问题 |
|---|---|
| 体素网格 | 分辨率立方级内存，$512^3$ 就是 1.3 亿个体素 |
| 多平面 / 张量 | 内存可控，但分辨率与表达力绑定 |
| 点云 / 网格 | 要"先有表面"，且不可微地提取 |
| **连续函数（MLP）** | 内存只有权重（几 MB），**任意分辨率、任意视角**——但**能不能优化得出来？** |

**NeRF 回答的就是最后这一问。**

## Historical Context

```text

1996  Jensen 光子图             —— 存证据（位置 + 方向 + 功率）
2002  PRT                      —— 存算子（SH 传输矩阵）

2020  ★ NeRF                    —— 5D 函数 + 体渲染 + 位置编码 + 分层采样，四件套齐
2022  Instant-NGP              —— 把函数换成"哈希网格 + 小 MLP"，训练从"天"到"分钟"
2023  3D Gaussian Splatting     —— 把函数换成"显式高斯基元 + 光栅化"，渲染从"秒"到"毫秒"
        ↓
      "'场' → '场的快速近似' → '场的显式采样'——
       每一次换表示，换的都是'查询一次多贵'"
```

**NeRF 在库里是"缺失的祖先"**：[[Gaussian Splatting]] 页里那句 `[[Radiance Fields]]` 一直是悬空链接，今天结清。

## Previous Work

- **SRN（Sitzmann 2019）**：连续函数 + 光线步进，但**要求前景 mask**，纹理糊；
- **DeepVoxels（Sitzmann 2019）**：体素特征网格，分辨率受限、内存高；
- **Neural Volumes（Lombardi 2019）**：体素 + 形变，需要**密集视角**且只能渲 512²；
- **LLFF（Mildenhall 2019）**：前向场景的新视角合成，**用 MPIs 分层表示**——NeRF 在真实前向场景上主要对标它。

**NeRF 相对它们的差别不是"更深的网络"，是"把表示换成了连续 5D 函数 + 用体渲染积分"**——于是**不需要 mask、不需要体素分辨率、梯度可以从图像直接传到最后一步**。

## Core Idea

> **一个场景 = 一个函数。渲染一帧 = 沿每条光线查询这个函数一遍，再做数值积分。**

$$F_\Theta:(\mathbf x,\mathbf d)\to(\mathbf c,\sigma)$$

**注意 $\sigma$ 只依赖 $\mathbf x$，$\mathbf c$ 依赖 $(\mathbf x,\mathbf d)$**。这一条不对称是刻意的：

- **密度与视角无关** ⇒ 几何是"一个"东西（多视角约束才能成立）；
- **颜色与视角有关** ⇒ 允许镜面反射、菲涅尔这类**视角依赖的外观**。

**如果颜色也与视角无关，多视角的一致性会更强，但镜面就没了**——消融里"no view dependence"掉 3.35 dB，掉的主要就是高光。

## Technical Approach

### 1. 函数本体：8 + 1 层

$$\mathbf x\ \xrightarrow{\text{8×FC(256,ReLU)}}\ (\sigma,\ \mathbf f_{256})\ ;\qquad [\mathbf f_{256};\mathbf d]\ \xrightarrow{\text{FC(128,ReLU)}}\ \mathbf c$$

**先把位置压到 256 维特征、再与方向拼接**——这是"密度只看位置、颜色再看方向"在结构上的落地：**方向进得越晚，几何越不会被视角信息污染**。

### 2. 位置编码：让 MLP 能表示高频

$$\gamma(p)=\big(\sin 2^0\pi p,\ \cos 2^0\pi p,\ \dots,\ \sin 2^{L-1}\pi p,\ \cos 2^{L-1}\pi p\big)$$

$\mathbf x$ 用 $L=10$（→ 60 维），$\mathbf d$ 用 $L=4$（→ 24 维）。**这是把 $F_\Theta$ 重写成 $F'_\Theta\circ\gamma$：一个不学的、一个学的。**

**为什么必要**：MLP 对低频函数友好，对"像素级细节"极不友好（谱偏置）。**把坐标先铺到一组高频基上，等于把"需要学的频率"挪到网络擅长的那一段**。消融：去掉它 31.01 → **28.77**；频率给少了（$L=5$）30.59，给多了（$L=15$）30.81——**不是越多越好，10 是拐点**。

### 3. 体渲染：从积分到求和

$$C(\mathbf r)=\int_{t_n}^{t_f}T(t)\,\sigma(t)\,\mathbf c(t)\,dt,\qquad T(t)=\exp\Big(-\int_{t_n}^{t}\sigma(s)\,ds\Big)$$

离散化（分层采样后）：

$$\hat C=\sum_i T_i\big(1-e^{-\sigma_i\delta_i}\big)\mathbf c_i,\qquad T_i=\exp\Big(-\sum_{j<i}\sigma_j\delta_j\Big)$$

**$\alpha_i=1-e^{-\sigma_i\delta_i}$ 这一项是全篇最重要的细节**：它把"密度 × 距离"变成**不透明度**，于是求和的语义与 alpha 混合完全一致——**这也是三年后 3DGS 能直接搬这套公式的原因**。

### 4. 分层采样：把查询预算花在有内容的地方

- **粗网络**：$N_c=64$ 个均匀采样，得到 $\hat\sigma$；
- **把这 64 个权重归一化成 PDF，反变换采样 $N_f=128$ 个点**，只在这 128 点上跑细网络。

**总查询数 64+128 = 192 次/光线**（粗网络的输出也参与最终积分）。**"空的地方少问、有东西的地方多问"——这是"预算按分布分配"在 2020 年的版本。**

### 5. 训练目标

$$\mathcal L=\sum_{\mathbf r\in\mathcal R}\Big\|\hat C_c(\mathbf r)-C(\mathbf r)\Big\|_2^2+\Big\|\hat C_f(\mathbf r)-C(\mathbf r)\Big\|_2^2$$

**只有渲染损失，没有深度、没有 mask、没有多视图一致性项**——所有几何都是"为了让像素对上"被逼出来的。**这是"端到端"在这个领域最纯粹的一次。**

## Key Contribution

1. **把场景表示成 5D 神经辐射场**，并用体渲染把它可微地连到图像；
2. **位置编码**：让 MLP 能拟合高频（没有它，一切都不成立）；
3. **分层采样**：把采样预算按可见内容分配（把查询数从"均匀密采"降到 192/光线）；
4. **一组至今仍是基准的数据**：合成 31.01 dB / 真实前向 26.50 dB。

## Why It Works

**因为它把"重建"这个逆问题，转化成了"函数拟合"这个良态问题。**

- 没有显式几何 ⇒ 没有"表面提取"这一步 ⇒ 没有拓扑错误、没有洞；
- 体渲染处处可微 ⇒ 梯度可以从像素一路回到 MLP 权重；
- **多视角一致性由"同一个 $\sigma$"自动保证**——同一个三维点，无论从哪个角度看，密度必须一样，否则两个视角的像素都对不上。**这是"一致性由构造保证"最早的样本之一**（与 10-23 的 Kavan DQS、10-23 的 LiveAct 同族，见 [[Skinning]]）。

**而位置编码解决的是另一个问题**：不是"能不能拟合"，是"**能不能在有限的网络宽度里拟合高频**"。

## Limitations

1. **逐场景优化**：100–300k 次迭代，**单卡 V100 上 1–2 天**——这不是"训练一个模型"，是"为一个场景解一个优化问题"；
2. **渲染极慢**：见下表的查询账；
3. **静态**：没有时间维（4D 是后来的事）；
4. **光照烤进权重**：$\mathbf c$ 是"这个方向看到什么颜色"，不是 BRDF——**不能改光、不能改材质、不能重打光**；
5. **需要较多输入视角**：合成场景 100 张；真实前向场景靠 LLFF 的稀疏视角，但**侧后方的质量明显下降**；
6. **镜面是"记住的"，不是"算出来的"**：5D 函数可以拟合视角依赖，但它没有反射的物理结构，**视角一离开训练分布就崩**。

## Game Development Relevance

- **它是"离线真值工厂"的现代形态**：NeRF 不快，但它**能把一组照片变成一个可任意查询的场景**——这对"参考场景数字化"、"过场镜头预演"、"资产扫描"是直接可用的；
- **但更重要的是它给了一套"成本记账"的语言**：**渲染成本 = 光线数 × 每光线查询数**。这条对你的 VFX 预算有直接同构——**粒子系统的成本不是"多少个粒子"，是"多少个粒子 × 每个粒子多少像素 × 每像素多少层"**。**"数量"是弱代理，"数量 × 每单位的处理次数"才是账**；
- **反面教材也值钱**：NeRF 把"表示"做到了极致优雅，却输给了"表示 + 光栅化"（3DGS）。**原因是它把成本放在了"每个采样点一次网络前向"上**——而这个成本与分辨率、与视角数都线性相关。**任何"优雅但每像素要跑一次网络"的方案，在实时里都会被"预计算 + 查表/光栅化"打败。**

## Unreal Engine Relevance

- **不直接可用**：UE 没有可微体渲染管线；把 NeRF 塞进实时渲染需要预烘焙成体积纹理或高斯，那就已经是另一条路了；
- **间接可用（更有价值）**：**NeRF 是"从照片到可查询场景"的通道**——扫描一个实景、训一个 NeRF、导出点云/高斯/网格，再进 UE。这条链在今天的工具里已经成熟（这也解释了为什么库里 GS 线这么厚）；
- **概念上的映射**：NeRF 的"分层采样"= UE 的**重要性采样 / 自适应采样**思路；它的"位置编码"= 材质里的**高频法线细节**问题（同一个病：网络/插值对高频无能为力，只能先把高频喂进去）。

## Relationships

### Based On

- **[[Kajiya — The Rendering Equation (1986)]]**：NeRF 的体渲染积分就是渲染方程的**无散射特例**（只有吸收与发射，没有 in-scattering）。**它没有解渲染方程，它把渲染方程的一项（$\sigma$ 与 $c$）变成了可学的参数**；
- **[[Global Illumination]]**：GI 谱系表里"存什么"这一列，NeRF 补上第四种形态（场）。

### Extends

- **[[Neural Rendering]]**：把"神经"从"后处理/上采样"推进到"**表示本身**"；
- **[[Radiance Fields]]**（今日新建）：NeRF 是这个概念的**定义者**。

### Related

- **[[Gaussian Splatting]]**：**同一个问题、两种表示**。NeRF 存函数（隐式、紧凑、查询贵），3DGS 存图元（显式、可光栅化、内存大）。**它们的分界线是"查询的单位成本"**；
- **[[2026-10-29-Choi — L3G-World Real-Time Infinite World Generation with Latent 3D Gaussian Memory|L3G-World]]**：今天的前沿把 GS 又往前推了一步——**高斯里存的不是颜色，是别人要的 latent**。**从 NeRF 到 3DGS 到 L3G，三代的差别都是"存的东西给谁用"**；
- **[[2026-10-30-Liu — Texture Consolidation of Generated Multi-View Renderings|Texture Consolidation]]**：同一族问题（多视角证据如何融合），NeRF 的选择是"**让网络自己消化矛盾**"，那篇的选择是"**先在曲面域对齐再融合**"。**前者靠容量，后者靠结构**。

### Followed By

- **Instant-NGP (2022)**、**Mip-NeRF (2021)**、**NeRF-W (2021)**、**3DGS (2023)** —— 本库已有 30+ 篇 GS 变体，全部是这条线的后代。

`Normal`。**这篇不需要"读"，需要"背三件事"**：

1. **$(\mathbf x,\mathbf d)\to(\mathbf c,\sigma)$，密度不看方向、颜色看方向**；
2. **位置编码是必需品，不是技巧**（去掉掉 2.24 dB）；
3. **成本 = 光线数 × 每光线查询数**（192 次），所以 30 s/帧。

## Learning Value

- **一条可迁移的判据**：*判断一个表示贵不贵，别看它占多少内存，看"查询一次多少钱"×"一帧要查多少次"。* NeRF 的权重只有几 MB（比任何体素都小），但它一帧要查 1.5 亿次——**内存与时间在这里是彻底解耦的**；
- **第二条**：**"一致性"可以由"共享一个量"来保证**。同一个 $\sigma$ 被所有视角共享，所以多视角自动一致。**这比写一个一致性损失强得多**——与 [[Skinning]] 里"混完归一化即回 SE(3)"是同一个思想；
- **第三条（对预算工作的直接映射）**：**"数量"从来不是成本，'数量 × 每单位的次数'才是。** 3000 个粒子不是预算，**3000 × 平均像素面积 × 层数**才是；256² 的模拟不是预算，**256² × pass 数**才是（Harris 2004 那条）。**NeRF 这张表把这条规律推到了它的极限形态。**

## Notes

**成本账（必须成对引用）**

| 项 | 数值 | 口径 |
|---|---|---|
| 训练 | 100–300k 迭代，**1–2 天** | 单卡 V100，**逐场景** |
| 每帧光线数 | 合成 640k / 真实 762k | 800×800 / 1008×752 |
| 每光线查询 | **192 次**（64 粗 + 128 细） | 每 MLP 前向 ≈ 9 层 |
| 每帧查询总数 | **1.5–2 亿次** | 论文原话 "150 and 200 million network queries" |
| 渲染速度 | **≈30 秒/帧** | V100 |

**这张表就是"为什么 3DGS 会赢"的答案**：3DGS 把"每像素 192 次网络前向"换成了"每像素若干次高斯排序与混合"——**同样的像素数，前者要跑神经网络，后者只做加法和排序**。
