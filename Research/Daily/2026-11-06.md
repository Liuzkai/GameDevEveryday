# Game Development Research — 2026-11-06

> **今日主题：最耐用的产出不是方法，是尺子。**
>
> 三篇论文，两个前沿一个经典，表面上毫不相干——一个把光栅化器删了，一个给生成的房间打分，一个是六年前的绑骨网络。
>
> 但把它们放在一起看，结论很刺眼：**三篇里最长寿的东西都不是它们的方法**。GRF 的渲染器比光栅化差 5.9 dB、慢 390 倍，但它给了一张"网络必须被告知哪些几何量"的价目表；GREP 的分数会让场景变差，真正的产品是那份点名到物体的报告；RigNet 的网络在六年后的表里是最差的一行，但它造的数据集至今叫 `ModelsResource-RigNetv1`。
>
> **方法的半衰期比度量短。** 而尺子好不好，取决于它**拆得多细**——今天三篇各拆了一次：5.2 / 1.4 / 3.0 dB；三层八指标；J2J / J2B / B2B。

## Frontier Research

### [[2026-11-03-Levy — GaussianRenderFormer Transformer-based Rendering of 3D Gaussian Splats|GaussianRenderFormer — 把光栅化器整个删掉，然后诚实地报告它输了]]

**Why this matters：** 这是第一次有人做出**"输入是显式高斯、输出是像素、中间没有一个手写算法"**的渲染器——也正因为如此，它第一次拿到了那个干净的对照：**同一份剪枝输入，算法 44.02 dB / 0.7 ms，网络 38.08 dB / 275 ms。**

它没赢。但**它输的方式比赢更有信息量**：把三项"被告知的几何量"逐个拿掉，得到一张价目表——**投影位置 5.2 dB、投影 footprint 1.4 dB、patch 粒度 3.0 dB**。

**Personal Relevance：** 这三项里最大的一项是"高斯落在图像的哪儿"。**3D 坐标和相机都给了，唯独没给投影**——而投影就是一次透视除法。注意力擅长"按相似度加权求和"，**不擅长做除法**。这条判据可以直接搬：**你想让网络替掉的那段算法，如果里面有一步"全局归一化"，那一步多半学不出来，得喂。**

关键数字：

- **三个消融（全规模）**：无 2D RoPE **−5.20 dB**；无 footprint **−1.40 dB**；8×8 patch（而非 4×4）**−3.05 dB**。三项都只改"输入"，网络结构几乎没动（早期试过 +9 层 / 8 倍宽 FFN，**毫无提升**）；
- **差距不是泛化差距**：训练物体 38.25 vs 未见物体 38.08，**只差 0.17 dB**；差距随距离变长（1.15 处 3.9 dB → 1.7 处 6.8 dB → 3.2 处直接崩到 24.09 dB）；
- **冷水一（最该记的一条）**：**输入越密，它越差**。40,000 高斯时，光栅化 **+4.6 dB**，网络 **−3.1 dB**。**两条曲线的斜率方向相反**——在"资产会越来越密"的趋势下，这类方法的可用区间会自己缩小；
- **冷水二**：**从零训不出来**（随机初始化 13.12 dB，坍缩成黑图）。唯一可行的配方是"从 RenderFormer 的网格渲染权重出发 + 先单独训输入层"。**预训练权重是一笔不可逆的抵押**：连把已有位置嵌入的频率加倍，都和替换掉它一样有害；
- **冷水三**：**复杂度阶数不同**。20k → 275 ms，640k → 74.9 s：32 倍输入 = 272 倍时间；光栅化是 3.6 倍。**这两个方法没有交叉点。**
- **一个最容易被捡的漏**：footprint 作者只加在 attention 的 key 上；在 1,000 物体的 harness 里，**同时加到 value 上还能再涨 0.68 dB**——全规模没做。

### [[2026-11-04-Cao — GREP Grounding Generated Room Evaluation in Principles|GREP — 打分只能排序，报告才能修改]]

**Why this matters：** 它把"这个生成的房间好不好"拆成**三层递进 + 八个指标**，让一个 Agent 自己判断"证据够不够"、不够就去渲新视角。但它真正的结果不是 86.7% 的一致率，是那张**"报告 vs 分数"的对照表**。

**Personal Relevance：** **同一份初始场景、同一套修订流程，给分数的变差了，给报告的变好了。** 这不是"提示词好坏"，是**反馈的形状**问题。你手上任何一个"自动评分 → 自动修订"的回路都是同一个形状，**包括你自己给自己定的验收标准**。

关键数字：

- **与人类多数偏好一致率 86.7%**（整体 VLM 62.2%，纯物理指标 53.3%）；15 组两两比较 / 6 个场景 / 5 位标注者（11 组全票、4 组 3:2）；
- **报告 vs 分数**：起始 0.585 → 报告组 **0.676**；只给分数组 **0.543**；不给反馈 0.543。**布局实际改动率：15/15 vs 5/15 vs 6/15**；
- **重复性（决定这个分数能拿来比什么）**：12 场景 × 5 次，单场景标准差中位数 **2.9 分**、极差中位数 **7.2 分**（最大 17.2），ICC = 0.92 ⇒ **均值差小于约 4 分不算差异**；
- **冷水一**：**judge 就是被测模型之一**（GPT-5.6 Sol 当裁判，同时是 8 个被测生成器之一）。作者自己点名自偏好风险，跨 judge 检验只覆盖 6 个场景；
- **冷水二**：**它评不了"好不好看"**——风格/审美上限由 scale/style/pairing 三个粗糙指标决定，没有光照、没有材质、没有相机；
- **一个顺带的观察**：给同一批模型加更严的约束（资产多 20%）时，**强模型反而变差**——它守着原有计划不肯改。作者的阶段划分：**"依赖 → 冲突 → 整合"，现在的模型在第二阶段。**

## Classical Research

### [[Xu 2020 — RigNet Neural Rigging for Articulated Characters|RigNet 2020 — 把"离散结构"交给算法，把"连续量"交给网络]]

**Historical Role：** **自动绑骨从"几何"转向"学习"的那一步。** 它和 [[Baran 2007 — Automatic Rigging and Animation of 3D Characters|Pinocchio 2007]] 的差别只有一句话：不再把一副**人给的**骨架塞进模型，而是从 2,703 个美术做的 rig 里学一副。

**为什么今天补它**：库内这条线一直是"2007 有、2026 有、中间空着"。[[Automatic Rigging]] 页的"Historical Evolution"从 2007 直接跳到 2020 并标注"库外，本库缺口"——今天把这一格填上，**19 年的曲线才有中段**。

**Knowledge Graph Role：** 它是 [[Automatic Rigging]] 这条线的**第三个坐标**，也是唯一一个"既不靠模板、也不靠大模型"的中间形态。

四件事，今天还在用：

1. **离散结构不回归，交给算法读出来**。没有一个"输出关节数"的头，也没有一个"输出邻接矩阵"的头：关节数 = mean-shift 的**模态个数**，拓扑 = 概率最大的**生成树**。**网络负责"哪个更可能"，算法负责"哪个合法"。**
2. **注意力是承重的中间量**。去掉注意力，IoU **61.6 → 52.4（−9.2）**——比换掉整个 GNN 骨干之外任何单项都大。**"哪块表面重要"这个可解释的中间产物，比网络结构本身更值钱。**
3. **权重比骨架更能说服产线**。蒙皮 L1 **0.39** vs Maya 的 geodesic voxel bind **0.65**、BBW **0.69**、NeuroSkinning **0.57**——**这是少数把"权重"单独列表并且赢了 DCC 默认算法的工作**，而美术每天在修的恰恰是权重。
4. **骨骼 LOD 的第一个旋钮是几何参数**：mean-shift 的带宽 $h$（0.01–0.1），小则关节密、大则疏；$h=0$ 会让每个顶点都变成关节。六年后的 [[2026-11-02-Guo — FlowRig Unified Skeleton Generation for 3D and 4D Meshes via Flow Matching|FlowRig]] 把它变成了**模型条件**——差别是：改 $h$ 要重跑聚类，改条件不用重跑网络。

**Related Concept：** [[Automated Content Evaluation]]（新，第 57 个概念）

**三处冷白开水：**

- **per-stage 训练，不能端到端**：每一段都"用真值训、吃预测跑"。作者原话：**"我们基于训练骨架而非预测骨架来训练蒙皮网络，因为我们没有预测骨架的蒙皮真值。"** 这是 exposure bias 的教科书形态，**而且没有任何一个损失函数能看见这件事**；
- **数据集只有一模型一 rig**：很多 rig 不含脚趾、手指、衣服的骨 ⇒ 模型对这些部位预测弱；
- **耗时没报**。对比 Pinocchio 明报的 31.3 s，这一项在正文里是空白——**对一个要进资产管线的工具，这不算小缺失**。

## Personal Learning Focus

### Normal → Easy

- **[[Automated Content Evaluation]]**（新建，第 57 个概念）：只拿三层——① **判决 / 分数 / 报告是三样东西**，用途分别是定位 / 排序 / 修改；② **三层阶梯是修复优先级**，不是分类（穿模的桌子，"桌面高度合不合适"这个问题不成立）；③ **先量重复性再比东西**（差值 < 4 分不算差异）。
- **"把算法中间量逐个喂回去，量每项值多少 dB"**：这是 GRF 那张价目表的做法，也是判断"该保留哪一层显式几何"的定量方法。**成本一个零初始化线性层，收益 1.4 dB 加一整类不变性。**

### Hard → Normal Bridge

- **RoPE 的多维旋转构造**属 Hard，**不必读**。桥是一句话：**它就是把"位置"变成注意力里的一个相对相位**——3D 版告诉模型"这两个高斯在空间里隔多远"，2D 版告诉它"在图像上隔多远"。**后者值 5.2 dB，前者是继承来的、没被消融过。**
- **mean-shift 的收敛性**属 Hard，**不必读**。桥是一个观察：**它不需要预先知道要分成几类**——这正是 RigNet 能用它"输出关节数"的全部原因。**换成一个需要指定 K 的 k-means，整条管线就断了。**

## Technology Evolution

**学习式渲染（今天第一次拿到同口径的账）：**

```text
2025  RenderFormer：三角网格 + 全局光照，≤4,096 三角，8×8 patch
  ↓
2026  RenderFormer-V2 / ++：更多基元、灯、介质
  ↓
2026-11  GaussianRenderFormer：20,000 高斯 token，4×4 patch
          · 第一次能问："比光栅化差多少？"  答：−5.9 dB / 390×
          · 三个改动全是"喂输入"，不是"改结构"
          · 网络的质量随输入密度下降，算法随输入密度上升
```

> **这条线的形状不是"逐步逼近光栅化"，是"逐步发现哪些东西不该学"。** 三个改动、三张价目，全部指向同一件事：**解析投影那一层是里面最不该删的。**

**绑骨线（19 年，今天补上了中段）：**

```text
2007  Baran & Popović：嵌入 + 热平衡权重 + 学罚项配比
        四套模板；结构不匹配就崩
  ↓
2020  ★ RigNet：GNN + 加权 mean-shift + MST + 测地蒙皮
        · 无模板；IoU 36.5% → 61.6%；蒙皮 L1 0.65 → 0.39
        · 带宽滑杆 = 骨骼 LOD 的第一个旋钮
  ↓
2023-25  MagicArticulate / UniRig / RigAnything / Puppeteer
        · 大模型化；骨骼数仍不可指定；逐帧套用会闪
  ↓
2026  FlowRig：整段序列一个样本 + 骨骼数当条件 + 拓扑池化一次
```

> **这条线的形状也不是"精度单调上升"，是"约束的形态在变"**：2007 硬约束（关节只能落在图顶点上）+ 人给模板 → 2020 无约束 + 数据给先验 → 2026 标量条件 + 时间一致性。**唯一没变的是"骨架是接口"。**

## Important Relationships

- **三篇在做同一个动作：把一个标量拆成有名字的几项。** GRF 把"差 5.9 dB"拆成 5.2 / 1.4 / 3.0；GREP 把"好不好"拆成三层八指标 + 一份报告；RigNet 把"骨架对不对"拆成 J2J / J2B / B2B（**"J2B 低 + J2J 高"这一对组合直接读出"位置对、但关节沿骨错位"**）。**拆开之后才知道下一步动哪里——这是今天三篇唯一真正的共同点。**
- **"离散决策谁来定"有两个答案，今天同框了。** RigNet 交给**算法**（聚类取模态 + MST 保证是树）；FlowRig 交给**池化后的网络**（时间池化 ⇒ 只定一次）。**两条路都在追求"只定一次"，只是"一次"的定义不同：一个在结构上，一个在时间上。**
- **"反馈的形状决定结果"这条，跨越了三个领域。** GREP：只给分数 ⇒ 修订变差；FlowRig：离散量用损失函数压 ⇒ 压不住只能一次定；[[2026-10-29-Rohmer — Dynamic Skinning Kinematics-Driven Cartoon Effects for Articulated Characters|Dynamic Skinning]]：因果核 ⇒ 造不出 anticipation。**三个"形状"（反馈粒度 / 优化目标 / 核的支撑集）不同，结论同构：形状选错，加大力度没用。**
- **[[Gaussian Splatting]] 的排序线今天多了第 8 个节点，而且是唯一一个"把整个光栅化器删了"的。** ①–⑦ 全都在问"排序怎么办"；⑧ 问的是"要不要保留解析投影"——**答案是不能删，删了要付 6.6 dB 把它买回来。**

## Emerging Trends

- **自动化的下一个门槛不是"生成得更好"，是"能被验收"。** FlowRig 让骨骼数变成输入（可控），GREP 让"哪里不对"变成输出（可验收）。**这两个方向正在合流：可控是前提，可验收才是能不能进产线的判据。**
- **"删掉算法"的代价开始有数了。** 以前所有神经渲染都无法回答"比光栅化差多少"（因为不吃同一份输入）。GRF 给了第一个：**−5.9 dB / 390×**。这个数会成为后面所有同类工作的基线——**一个诚实的负结果，价值超过三个 SOTA 声明。**
- **评测器本身开始被评测。** GREP 报了重复性（SD 2.9 / 极差 7.2）和自偏好风险；[[Giroux 2023 — Towards a Perceptual Evaluation Framework for Lighting Estimation|Giroux 2023]] 报了"标准指标≈随机"。**"我的尺子准不准"正在从客套话变成一个必报的数。**

## Industry Signals

- **本批次 7 条公告全部为学术预印本**（1 篇 TMLR 在审、1 篇 WACV 2027），无产业侧材料；
- 但有一条可用的产业侧推论：**目前所有"神经网络进渲染管线"的产品（DLSS 系、神经去噪、神经材质），输入都是被显式整理过的**——运动矢量、深度、历史帧、G-buffer。**没有一个是从原始场景表示端到端出图的。** GRF 从反面解释了为什么：**端到端意味着你要自己把那些"算法本来免费给你的量"重新算一遍，而这一步的代价是 6.6 dB。**

## Watchlist

1. **GRF 的混合路线**：解析做投影（一张廉价的 2D 表）+ 网络做混合与光传输。消融已经在指路——**它花 1.4 dB 学的那件事，光栅化器用一个雅可比就做完了**。如果有人把这条做出来，会是"神经渲染进管线"最合理的一种形态。
2. **footprint 加到 value 上的 +0.68 dB**：作者只在 harness 里做了，全规模没做。**这是全文最容易捡的一处**，也说明"key 与 value 的分工"这件事在神经渲染里还没被认真研究。
3. **RigNet → 2023-25 的中段仍然是空白**：MagicArticulate / UniRig / RigAnything / Puppeteer 四篇，库内零覆盖。今天补了起点和终点，中段还是黑的；而 FlowRig 表 1 已经给了横向快照，**据此选 1–2 篇补是可行的**。
4. **GREP 的自偏好没有被量化**：judge = 被测模型之一，跨 judge 只覆盖 6 个场景。**"裁判偏爱自己"这件事在图形/生成领域还没有一个标准测法。**
5. **"差值 < 4 分不算差异"这条门槛，应该进自己的评审流程**：不只是自动评测——**任何用打分做版本对比的会议，都该先问一句"你这个评分的重复极差是多少"。**

## Key Takeaways

- **方法的半衰期比度量短。** GRF 的渲染器输了，但那张价目表会被引用；GREP 的分数会让场景变差，但报告是真的产品；RigNet 的网络是最差的一行，但数据集和指标至今是标准。**做工具时，把价值押在"能不能说清楚哪里错了"上，别押在算法上。**
- **"能推出来"和"推出来了"之间隔着 1.4 dB。** footprint 完全由网络已有的输入决定，作者明说"the decoder did not recover the footprint on its own"。**凡是"由已知量唯一决定、但需要一步非线性变换"的量，都别指望网络自己合成。**
- **全局归一化是注意力学不会的那一步。** 透视除法值 5.2 dB——三项里最大。**判断"这段算法能不能被网络替掉"，先找里面有没有"除以某个全局量"。**
- **只给分数会让结果变差。** 0.585 → 0.543。**反馈的粒度决定了它能被用来做什么：分数只能选，报告才能改。**
- **离散结构交给算法，连续量交给网络。** 网络出"哪个更可能"，MST 出"哪个合法"。**凡是有"合法解空间"的结构（树 / DAG / 区间 / 排列），都不要用回归头硬出。**
- **输入越密它越差，这条比"谁更准"更值得记。** 一个方法的可用区间可能和它的对手方向相反——**在资产密度单调上升的行业里，这种方向性比当前差距更致命。**
