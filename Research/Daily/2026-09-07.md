## Top Research

### 1. [[LightOpt — Lights Optimization for Real-Time Rendering]]

| | |
|---|---|
| Importance | **S** |
| Personal Relevance | **最高** |
| Knowledge Target | [[Differentiable Rendering]] / [[Real-Time VFX Performance Budgeting]] |
| Current Level | Normal |
| Venue | SIGGRAPH 2026（清华 + 腾讯光子 LIGHTSPEED） |

**Why Recommended**：

你的 SABC 预算模板里有"动态灯光 S≤3 / A≤2 / B≤1 / C=0"这一维。LightOpt 做的正是**自动减少实时场景灯光数量、同时保持视觉外观**。它把"灯光上限"从一个拍出来的经验值，变成了一个可求解的优化问题。

这是今天唯一一条**与你正在做的工作精确对齐**的研究。

**Action**：即使只有摘要，也请读它的**问题定义**部分。然后回答一个问题：你的 3/2/1/0 是经验值还是推导值？

### 4. [[Motion Style Slider — Continuous Style Control for Human Motion Diffusion]]

| | |
|---|---|
| Importance | **A** |
| Personal Relevance | 中高（方法论可迁移） |
| Knowledge Target | [[Neural Animation]] / [[Real-Time VFX Performance Budgeting]] |
| Current Level | Normal |
| Venue | ECCV 2026（Cygames Research + 东京科学大学） |

**Why Recommended**：

游戏公司自己的研究所，解决的是真实制作痛点："美术想再调一点点，要不要重拍？" 只用两种端点数据（neutral / styled）就训出连续强度滑杆，中间样本完全不准备。

**这条是今天唯一一条"不用读懂模型也能用上"的论文。** 可迁移的问题是：

> S/A/B/C 是 4 个离散端点，还是 1 个强度滑杆？

如果是后者，Niagara 侧用 User Parameter 驱动强度、而不是切换整套 emitter，分档维护成本会显著下降。

## Emerging Trends

**1. 生成式渲染正式越过范式线**
DLSS 5 是第一个"生成最终显示外观"而非"重建参考"的产品化实时模型。行业把三大硬门槛（保留艺术意图 / 帧间稳定 / 4K 实时）写进了架构——这是行业在回应它自己的批评，而不是 dismiss。

**2. 神经 GI 从"去噪"走向"接管光照"**
NRC 已产品化（RTX Remix、HL2 RTX、Portal RTX，~2.6ms @1080p）。AMD 与 NVIDIA 都在推新一代方法。

**3. 3DGS 进入工程化深水区**
不再是"能不能跑"，而是收敛速度、重建质量、规模三刀。SIGGRAPH 2026 Workshop 直接宣布它已成为**生成式世界模型的原生输出格式**。

**4. 生成式动画打通"实时"这条线**
MotionBricks 2ms。Motion Matching 的 20 年统治第一次有了实质挑战者。

**5. 游戏公司自研所成为重要研究源**
Cygames Research、腾讯光子（LightOpt）都在发顶会论文，且问题定义直接来自制作现场。这类论文的**问题定义**往往比方法更值得读。

## Key Takeaways

1. **今天最重要的一条不是最有名的那条。** DLSS 5 声量最大，但对你而言 [[LightOpt — Lights Optimization for Real-Time Rendering]] 才是——它精确落在你的一个预算维度上。

2. **你的预算模型即将面临一次自变量变化。** 目前"粒子/贴图/动态灯/时长"都是为"渲染器表达力不足"买单。神经渲染把一部分表达力外包出去后，这些预算项的含义会变。代价（-50% 帧率、仅 RTX 50）意味着短期影响只在 PC_High，但**现在就该想清楚重构路径**。

3. **有一条方法论比任何论文都值钱**：[[Motion Style Slider]] 的"端点监督换连续控制"。它提示你的分档体系可以从"4 个离散端点"变成"1 个强度滑杆"。

4. **一个马上能做的检查**（零新知识）：挑一个你负责的高频运动特效，检查它在开启超分/帧生成时是否正确输出 motion vector / depth / albedo。粒子是神经渲染最容易翻车的场景。
