## Frontier Research

### [[2026-09-01-ToCo-Mesh — Topology-Consistent Dynamic Mesh Reconstruction via Adaptive Tessellation and Surface-Aligned 2DGS|ToCo-Mesh]]

**Why this matters**：**动态网格重建把"固定拓扑"与"自适应分辨率"第一次同时拿到**（USTC，SIGGRAPH Asia 2026）。重建资产进游戏管线的第一道门不是"像不像"，而是"**能不能绑定、能不能喂动画**"——而逐帧提取（细节好、对应断）与模板变形（对应稳、分辨率锁死）一直是二选一。ToCo-Mesh 的做法：

| 组件 | 做法 | 角色 |
|---|---|---|
| **双网格绑定** | 规范模板网格 ⟷ 时变**粗引导网格**（重心坐标参数化） | guide 冻结管运动；template 误差驱动改分辨率 |
| **split-and-merge** | 按**几何 + 渲染误差**自适应分裂/合并顶点 | 保持严格拓扑一致的"自适应镶嵌" |
| **Surface-Aligned 2DGS** | 压扁的高斯**吸附在面片上**，法线反哺几何微调 | 网格管拓扑、高斯管外观 |

**关键数字（DG-Mesh）**：CD **0.659**（4D-GS 1.396 / DG-Mesh 0.697）、时序平滑 3D-TS **0.05**（最低）、**网格只要 13K 顶点**（对比 4D-GS 729K / GT 72K）、训练 75 min / 6.6 GB / **72 FPS**（RTX 3090）。重建结果**喂入未见过的 pose 参数即可动画**（SMPL 驱动）。

**Personal Relevance（三条抽象，不需要读消融）**：

1. **"拓扑一致性 = 可动画的货币"** —— 管线视角：可动画性 > 单帧精度；
2. **"固定拓扑 + 自适应分辨率" = 把一对矛盾拆成两个自由度** —— 与"结构锚定"母题同构（guide/模板分工 = 确定性结构 + 受控自由度）；
3. **"误差阈值决定密度"** —— 与 LOD/自适应细分同源，可作"何时升档"的量化判据。

## Classical Research

### [[Scheuermann — Practical Real-Time Hair Rendering and Shading (2004)]]

**Historical Role**：**"游戏毛发为什么长这样"的答案文档**。2004 年（SIGGRAPH Sketches，ATI Research，用于实时动画《Ruby: The Double Cross》），把 2003 年的物理模型（Marschner R/TT/TRT）第一次塞进实时渲染器，靠三刀：

1. **模型刀**：连续发丝 → **分层 2D 发片** + 每顶点 AO（顶点负载低 / 排序简化 / 贴美术管线）；
2. **着色刀**：**两 lobe 移位近似**——扰动切线 `T′ = normalize(T + s×N)`（s 查贴图），主高光（白、向发梢）与次高光（有色、向发根、乘噪声）分别近似 R 与 TRT；漫反射 `max(0, 0.75×N·L + 0.25)`；
3. **排序刀**：**取消运行时 CPU 空间排序**——预处理排序（发片为连通分量）存 **静态索引缓冲**，运行时**四趟渲染**（prime-Z → equal 着色 → 背面透明 → 正面透明）。

**Knowledge Graph Role**：**[[Hair Rendering]] 的 Learning Gap #3 直接闭合**——毛发线自此**三节点齐全**：texel（1989 经验）⟷ 物理 lobe（2003）⟷ **实时工程（2004）**。它的参考文献只有两篇，正是它继承与逼近的两端。

**今日最值钱的三条（都已进笔记与概念库）**：

1. **"取消式优化"追出 2004 年版本**：原文 *"Instead of executing a spatial sorting step on the CPU at run-time…"* → 与 2026 的 [[2026-09-22-Stochastic GS Denoising — Ultra-fast Neural Inference for Stochastic Gaussian Splatting Denoising|Stochastic GS Denoising]]（取消 GS 排序）、[[2026-09-23-CuACD — A Fully GPU-Resident Approximate Convex Decomposition|CuACD]]（取消 host 同步）构成**跨越 22 年的同一条链**；
2. **新判据：看到"加一步前置工作/多渲染一趟"的方案，先问它解锁了什么** —— 第①趟 prime-Z 的真正目的是**避免 alpha-test 禁用 early-Z**（"多一趟被随后三趟的 early-Z 收益盖过"）；
3. **"前提假设必须写在明面上"**：静态排序成立的前提是**发片间相对运动足够小**；不成立则回退 CPU 排序（原文明写）——任何预计算方案的规格里都该有"什么条件下失效"这一行。

## Emerging Trends

1. **"取消式优化"完成三例闭环（2004 → 2026 ×2）** —— 从"本周新手法"升格为"**有历史纵深的工程原则**"：面对任一瓶颈，先问"**它能不能不存在**"，再问"能不能更便宜"；且在**执行层**（排序 / 同步 / 边界）同样适用；
2. **"表示分工/混搭"继续扩张**：网格管拓扑 + 高斯管外观（ToCo-Mesh）——与本周的"结构锚定"母题（生成只做不确定部分）在**表示层**会合；
3. **"可动画性"作为资产第一验收项**：ToCo-Mesh（拓扑一致）、HairCS（发片↔发丝）从两个方向说明：**进管线看的是"能不能动、能不能绑"，不是截图**。
