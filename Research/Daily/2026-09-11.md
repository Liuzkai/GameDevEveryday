## Top Research

### 1. [[InstantMimic — A High Performance System for Learning Physics-based Skills in Seconds]] ⭐ 今日主推

| | |
|---|---|
| Importance | **A-** |
| Personal Relevance | 中高（系统方法论 + 新 Concept 锚点） |
| Knowledge Target | [[Physics-based Character Animation]]（新建，Hard）/ 系统诊断侧 **Normal 可读** |
| Venue | SIGGRAPH Asia 2026（conditionally accepted，有项目页） |

**Why Recommended**：

DeepMimic 式物理角色模仿学习的影响巨大，但训练成本一直是它进管线的拦路虎。InstantMimic 的诊断值得记住：**即使物理求解器已经 GPU 加速，端到端训练管线还是吃不满硬件——瓶颈在求解器之外**（碎片化 GPU kernel + 关键路径 CPU 内存访问）。解法是把仿真/环境计算/策略推理/策略更新做成**全 GPU 原生的单一执行流**，技能训练压到**秒级**——快到 LLM agent 驱动的超参搜索第一次实用化。

这是 [[From Splats to Silicon — Rethinking Computational Efficiency of 3DGS|Splats to Silicon]] 同一课在一周内的第二次出现：**组件加速 ≠ 端到端加速，隐性成本在数据搬运与同步**。一次是渲染效率测量学，一次是 RL 训练管线——同一把尺子跨领域复用，说明它不是某个领域的局部经验。

作者栏同样有信号价值：末位作者 Jungdam Won 是 NVIDIA 物理角色控制线核心作者——继 FlexMoGen（Holden）之后，本周第二篇"阵营建桥人亲自下场"的论文。为此新建了 [[Physics-based Character Animation]] Concept（Hard，桥已标注：先推 [[Motion Matching]]，不急着学）。

**Action**：只读 Abstract + 诊断段，10 分钟，当作 Splats to Silicon 的第二个案例读。
