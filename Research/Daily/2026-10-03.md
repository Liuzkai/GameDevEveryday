## Frontier Research

### [[2026-09-27-Plate-Local River Generation]]

**Why this matters**（独立研究者）：**"确定性 + 地形感知 + 下坡保证 + 无限域"四者首次同时成立的程序化河流算法**——解法是"板块局部"：确定性板块种子给出**点值 + 几何双重表示**，每板块独立在低分辨率网格上追河、**懒加载逐板块缓存**；全分辨率采样时精确计算到河网的距离并混合（**混合结果不缓存**）。

- **机制五步**：① 板块种子对偶表示（点值归属 = argmin 距离 + 有界 warp；几何域 = 中垂面裁剪的 Voronoi 式有界域）→ ② 低分辨率规划网格（100×100）+ border-safe 标记 → ③ 逐河溯源（从高到低、走最低 border-safe 样本；终点 = 海面 / 汇流 / 死路成湖或弃）→ ④ **单调高度调整 + Strahler 序**（"每段下降"由构造保证）→ ⑤ 懒缓存 + 按需混合（只需缓存河网本体）；
- **保证的不等式设计**：**板块边界余量（100 单位）≥ warp 最大位移（~94 单位）** → 通道只在本板块内、下坡性质传递到最终地形——**验证是复核而非兜底**（1,450 段全部下降；23,200 采样点无上升）；
- **数字（M4 Max）**：10 板块缓存 **37.9 ms**（均值 3.81/板块）；带河流查询采样 **1.13 µs/样本**（比纯地形 +0.85 µs = 穷举段扫描）；河网缓存 **0.169 MiB**（122 B/段）；**222/500 路径被接受（44.4%）**；C++17 零第三方依赖；
- **诚实反例**：混合带 92,800 采样中 6 个（**0.0065%**）归邻板块 → 河槽外缘被裁、**通道无恙**——原文明确报告，按"边界写进笔记"归档；
- **对库**：PCG 谱系新增**自然地形 / 水网**分支；"**有界域 + 懒加载 + 确定性**"三件套与开放世界流式工程（NGR 一类）直接同构——**确定性 = 多人一致性 = 可丢弃重建权**。

### [[2026-10-01-GALA — Gaussian Blendshape Distillation for Real-Time Avatars]]

**Why this matters**（MBZUAI × MWS AI）：**"3D 高斯化身渲染便宜（622 fps）、动画昂贵（每姿势重跑大网络 1.8 s）"的不对称，被一条线性结构抹平**——动画输出 ≈ **一套身份无关的共享 blendshape 基**的线性组合（"It even holds for identities never seen before"）；把它蒸馏为 **共享基 + 浅层 MLP 系数预测器**，**宿主零重训**。

- **三步**：基构造（残差矩阵 + **块局部 PCA**，rendering-aware 度量 + 内存预算；同预算下对宿主 PSNR 42.6 vs 简单 PCA 32.8 dB）→ 系数蒸馏（浅层 MLP）→ 推理（中性态一次 + 每帧线性混合）；
- **数字**：三类异构宿主 **154→5.5 ms（×28）/ 234→4.4 ms（×53）/ 42.9 s→16.1 ms（×2,659，含蒙皮）**；**手机浏览器 60 fps**；质量不降——FID 3.47@5.5ms vs 最佳蒸馏网络 3.60@124ms（**快 22× 且更准**），唯一更准的蒸馏网络慢 40×；
- **对库**：**"一个表示代表全部"家族今日三例同框**——IR 1997（一组点光源 = 光场）· Zinke 2008（一条原型路径 = 全部路径）· **GALA（一套基 = 全部身份）**；且是**"神经 → 传统资产形态"**的翻译样本（blendshape = 引擎原生语言），[[Neural Animation]]（Hard）桥的新一级台阶。

## Classical Research

### [[Dachsbacher-Stamminger — Reflective Shadow Maps (2005)]]

**Historical Role**：**"缓存族"的 RSM 侧源头**（I3D '05）。观察惊人地简单：**单光源下一个 bounce 的间接光全部来自光源可见表面——信息本来就在 shadow map 里**。于是 shadow map 扩成四缓冲（深度 / 世界坐标 / 法线 / **反射通量**），**每个像素 = 一盏 pixel light**；求和太贵 → **每像素固定约 400 样本**（重要性采样）+ **屏幕空间插值**（低频算准、高频插值）。

- **账本意义**：把 [[Keller — Instant Radiosity (1997)]] 的"每盏虚拟灯一遍渲染"压成"**每像素固定样本数**"——**成本函数从"∝ 光源数"改写成"∝ 像素 × 常数"**（2005 硬件 4.2–27.5 fps @512×512）；
- **最重的近似（原文自陈）**：间接光**不处理遮挡**（"severe approximation, can lead to very wrong results"；AO 贴图补偿）；
- **对库**：2026 的 AMD attention GI **把 RSM 当输入通道**——**"缓存族"成了神经 GI 的眼睛**；MegaLights"每像素固定光照采样预算"= 同一句台词的 2026 形态。

### [[Keller — Instant Radiosity (1997)]]

**Historical Role**：**VPL（虚拟点光源）的起源**（SIGGRAPH '97）。把光路顶点变成"虚拟点光源"、让硬件逐灯渲染、累加缓冲求和——**"光照场 = 一组点光源"**的原始台词；1997 硬件的"instant" = **几秒**（402 四边形场景、296 幅图、SGI Onyx **24 秒**）。两个技术支点：**quasi-random walk**（Halton 低差异、确定性无方差）+ 本文首创的 **jittered low-discrepancy sampling**。

- **机制四件**：分数吸收替代轮盘（路径数 ⌊ρᵏN⌋ 几何衰减，M ≤ N/(1−ρ)）；低差异序列 + 光源表面等距映射；镜面 = 平面虚拟光源；实时变体 = 滑动窗口 N 幅图（隐式时域抗锯齿）；
- **诚实记账（原文）**：弱奇异（距离→0 过调 clip）；单灯影响被 1/N 权重压制到"基本不可感知"；
- **对库**：与 RSM 合读 = **缓存族的两种记账**（随机光路 vs 结构化像素；对照表见 RSM 笔记与图解）；**历史彩蛋**——本文致谢 *"Marc Stamminger, providing access to the Reality Engine 2"*，8 年后 Stamminger 正是 RSM 的作者——**两篇论文之间隔着一次硬件借用**。

### 知识图景：缓存族的两种记账（今日沉淀）

| | **Instant Radiosity（1997）** | **RSM（2005）** |
|---|---|---|
| 光源集来源 | 光路顶点（quasi-random walk，**随机**） | 光源视野像素（一次光栅化，**结构化全集**） |
| 光源集规模 | M 盏 VPL（几百） | 40 万+ pixel light（**按需采样 ~400**） |
| 遮挡 | **有**（每盏 VPL 一遍硬件阴影） | **无**（最重的近似） |
| 成本单位 | **每盏灯一遍渲染**（∝ 灯数） | **每像素固定样本数**（与灯数脱钩） |

> **一句话**：两篇都在回答"**把无限反弹积分换成什么有限结构**"——IR 的答案是"光路顶点的稀疏集合"，RSM 的答案是"光源视野的稠密像素集合 + 采样预算"。**"缓存族"自此从记名变为可读。**
