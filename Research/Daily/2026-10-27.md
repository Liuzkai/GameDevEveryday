### ✅ [[2026-10-26-Zhang — RADIANT Object-Centric Feed-Forward Global Illumination|RADIANT]]（A 前沿）

MIT CSAIL，`2610.32075`。**前馈 GI**：不是"把缓存介质换成网络"（NRC 那条路），而是**直接把整个传输的解一次前向算出来**。

核心手法三件套：
1. **物体化**：每物体采 2048 点 → PointNet++ 集合抽象 → 32 个质心 + 128 近邻 = 32 个 surface-patch token。传输序列长度从三角形数 $T$ 变成 $32N$；
2. **不变形式因子注意力**：把 4 维几何不变量 $G_{ij}=(-\|Δ\|^2,\ m_i^\top Δ,\ -m_j^\top Δ,\ m_i^\top m_j)$ **因子化成 query-key 内积**——不物化 $O(N^2)$ 的 bias 矩阵，就能让注意力"知道几何"；
3. **免网格 G-buffer**：point-splat 7×7 膨胀渲染 + 物体 id routing bias，不需要光栅化三角形。

**数字**：205.9 M 参数；**32.22 dB per-image / 27.65 dB pooled**（RenderFormer 28.95/25.80、RenderFormer-V2 24.60/23.05）；500 物体 512² **0.83 s**（比 FlashAttention RenderFormer 快 8.5×、比 SDPA 快 22.2×）；交叉点 25 物体（开 FlashAttention 35）。

**最值钱的一张消融表**（也是今日主线的证据）：

| 消融 | ΔPSNR |
|---|---|
| 去掉 form-factor | −0.52 dB |
| 去掉物体间注意力 | −2.46 dB |
| 去掉 rasterizer 通道 | −3.12 dB |
| 只给 G-buffer、不给 3D token | **−5.66 dB** |
| **token 预算 M ∈ {8,16,32,64}** | **≤0.04 dB** |

**最后两行是同一句话的两面**：三维 token 本身不可替代（−5.66），但 token **给多少**几乎无关（0.04）。而**换单位**（三角形 → 物体）值 3.3 dB。**换单位比调额度高两个数量级**——这就是 [[Budget Units]] 的第一条判据的来源。

**诚实边界**：0.83 s/帧是**研究级**，不是实时；质量评估只到 50 个实体；数据集全合成（1.03 M 场景 / 18,085 网格 / Cycles 512²·512spp），真实场景泛化未验。

![[Research/Files/Pictures/Zhang 2026 — 图1 RADIANT 架构总览.png]]
**读图**：左半是**视角无关**的场景表示（点云 → 每物体 32 token），右半才是**视角相关**的解码（G-buffer + 传输 token → DPT 上采样）。**这条切分线就是"物体化"能成立的原因**：几何只进 token 一次，之后所有视角共享。（图 1，RADIANT 2026）

### ✅ [[2026-10-26-Zhang — UniWorld A Unified World Model for Real-Time Visual World Simulation|UniWorld]]（A- 前沿）

复旦 / 中国电信 TeleAI / 吉大 / 南大，`2610.32381`。**世界模型的"薄接口"路线**：不要求世界源提供结构化状态，只要求**图像 + 图像对齐深度**——于是引擎渲染帧与真实视频在同一个接口上等价。

两个工程机制值得单记：
1. **noise-aligned overlapping continuation**：新窗口不重新起噪，而是**投影回上一条噪声轨迹**——$P_{i,t}(z)=M_i\odot[tH_i+(1-t)\varepsilon_i]+(1-M_i)\odot z$。性质：**幂等**、$t=1$ 时精确还原历史、**不需要额外模型评估**；
2. **rolling depth latent state**：`C_i = concat(C_{i-1}[a_i-a_{i-1}:L_{i-1}], ReadDepth(b_{i-1},b_i))`——深度只在窗口边界读一次，窗口内 8 次评估复用。**上界与时长无关**：`4·L_max·S·96` 字节 = 19.05 MiB @960×544 / 9.41 MiB @672×384。

**数字**：14.472 FPS @960×544、21.361 @672×384（**8×H100**，FSDP/Ulysses，8 次评估）；PSNR 13.3973 dB；VBench 80.54（H3 50 步 79.87 / LongVie2 78.54）。

**必须说清楚的一条**：**它的消融几乎全是零效应**——boundary-only 变体 +0.00637 dB，seam LPIPS 0.00195，置信区间 `[0.00033, 0.00362]` 几乎贴着零。也就是说，**"重叠续写 + 滚动深度"这套机制在它自己的实验里没有被证明必要**。真正被证明的只有两件事：① 显存上界与时长解耦（这是**结构性**的，不需要实验证明）；② 端到端能跑分钟级。**架构贡献成立、机制归因不成立**——这条区分比论文摘要重要。

![[Research/Files/Pictures/Zhang 2026 — 图2 UniWorld 统一渲染器与滚动深度状态.png]]
**读图**：上排是异构世界源（引擎 / 真实视频 / 合成）经**图像对齐深度**汇入同一个 DiT；下排是滚动状态——注意深度只在窗口接缝处更新一次（红/蓝箭头），窗口内部 8 次评估全复用旧深度。**显存上界与时长无关，靠的就是这条"只在接缝读"**。（图 2，UniWorld 2026）

### ✅ [[2026-10-26-Liu — PASPA Past as State Present as Attention|PASPA]]（A- 前沿，NeurIPS 2026）

同济 / 东大 / 阿里，`2610.32373`。**长时程共同言语动作生成**：过去压成**定长状态**（块级 Gated DeltaNet，BGDN），当下用**块内注意力**（BMHSA）。

**它给出的最有价值的东西不是方法，是一条实测论证**：拿 BEAT2 做自相关分析——**风格特征超过 100 帧仍然相关**（必须记住），**局部运动特征不到 20 帧就衰减**（不必记住）。**一条序列里同时存在两个时间尺度差 5 倍以上的量，统一上下文窗口对前者不够长、对后者纯浪费。** 这就是 [[Motion Tokenization]] 的判据来源：**token 化的单位必须匹配你要记住的那个时间尺度**。

**消融表里有一行应该被所有做记忆机制的人抄下来**：

| 变体 | FGD（越低越好） |
|---|---|
| 完全不给历史 | 7.065 |
| 短种子 + 8 帧注意力 | 6.051 |
| 全历史 + 全注意力 | 5.710 |
| **State + State（历史进状态，当下也从状态读）** | **7.652** |
| State + Attn（本方法） | **5.216** |

**"State + State 比完全不给历史还差"**——历史给错方式，是**负收益**，不是零收益。这条比"我们的方法更好"有用得多。

**长时程**：10 s 输入下终端窗口 FGD `[0,10]` 4.448 / `[20,30]` 5.119 / `[50,60]` 5.745（三档对比方法同步退化更快）；延迟 120 s = 11.4 s、300 s = 28.6 s、600 s = 56.0 s，**成本回到线性**；峰值显存 0.36–0.48 GB。**产物是离线烘焙可用（120 s 动作 11 秒推理），不是运行时。**

![[Research/Files/Pictures/Liu 2026 — 图3 风格特征与局部运动特征的自相关.png]]
**读图**：两条曲线的衰减速度差一个数量级——风格（蓝）在 100 帧处仍在高位，局部运动（红）20 帧内掉平。**"历史要不要全记"这个问题没有统一答案，取决于你要记的是哪条曲线**。（图 3，PASPA 2026）

### ✅ 经典 [[Reyes — The Reyes Image Rendering Architecture (1987)|Reyes 1987]]（A 经典·历史重要性 5）

Cook / Carpenter / Catmull，SIGGRAPH 1987。**这不是某个效果的论文，是"整条管线怎么排"的论文**——八条设计原则（自然坐标 / 向量化 / 统一表示 / 局部性 / **线性** / 大模型无上限 / 后门 / 纹理）+ 八阶段管线（bound → cull → split → dice → shade → break → sample-visibility → filter）。

**它换的单位**：着色的对象不是三角形，是**微多边形**——平面着色四边形、边长**约半个像素**（Nyquist 极限）。于是着色率与几何复杂度**解耦**（这正是今天 Nanite / 虚拟几何的同一条判据，早了 36 年）。

**它买的统一性**：16 子像素 jitter 一套采样点同时解决抗锯齿、运动模糊、景深——三个问题一个机制。ε 平面让 hither 裁剪与逆透视都不需要。

**它卖的代价**：**先着色、后判可见** ⇒ **结构性 overdraw**。用原文的 1986 圣诞卡数字反推：1024×614（63 万像素）渲了 **6.8 M 微多边形** ≈ 10.8 个/像素；半像素边长的微多边形铺满一屏只需 ~4 个 ⇒ **约 2.7× 的结构性 overdraw**（⚠️ **这是我用原文数字反推的，不是原文结论**）。这条权衡在 30 年后被 visibility buffer 反向解掉——**同一个决定，1987 年是"买了统一性"，2010s 是"卖掉了灵活性"**。

## Technology Evolution

```text
"用什么单位给画面记账"
1978  三角形 / 图元：阴影贴图按分辨率付费，与场景复杂度解耦
1983  一个点：粒子成本随数量线性
1987  ★ 屏幕采样格：微多边形 ≈ 半像素边长——**着色率第一次与几何解耦**
1990s 像素：fill rate 是显卡规格表第一行
2000s 每片元算法（可编程着色）→ 每像素一次（deferred）
2019  探针：DDGI 用"每帧 m×n 射线"给间接光定价
2021  缓存条目：NRC 把辐照度缓存的介质换成网络，单位没变
2026  ★ 物体：RADIANT 把传输序列从三角形压到 32N（**单位换了，复杂度就换了**）
2026  ★ 窗口：UniWorld 把状态单位从帧数换成窗口（**上界与时长解耦**）
2026  ★ 定长状态：PASPA 把历史单位从 token 换成状态（**历史长度不再进上下文**）
```

**一条主线**：**每一代真正跳级的进展，都是换了记账单位；每一次"参数调优"都只是在同一单位里挪额度**。1987 换单位买的是统一性，2026 换单位买的是复杂度——**同一条动作，两次都值一篇论文**。

## Important Relationships

- **[[Budget Units]] ↔ [[Overdraw]]**：Overdraw 页最后一句"计价单位一直在换"（像素吞吐 → 每片元算法 → 写入次数 → tile 容量 → 层数）是同一命题的渲染侧表述；Budget Units 把它抬到了元层——**"金额"和"单位"是两个不同的旋钮，而大多数人只拧前者**；
- **[[2026-10-26-Liu — PASPA Past as State Present as Attention|PASPA]] ↔ [[Motion Tokenization]]**：PASPA 是"**用错单位**"的第一个可量化反例（State+State 7.652 > 无历史 7.065）。这条关系的价值在于它可证伪：**如果 token 化单位选对了，多给历史就一定不该变差**；
- **[[Reyes — The Reyes Image Rendering Architecture (1987)|Reyes 1987]] ↔ [[Harris — Fast Fluid Dynamics Simulation on the GPU (2004)|Harris 2004]]**：两篇都是"架构/翻译"型经典，都不靠新算法。区别是 Reyes 换的是**记账单位**（几何 → 屏幕格），Harris 换的是**执行单元**（CPU → 片元管线）。**本库现在有了这两类"非算法型经典"的对照样本**；
- **[[2026-10-26-Zhang — RADIANT Object-Centric Feed-Forward Global Illumination|RADIANT]] ↔ [[Neural Global Illumination]]**：把"神经 GI"从一条线拆成两条（拟合派 / 前馈派），分界线是"要不要在目标场景上训练"。**判据一句话：这个网络见过我没见过的场景吗**；
- **[[2026-10-26-Zhang — UniWorld A Unified World Model for Real-Time Visual World Simulation|UniWorld]] ↔ [[World Models for Games|Matrix-Game 4.0]]**：接口厚度轴的两端——MG4.0 吃 low-poly 白模（厚、快、窄），UniWorld 只吃图像 + 深度（薄、通用、贵）。**AnyGameRenderer 在更外面（纯视频 + 字幕）**，三点连成一条完整的旋钮。

## Emerging Trends

- **"换单位"正在成为 2026 下半年的一条暗线**：今日四篇里三篇的贡献本质都是换单位，而且都**不是**靠更大的模型/更多的算力。**这条暗线值得单独跟踪**——它意味着下一波进展可能来自"重新定义记账对象"，而不是"再堆一层"；
- **"消融几乎全零"正在变成一种诚实标注**：UniWorld 的消融区间几乎全跨零，作者照实报了。**这比"消融全都有效"更可信**——它说明架构成立但机制归因未达显著。**读论文时应该先看消融的置信区间，再看点估计**；
- **长时程的共同解法在收敛**：PASPA（定长状态）与 UniWorld（滚动窗口状态）虽在不同模态，结构上做的是同一件事——**把"随时间增长的东西"换成"常数大小的东西"**。这与 WorldCrafter 的"记忆即预算"是同一族。

## Key Takeaways

**1. 换单位比调额度高两个数量级——今天第一次有了量化证据。** RADIANT 把传输单位从三角形换成物体，值 **+3.3 dB**；而在同一单位内把 token 预算从 8 调到 64，值 **≤0.04 dB**。**这条判据可以直接搬进预算评审**：如果一个额度砍一半只损失一点质量，说明它本来就在冗余区——**你该换的是单位，不是数值**。

**2. 历史给错方式，是负收益，不是零收益。** PASPA 的 State+State 变体（7.652）比**完全不给历史**（7.065）还差。**这条比任何"我们的方法更好"都更有用**：它给出了记忆机制的一条硬边界——**状态里必须留有"当下要用"的信息，否则历史就是噪声**。

**3. 架构贡献成立，不等于机制归因成立。** UniWorld 的消融几乎全是零效应（区间跨零、点估计 0.006 dB），但显存上界与时长解耦是**结构性事实**、不需要实验证明。**读论文要分开问：这个架构能不能跑？它声称起作用的那个部件，真的起作用了吗？**

**4. 1987 年的 Reyes 与 2010s 的 visibility buffer 是同一场战争的两端。** 同样是"着色与可见性谁先"，1987 年选"先着色"买到了**统一性**（一套采样点解决抗锯齿/运动模糊/景深），2010s 选"先可见"买到了**便宜**。**同一个决定在不同约束下是相反的正确答案**——这正是"成本模型必须随硬件改"的最好例证。

**5. 选材的第二判据：证据形态要先说清楚。** Reyes 全文六条路全断，最后用 ResearchGate 的作者上传 OCR 稿重建，**放弃引用任何图号、本页不出图**。Harris 2004 是书章不是同行评审、定量只有两个且无基线——**这些都在笔记顶部写明**。**证据形态的诚实度，决定了这篇笔记三年后还能不能被信任。**
