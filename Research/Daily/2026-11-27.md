# Game Development Research — 2026-11-27

> **今日主题：你选的参数化，决定了哪些错误藏得住。**
> 三篇论文、十四年、三个领域，同一个动作：**先看这组参数允许什么，再看算法能做什么。**
> ReMeDi（2026）把 base color 与 metalness 拆成两个回归通道，于是**两个通道的误差可以互相抵消**——单通道 RMSE 全部"中等好"，重光照时全崩。
> MEMO（2026）把高斯的时间支撑设成"相邻几帧"，于是**高斯不再有资格当表面元**——想要表面，只能回去做 TSDF 融合。
> Burley（2012）把十个旋钮归一到 0–1，于是**mask 被纹理过滤插出的中间值也必须合法**——*"the mask will be filtered and at the blurred edge of the mask the material response must remain plausible"*。
> **参数化不是一层皮，它是问题的定义域。**

## Frontier Research

### [[2026-11-27-Fei — ReMeDi Single-Image PBR Material Estimation via Reparameterization|ReMeDi 2026 — 一张 base color 不是自描述的]]

**Why this matters**：单图 PBR 材质估计做了快十年，指标一直在涨，但**没有人问过"逐通道指标能不能判对错"**。ReMeDi 的回答是不能——而且是结构性的不能。

原因是 [[Metallic-Roughness Workflow|MR 工作流]] 里一个被当作工程细节的事实：**$C$ 与 $M$ 通过 $C=\mathrm{lerp}(C_d,C_m;M)$ 耦合**。同一张贴图，$M=0$ 时它是漫反射反照率，$M=1$ 时它是镜面反照率。网络把两者当独立目标回归，就能给出"base color 误差小、metalness 误差中等"的解，而这两个误差**方向相反、在图像上互相抵消**——训练集上看起来最干净，重光照时才暴露。

作者给这个隐式决定起了名字：**intended metalness $\mu_X$**——"这张贴图的作者想用它描述的那个材质的 metalness"。$\mu_C\neq M$ 的两种后果，一句话就能记住：**太暗**（漫反射图层被当金属渲染，反射只剩 0.5 左右），或者**太亮且平**（金属 albedo 被当漫反射，再叠一个 4% 白高光）。

**做法不改 backbone，改参数化**：

> 不要问"这张 $C$ 对不对"，改成问"**哪两个完整假设，按什么比例混出这张 $C$**"。

把 $C$ 重参数化成 $C=\mathrm{lerp}(C_d,C_m;M)$，$R$ 同构；$C_d$ 是**全介电假设下的漫反射反照率**、$C_m$ 是**全金属假设下的镜面反照率**（注意 **$C_d\neq D$、$C_m\neq S$**，这是重参数化而非换工作流）。然后把三个量交给**三个网络**，共享一个冻结的 DiT 骨干、各挂一个 rank-64 LoRA：$\mathcal G^d$、$\mathcal G^m$、$\mathcal G^M$（后者加二值化惩罚 $\mathcal L_{bin}$）。

**为什么必须三个网络——这是全篇最该抄的一段**：单网络会走捷径，让两个变体都输出真实的 $C$，于是 lerp 退化成恒等，重参数化白做。**消融把这件事量了出来**（Table 4，重光照 PSNR）：

| 变体 | 全图 | **金属区域** |
|---|---|---|
| (A) 单网络 | 19.98 | 17.07 |
| (B) 单网络 + 假设专属监督 | 20.10 | 17.81 |
| (C) 两网络（$d$+$M$） | **19.37** | 17.37 |
| (D) **三网络（ReMeDi）** | **20.24** | **18.40** |

**(C) 比 (B) 还差、比 (A) 只差不好**——这一行比 (D) 更有信息量：**重参数化的收益不在"多一个分支"，在"两端都完整"**。少一个假设，那个假设对应的区域就没有人负责。

**结果**（SYNTEST，365 个 Objaverse-XL 资产，最强基线 SuperMat）：base color PSNR **21.33**（18.47，**+2.86 dB**）；重光照 **22.34**（19.60，**+2.74 dB**）；metalness RMSE **0.197**（0.266，**−25.9%**）。

**三处不能漏的冷水**：① **"一致性 ≠ 正确性"**——$C$ 的 intended metalness 按构造等于 $M$，但这只保证自洽，不保证 $M$ 本身对；② **Table 3 与 Table 4 的设置不同，两表数字不可相减**（作者没提醒，是自己看出来的）；③ 训练用 24×H20、95K 资产、1024²、30K 步，推理单卡约 **60 s/图**——离"扫描进引擎"还差一个数量级，而它没有开源权重。

**Personal Relevance**：这是"**多通道输出必须先查通道间有没有一致性约束**"最干净的一次示范。任何"我同时预测 A 和 B"的系统——法线 + 高度、albedo + AO、位置 + 朝向、骨骼 + 蒙皮权重——都在这道题上。**逐通道指标在耦合存在时会系统性放过联合错误，而且放过得最彻底的那一版，看起来最漂亮。**

### [[2026-11-27-Or-El — MEMO A Mesh for Every Moment|MEMO 2026 — 每一个高斯的寿命，决定了它能不能当表面]]

**Why this matters**：动态 3DGS 只优化外观。要几何，标准做法是渲深度 → TSDF 融合 → marching cubes——固定网格、浮空块、又噪又破。做"动态表面"的方法则几乎都要求前景 mask + 单个物体，真实场景跑不了（DG-Mesh 在 Table 1 里真实场景那两格直接是"—"）。

MEMO 的判断是：**问题不在提取器，在表示。** 它给每个高斯挂 $M$ 个**覆盖整条时间轴的时间高斯核**：

$$k_{i,m}(t)=\exp\!\Big(-\frac{(t-\tau_{i,m})^2}{2\ell_i^2}\Big),\qquad p_i(t)=\frac{\sum_m w_{i,m}k_{i,m}(t)\,\mu_{i,m}}{\sum_m w_{i,m}k_{i,m}(t)}$$

三个设计细节都不是随手写的：inducing time $\tau$ 用 sigmoid 约束到**等宽格子**（不许自由漂浮，否则核会叠在一起退化成单个）；$\ell$ 初始化为**格宽**；**两端各加 $B=2$ 个中心在时间范围之外的核**。

**因果链是本篇的全部价值，值得完整抄下来**：

```text
高斯的时间支撑短（只覆盖相邻几帧）
        ↓
每个时刻的高斯是独立快照 ⇒ 不透明度只能"开 / 关"
        ↓
高斯不再是一个表面元，只是一个时刻的样品
        ↓
"表面"只能靠跨帧融合（TSDF / Poisson）得到
        ↓
融合窗口内的任意时刻，表面没有定义
```

**反过来说：想让"每一帧都有一张网格"，必须先在表示层让每个高斯在时间上连续存在。** 这不是提取器的胜利——同一份 pivots 换提取器（原配 → TSDF），Chamfer 反而从 0.51 降到 0.50，但法向从 24.6° 掉到 29.1°、F-score 从 0.556 掉到 0.468。**CD 不罚表面噪声，这条本库在 11-17 已经付过一次学费。**

**结果**（Blender-Moments，9 个有逐帧 GT 网格的场景）：Chamfer **0.51**、法向 **24.6°**、F-score **0.556 / 0.746**，全项第一；训练 **18 min**，同为几何方法的 DG-Mesh 要 **142 min**。

**消融表是一张"价格表"**（合成场景）：

| 变体 | PSNR | FS | FR | 真实 PSNR |
|---|---|---|---|---|
| 去掉轨迹拟合 | 26.88 | 0.295 | 0.436 | **28.98** |
| 核数减半 | 32.97 | 0.470 | 0.691 | 29.32 |
| 去掉界外核 | 33.85 | 0.497 | 0.716 | 29.34 |
| **MEMO** | **34.84** | **0.515** | **0.745** | **29.40** |

**看第一行**：去掉轨迹拟合只掉 **0.42 dB**（真实场景 29.40 → 28.98），因为静态背景占了 PSNR 的分母。而作者写得明白——*the real scenes lose their fast-moving parts*。

> **0.42 dB 的代价，是"运动的部分整个消失"。** 两个 F-score 从 0.745 / 0.515 掉到 0.436 / 0.295。

这是本库**第三次**遇到同一形状（DeepMimic 的 0.730 分不会后空翻、SplatTok 的逐图元 PSNR）。现在可以把它写成一条通用判据：**目标只占画面一小块时，PSNR 不是尺子。**

**还有一条方法学收获**：核权重对轨迹是**线性**的，所以轨迹拟合是一个 GP 回归，**能闭式初始化**——$\tau,\ell,w$ 不是训出来的，是解出来的。点轨关联用 Kalman 滤波 + Mahalanobis 门。**与 AbacusGS 的"顺序搬进资产"同构：能离线算的，别放进训练循环。**

**冷水**：① **逐帧网格没有时间一致性**（作者明写）——第 $t$ 帧与第 $t+1$ 帧的顶点可以任意重排，能渲染、能算距离，但**不能直接进蒙皮 / 碰撞 / 动画重定向**；② 多机位同步采集 + 18 min/场景，仍是离线管线；③ 界外核去掉只掉 0.06 dB（真实场景）——**yet 它是"每帧都有表面"在首尾两帧成立的前提**。

**Personal Relevance**：**"什么时候能提取"是表示层的性质，不是提取算法的性质。** 这条可以直接搬到引擎里：如果你的破坏系统每帧都要出网格，那决定手感的不是你的 marching cubes 写得多快，而是**你的体素/元素在时间上连续不连续**。

## Classical Research

### [[Burley 2012 — Physically Based Shading at Disney|Burley 2012 — 五个原则里，只有两个是数学]]

**Historical Role**：这是 [[Physically Based Rendering]] 谱系里**唯一还断着的一环**。库里的 `Physically Based Rendering` 页写着"Disney Principled BRDF（2012，原则化参数化）"，而它下游的 [[Karis — Real Shading in Unreal Engine 4 (2013)]] 早就是链接、早读过——**上游缺失了一年多**。

它做的事一句话说完：**不新增任何物理，只回答"给美术几个旋钮，才能让他在不越界的前提下把这堆 BRDF 调到想要的样子"。**

> 原话：*"we want a model that is **plausible** for all combinations of parameters"*——不是"每个参数都对"，是"**所有组合都可信**"。

**十个标量，全是 0–1**：baseColor / metallic / subsurface / specular / roughness / specularTint / anisotropic / sheen / sheenTint / clearcoat / clearcoatGloss。**metallic 的定义是全篇的枢纽**：

> *"metallic is a blend between a pure dielectric and a pure conductor"*——$C=\mathrm{lerp}(C_d,C_m;M)$，$F_0=\mathrm{lerp}(0.04,\,C;M)$。

**这不是"金属度这个材料属性"，这是一个插值权重。** 这句话在 2012 年是设计选择，在 2026 年被 ReMeDi 变成了架构约束——**同一个 lerp，十四年后成了重参数化的骨架。**

**三个约定的出处（本库此前只有 Karis 的二手版本）**：

| 约定 | Burley 的原始理由 |
|---|---|
| $F_0\in[0,0.08]$ | 0.04 是 specular 参数 $[0,0.08]$ 的**中点**，而 0.04 恰好就是 IOR 1.5 的精确 Fresnel 值 $\big(\frac{n-1}{n+1}\big)^2=0.04$——**两个来源撞在同一个数上，所以它成了默认值** |
| $\alpha=r^2$ | 让粗糙度在**感知上**均匀（GGX 的 $\alpha$ 均匀时看起来全挤在光滑端） |
| 金属的 $F_0$ = base color | 金属没有漫反射，base color 就是镜面反射率 |

**三处感知重映射**（§5 全部内容就是这三行）：specular → $F_0\in[0,0.08]$；roughness → $\alpha=r^2$（镜面）；clearcoat → $\alpha_g=(0.5+r/2)^2$（**注意它连方向都和别的不一样：粗糙度越高，清漆越锐**）。

**GTR 分布族**是它真正的技术贡献：

$$D_{\rm GTR}=\frac{c}{\big(\alpha^2\cos^2\theta_h+\sin^2\theta_h\big)^\gamma}$$

$\gamma=2$ 是 GGX / TR，$\gamma=1$ 是 Berry，$\gamma=3/2$ **恰好等于 HG 分布在 $2\theta_h$ 上的形式**。**一个参数 $\gamma$ 把三个历史上互不相干的分布连成一条线**——这是"参数化"这个词在本篇最字面的用法。

**漫反射侧那个反直觉的修正**：$F_{D90}=0.5+2r\cos^2\theta_d$。光滑表面掠射处**减半**（回溯反射被遮住），粗糙表面**涨到 2.5 倍**（多次弹射把能量还回来）。**方向与直觉相反，因为直观上"粗糙 = 少反射"。**

**冷水七条，最硬的三条**：① 这是**课程讲义不是论文**，没有定量误差表，说服力全部来自 MERL 100 的定性对照；② $\gamma$ 是"手选的"，没有拟合流程——**所以 GTR 不是一个可学习的分布族，是一个可调的**；③ **各向同性**，各向异性只做了很小的补充；清漆层不扣能量（与 Kulla-Conty 那条线至今没接上）。

**但最该记的是 §5.7 那句话**，它把今天两篇前沿连起来了：

> *"the mask will be filtered and at the blurred edge of the mask the material response must remain plausible"*

**纹理过滤会把 mask 插出中间值，所以中间值必须合法。** 这就是"处处合法"这条原则的**物理来源**——不是你选 0–1 好看，是**你的参数会被硬件插值**。

**Knowledge Graph Role**：补齐了 PBR 谱系的**参数化侧**。`Physically Based Rendering` 页至此四侧齐备：来源侧（D·G·F 的物理出处，2026-09-17）→ 工程侧（进引擎 + IBL 查表，2026-09-18）→ 能量侧（多次散射，镜面 2026-09-19 / 漫反射 2026-10-05）→ **参数化侧（2026-11-27）**。新建的 [[Metallic-Roughness Workflow]] 是这一侧的独立成页。

## Personal Learning Focus

### Normal → Easy

- [[Metallic-Roughness Workflow]] —— **目标：看到任何一张"base color"贴图，能立刻问出它的 intended metalness 是多少。** 三个必答：这张图是"以介质身份"画的还是"以金属身份"画的？它现在被哪个 $M$ 渲染？两者的差会造成偏暗还是偏亮？**这三个问题答得出来，这个工作流才算会了。**
- [[Burley 2012 — Physically Based Shading at Disney|Burley 2012]] 的 §5 三行重映射 —— **30 分钟的纸面实验**：把同一个 $r=0.5$ 分别代进 $\alpha=r^2$、$\alpha=r$、$\alpha=r^4$，各画一条 GGX 的 $D(\theta_h)$ 曲线，看"感知均匀"到底长什么样。**手画一次比读三页公式有用。**
- **"0.04"这个数** —— 记住它有**两个来源**（参数区间中点 + IOR 1.5 的精确 Fresnel），这解释了为什么它能活十四年：**它不是被选的，是被撞上的。**

### Hard → Normal Bridge

- **"中间值合法"为什么要求"两端各自完整"** —— 这是今天留下的最大问号。Burley 只说"中间必须 plausible"，ReMeDi 说"所以两端必须各自是完整材质"，但**中间的数学联系没写**。桥：把 lerp 看成凸组合，问"凸组合的两端如果各自都不合法（比如 $C_d$ 本身是个灰块），中间有可能合法吗"。若答案是否，那"两端完整"就是"处处合法"的**充分必要条件**，而不是一种实现选择。
- **GP 闭式初始化为什么够，以及 Kalman + Mahalanobis 门在补什么** —— MEMO 的核权重对轨迹线性 ⇒ 最小二乘即可；那为什么还需要滤波与门控？桥：先分清"**模型误差**"（核模型表达不了这个运动）与"**关联误差**"（这个点轨根本不属于这个 pivot）。**闭式解只能处理前者，门控处理后者。**
- **逐通道指标失效的四种形状** —— 本库现在有四个实例（DeepMimic 的奖励累积、SplatTok 的逐图元 PSNR、MEMO 的全图 PSNR、ReMeDi 的逐通道 RMSE）。桥：把它们排成一张表，问"**目标集合与度量集合的差集**长什么样"。**四次的差集分别是：技能存在性、场景相似度、运动部分、通道耦合。** 这个分类很可能就是完整的。

## Technology Evolution

**参数化这条线，四十五年只做了一件事：把"物理量"换成"美术能调的 0–1"。**

```
1981  Cook-Torrance    参数 = 物理量（粗糙度、折射率、F0）——可测，但不可调
        └ 问题：美术不知道 0.35 的粗糙度长什么样，也无法判断"调过头了没有"

1994  Schlick          F 的 5 次方近似（把一个积分换成一行）—— 但没解决"调"的问题

2012  Burley ★         参数 = 10 个 0–1 旋钮 + 五条"处处合法"原则
        └ 关键：metallic 从"材料属性"降级成"插值权重"（lerp 的 t）

2013  Karis           参数 = 3 个（BaseColor / Metallic / Roughness）+ 贴图通道
        └ 关键：从"手调 10 个"变成"画 3 张图"——参数化进了纹理管线

2015  glTF / USD      参数 = 交换格式 —— 跨工具、跨引擎的公共契约
        └ 关键：参数化一旦成为格式，就再也改不动了（这是它最大的优点也是最大的债）

2026  ReMeDi ★        参数 = 两个完整假设 + 一个覆盖率（$C_d,C_m,M$）
        └ 关键：参数化从"正向怎么喂"变成"逆向怎么解"——同一组数，两个方向

2026  MEMO ★          另一条轴：几何元素在时间轴上的参数化（核的中心与宽度）
        └ 关键：支撑长度 = 元素的寿命 = 它能不能当表面
```

**两条轴在 2026 年撞上了同一句话：参数化的覆盖范围，就是算法的可行域。**

而**指标侧是同一个动作换了个对象**：

```
2018  DeepMimic       量奖励累积         → 0.730 分的策略不会后空翻
2026  SplatTok        量逐图元 PSNR      → 码长被图元数锁死在 10-30×
2026  MEMO            量全图 PSNR        → 运动部分消失只掉 0.42 dB
2026  ReMeDi          量逐通道 RMSE      → 两个通道的误差互相抵消
```

**四次误测，同一条判据：度量集合必须包含目标集合。** 而每次的修法都不是"换一个更好的指标"，是**换一个度量对象**——换到"技能存在性 / 场景相似度 / 运动部分 / 通道联合"上。

## Important Relationships

- [[Metallic-Roughness Workflow]] ←→ [[Physically Based Rendering]]：**同一个知识体的两个切面**。PBR 页回答"用哪个 BRDF"，MR 页回答"用哪几个数喂它、这几个数在通道里各是什么含义"。**新增的第四侧"参数化侧"就是这个箭头。**
- [[Metallic-Roughness Workflow]] ←→ [[Inverse Rendering]]：**正向的耦合变成逆向的耦合**。正向里 $C=\mathrm{lerp}(C_d,C_m;M)$ 是一个省事的写法；逆向里它意味着**未知量之间不能独立反解**——ReMeDi 的整个架构都是在还这笔债。
- [[2026-11-27-Fei — ReMeDi Single-Image PBR Material Estimation via Reparameterization|ReMeDi]] ←→ [[Burley 2012 — Physically Based Shading at Disney|Burley 2012]]：**隔了十四年、同一句问题的两面**。Burley 在正向侧说"mask 插出的中间值必须合法"；ReMeDi 在逆向侧说"所以两端必须各自完整"。**一个给了约束，一个给了它成立的唯一方式。**
- [[2026-11-27-Or-El — MEMO A Mesh for Every Moment|MEMO]] ←→ [[Isosurface Extraction]]：**"密度从哪来"的第五个答案——密度来自表示本身。** 此前四个答案（均匀 / 曲率 / lfs / 误差驱动）都假定"场是给定的，采样点要另挑"；MEMO 让 pivots 的位置同时是采样位置。**代价：失去输出敏感的自由。**
- [[2026-11-27-Or-El — MEMO A Mesh for Every Moment|MEMO]] ←→ [[Gaussian Splatting]]：GS 页今天开第五条线（动态 / 时间参数化）。此前四条线（排序 / 训练成本 / 压缩 / 网格化）**全部把场景当静止的**——这一条补上，而且它第一次出现"表示层的选择直接决定下游算法可行性"。
- [[2026-11-27-Fei — ReMeDi Single-Image PBR Material Estimation via Reparameterization|ReMeDi]] ←→ [[Amortization Gap]]：**"补丁必须能被关掉"的镜像版**。MESSI 靠"门关着时 $z_t=0$"证明零回归；ReMeDi 靠"三个网络各自完整"证明**没有一个能走捷径**。**两篇都在处理"共享结构会不会被滥用"，一个用开关，一个用分工。**
- [[Burley 2012 — Physically Based Shading at Disney|Burley 2012]] ←→ [[Karis — Real Shading in Unreal Engine 4 (2013)]]：**上游与下游，格式一致**。Karis 保留了三处重映射与 0.04，删掉了 7 个旋钮、换了三个廉价形式（Schlick F / GGX D / Smith G）。**"进引擎"这个动作的本质是"删参数"，而不是"改物理"。**

## Emerging Trends

1. **"参数化"正在成为论文的核心论点，而不只是实现细节。** ReMeDi 不改 backbone、不改损失族、不改数据，只改 $C$ 被摆成的形状；MEMO 不改提取器、不改渲染器，只改每个元素在时间轴上的支撑。**两篇的说服力都来自"换一个摆放方式，同一套零件就通了"。**
2. **"合成验证会把输入排错序"开始被当成一等公民写进摘要。** PhysReader（今日未选，B++）的发现是：在仿真里最好的几何输入（3D tracklets）在真实视频上**最差**，而仿真里毫无用处的 2D 光流在真实上**最好**——而且**给更好的深度也修不好**。这不是 domain gap 的常见版本（"sim 好 real 差"），是**排序反转**。**"哪个输入更好"这个问题，不能在被控域里回答。**
3. **中间值合法性正在从"着色问题"变成"架构问题"。** Burley 2012 只能在文档里写一句"必须 plausible"；ReMeDi 2026 用三个网络把这件事**构造进架构**。**同一个要求，从"约定"升级成"结构"——这是十四年里真正的进展。**
4. **"每通道一个指标"这套评测范式正在被拆。** 今天的四次误测（奖励 / 图元 PSNR / 全图 PSNR / 通道 RMSE）有一个共同点：**它们都是"把多目标压成单目标"的便利做法**。2026 年的论文开始给联合指标（ReMeDi 的金属区域单列、MEMO 的 F-score + 法向）。
5. **时间维终于有了"参数化"这个视角。** 以前动态重建的讨论是"用变形场还是轨迹"，现在可以问"**你的元素在时间上占多长**"——而这个问题直接决定了"能不能逐帧出网格"。**时间支撑长度是一个可以画在轴上的量。**

## Key Takeaways

1. **参数化的耦合，会变成算法的耦合。** ReMeDi 的 $C=\mathrm{lerp}(C_d,C_m;M)$ 在正向是一个省事的写法，在逆向意味着**这两个未知量不能独立反解**。**你今天为了"好调"付出的每一步简化，明天都会以"不可解"的形式回来。**
2. **逐通道指标在存在耦合时，会系统性放过联合错误——而且放过得最彻底的那一版看起来最漂亮。** 本库至今四个实例：奖励累积、逐图元 PSNR、全图 PSNR、逐通道 RMSE。**判据一句话：度量集合必须包含目标集合。**
3. **"中间值合法"要求"两端各自完整"，而不是"加权平均后像"。** Burley 只能写进文档（2012），ReMeDi 把它构造进架构（2026）。**从"约定"升级到"结构"，是这十四年真正的进展。**
4. **一个元素的参数化覆盖范围 = 它能承担的角色。** 高斯的时间支撑短 ⇒ 它只是"一个时刻的样品" ⇒ 表面只能靠融合 ⇒ 融合窗口内表面没有定义。**"能不能逐帧出网格"这个问题，答案在表示层，不在提取器里。**
5. **"什么时候能提取"和"提取得多准"是两件事。** MEMO 换提取器（→TSDF）CD 反而更好（0.51 → 0.50），但法向与 F-score 都掉——**因为 CD 不罚表面噪声**。评价一个几何管线，**至少要有位置 + 法向 + 联合 F-score 三栏**。
6. **"合成验证会把输入排错序"——这是 sim-to-real 里最难修的一类错。** 不是"sim 好 real 差"（可以靠域随机化缓解），是**排序反转**（你按错误的重要性做了正确的工程）。**"哪个输入更好"不能在被控域里回答。**
7. **0.42 dB 可以买走整个运动部分。** MEMO 去掉轨迹拟合只掉 0.42 dB（真实场景），而所有快速运动的部分消失。**当一个指标的分母大部分是"容易的部分"时，它对"难的部分"完全没有分辨率。**
8. **能离线算的，别放进训练循环。** MEMO 的核参数是 GP 回归闭式解出来的，不是训出来的；AbacusGS 把逐 splat 排序搬进了资产。**两条线在 2026 年撞上同一句话：先把能解的解开，剩下的才训。**
