> **🔴 对你的五档画质框架的直接含义（今天最该带走的一条产业判断）**：
>
> **画质档位正在从"性能阶梯"变成"渲染管线切换"。**
>
> 传统分档的隐含假设是"档位 = 在同一管线上降分辨率 / 降效果 / 降频率"。
> 但当一个作品**把 PT + GI 做成所有光追档位的公共底座**时，**中间档就消失了** —— 玩家面对的不再是"高/中/低"，而是**"进不进 PT 管线"的二值选择**，以及**"用多激进的升频把它拉回来"**。
>
> **这不是一家公司的选择**：同期 TweakTown 的评论也把结论写成了同一件事 —— **升频技术已经从"可选的性能加成"变成了"基线优化工具"**（"baseline optimisation tools rather than optional performance boosters"）。
>
> **对你的具体影响**：做 S/A/B/C × 五档的预算矩阵时，**"每个档位是一套独立的资源上限"这个前提需要重新审视** —— 至少要为"管线切换型"的差异留一列（哪一档换管线，而不是换参数）。

### 产业信号 3：Windows Auto SR 扩到 Intel Panther Lake —— "神经层是预算项"今天多了一个新维度

微软正式把 **Windows 自动超分辨率（Auto SR）** 扩展到 **Intel Core Ultra 第 3 代（Panther Lake）**，覆盖内置 **Arc B390 / B370** 的移动平台。

**关键点（与已内置于游戏的 XeSS / DLSS / FSR 的本质区别）**：

| 维度 | Auto SR |
|---|---|
| 位置 | **操作系统层**（Windows 视频管线），**无需游戏适配**，覆盖 DX10/11/12 的成千上万款老游戏 |
| 算力来源 | **处理器内置 NPU** |
| 输入分辨率 | Panther Lake 上放宽到 **最高 1080p**（此前 Copilot+ PC 推荐约 800p） |
| 微软自测（《英灵殿》，Arc B390） | 原生 1600p High = **45 fps** → 1050p 输入 + Auto SR → 1600p **Ultra High = 52 fps**（**+15%**，且画质档位更高） |
| 微软自测（《影》） | 原生 1600p Very Low = **31 fps** → Auto SR 后可跑 **Ultra High ≈ 29 fps**（**用画质换帧率**，不是加帧率） |
| **已知代价** | ① **整张画面都被缩放 → UI 与文字会发虚**；② **NPU 与 CPU/GPU 共享整机功耗预算 → 部分轻薄本会升温 / 掉续航（个别场景小幅掉帧）**；③ 不支持 DX9 / Vulkan / OpenGL；④ 当前不支持 HDR |
| 官方建议 | 游戏自带 XeSS 等时**优先用游戏自带的**（原生时序升频能用引擎的运动矢量与子像素数据，OS 层拿不到） |

> **🔴 这条对本库"神经层 = 预算项"这条线的含义**：
> 昨天与今天前两条说的是**帧时间与功耗**（DLSS 5 吃掉 15 ms、70–130 W）。
> **Auto SR 报出的是第三个维度：整机功耗预算的重新切分** —— **NPU 的算力不是"白给的"，它和 CPU/GPU 抢同一块功耗墙。**
> 也就是说：**神经层在移动端的第一约束可能不是"算得多快"，而是"这块电池愿意分多少给 NPU"。**
> 这与你 Android_High / Android_Mid / Android_Low 三档的设计直接相关 —— **"要不要给神经层留功耗预算"会变成移动端分档的一个前置决策，而不是后期优化。**

## Classical Research（今日主体，两篇）

### [[Heitz — Multiple-Scattering Microfacet BSDFs with the Smith Model (2016)]]（S / historical_importance 5 / 原文 PDF 逐节核对）

**它是多次散射"三角形"的最后一只角，也是前三天那篇 Dupuy 2026 的十年前的对应物。**

- **核心洞见一句话**：**Smith 微面理论 = 微片（microflake）体积理论的一个特例，只是额外加了一条"强制锐利界面"的约束。**于是"光在微面间反复弹射"被翻译成"光在一团特制介质里的随机游走"。
- **算法心脏只有一行**（原文 Alg. 1）—— **"逃逸判定"与"下一层高度采样"共用同一个随机数**：

```text
if  U ≥ 1 − G1_dist(ω_r, h_r, ∞)   →  离开微表面， h = ∞
else                               →  h_{r+1} = C1^{-1}( C1(h_r) · (1−U)^{1/Λ(ω_r)} )
```

- **必须放弃常见的乘积式 G2**：随机游走要知道"光现在在哪一层高度"，所以要用**高度相关**的 $G_2$（Heitz 2014）。
- **一次漂亮的交叉验证**：从微片框架推出的可见法线分布 $D_{\omega_i}$ **与经典 VNDF（Heitz & d'Eon 2014）完全一致** —— 两条独立推导路径收敛到同一结果。
- **验证方式很硬**：与**显式随机 Beckmann 表面**的光线追踪真值逐项比对（自由程分布、出射能量、逐次弹射的 $E_r/E_t$ 都对得上）；另有 white furnace test 与一组数值单元测试（能量守恒 / 互易性 / 高度采样与掩蔽阴影的一致性）。
- **🔴 但作者自己写下了这句判词**：

> **"our model is unsuitable for real-time rendering where the shading has to be smooth with one sample per pixel."**

**这句话定义了此后所有实时方案要解决的问题。** 后面的 Kulla-Conty（放弃分布正确性）与今天第二篇（复用已有表）都是对它的直接回应。

- **成本数字（全为原文）**：电介质板 **+19%**（并达成 100% 能量守恒）· 粗糙导体 α=0.3 **+24%** · 漫反射/电介质 α=0.1/0.5/1.0 **+6% / +50% / +62%** · bottles 场景 **+87%（几乎翻倍）**。**成本随粗糙度上升 —— 与"粗糙度越高丢的能量越多"是同一件事的两面。**
- **一个标志性数字**：**双次散射在某些情况下可占总反射或透射的 20%** —— 少收的那笔钱不是零头。
- **🔴 一条今天才发现、跨领域的合流（本日最值得记的关系）**：原文把粗糙电介质 BSDF 按 **R/T 事件序列**分解（**TRT、TTR** 等 lobe）；而 [[Marschner — Light Scattering from Human Hair Fibers (2003)]] 按 **R/TT/TRT** 分解毛发散射。
  **两个完全不同的物理场景，独立收敛到"按散射事件序列分解 BSDF"。**
  → **可操作结论**：[[Hair Rendering]] 里那条"**TRT 先砍、TT 最后砍**"的分档判据，**其底层手法不是毛发专属的**。"哪个 lobe 先砍"的通用判据是**事件序列的可见性**。
- **原文对既有工作的批评也很值得单列**（判断"谁解决到哪一层"的依据）：Kelemen 2001 的多次散射 lobe **被强制成"方位角不变"，而本文的真值模拟显示这一点不准**；Jakob 2014 继承同一非物理性且实现很重。**两者的根本区别**是：**"these BRDFs are not associated with microsurface models"** —— 它们**不与任何微面模型绑定**，所以只能算"强制能量守恒的技巧"，不是模型。

### [[Fdez-Agüera — A Multiple-Scattering Microfacet Model for Real-Time Image-based Lighting (2019)]]（A / historical_importance 4 / 原文 PDF 逐节核对 + 勘误栏逐字核对）

**它是这条线上唯一一篇从一开始就冲着实时来的论文，而且答案极度便宜：**

> **"你用来算单次散射的那些预计算积分里，本来就含有模拟剩下几次弹射所需的全部信息。"**

- **全部秘密是一行加法**：`float Ess = f_ab.x + f_ab.y;` —— **Karis 那张 EnvBRDF LUT 的两个通道相加，就是单次散射的方向 albedo**。于是缺口 `Ems = 1 − Ess` **不需要任何新表**。
- **推导链（逐式核对）**：① $1=E_{ss}+E_{ms}$ → ② 二次以上散射当作漫射、用已有的 irradiance 近似 → ③ 引入 Fresnel 写成**几何级数**，并**推出 $E_{avg}=E_{ss}$** → ④ $F_{avg}=F_0+(1-F_0)/21$（Schlick 的解析红利）→ ⑤ $F_{ms}=\dfrac{(F_0f_a+f_b)F_{avg}}{1-F_{avg}(1-E_{ss})}$。
  - **第 ③ 步是全篇最漂亮的地方**：**能量逃逸比例不是常数，而是与视角相关** —— "有些方向上光需要更多次弹射才能逃出去"；
  - **论文自带完整 GLSL**（Listing 1 导体 / Listing 2 电介质）。
- **🔴 它修好了账本的另一半 —— 本库此前只记了"少了"，没记"多了"**：
  - **高粗糙度端**：补回缺失能量（表面不再发暗、颜色不再失饱和）；
  - **低粗糙度端**：把常见的 $E_d=1-F_0$ 换成 $E_d=1-(F_{ss}E_{ss}+F_{ms}E_{ms})$，**消掉掠射边缘那一圈不自然的亮边（超额能量）**。原文用参考照片对照（Fig. 7）。
  - → **实操含义：furnace test 要查两头。** 过去只查"暗"，今天起要加一条"**光滑白电介质的掠射边缘是否偏亮**"。
- **⚠️ 官方勘误（必须走修订版）** —— JCGT 论文页勘误栏原文（逐字核对）：

```
Equation 6,7,10: missing factors of 1/π in integrals.
Equation 11: missing factor of π.
Equation 15: missing dot product operator.
Listing 1,2: Constant used in computing Favg adjusted by π.
```

  **错误全在常数与因子层** —— 这类错误抄进 shader 不报错，只会慢半拍地表现成"看起来有点不对"。论文页标注 **Updated for errata: 2018-02-01**。
- **⚠️ 它的边界（必须写进任何技术文档）**：二次以上散射被假设为"均匀漫射" → **对均匀环境精确、对大面积光源（天穹）很好、对窄光源（点光 / 方向光）不成立**（原文原话）。**所以它只修 IBL，不修解析光。**
- **顺带发现第五条路线（今天意外收获）**：核对本文时从 **Filament 引擎官方 PBR 文档**取到一条**比本文更便宜**的做法 ——

$$f_r=f_{ss}+F_0\Big(\frac{1}{r}-1\Big)f_{ss},\qquad r=\int D\,V\,\langle n\!\cdot\!l\rangle\,dl=\texttt{dfg.y}$$

```glsl
vec3 energyCompensation = 1.0 + f0 * (1.0 / dfg.y - 1.0);
Fr *= energyCompensation;
```

  **连新项都不加，只有一条乘加**；Filament 把它记为 **[Lagarde18]（作者 Lagarde 与 Golubev，致谢 Emmanuel Turquin）** —— **正是 9-19 记录的那位指出 Kulla-Conty 勘误的人，同一个人两次**。
  ⚠️ **来源标注**：公式与 shader 已逐字核对；但 `[Lagarde18]` 的**原始书目条目本次未取到** → **待核实**。
  另：Filament 文档也把 [Heitz16] 明确标注为 **"not suitable for real-time rendering"** —— 与 Heitz 原文自述一致，**一次独立佐证**。

## Personal Learning Focus

### Normal → Easy（本周主攻：PBR）

**这条线今天从"三角形"变成了完整的"谱系"。** 五条路线的账本、成本与覆盖面：

| 路线 | 新增资源 | 成本 | 修正范围 | 出处 |
|---|---|---|---|---|
| ① 精确随机 | 无预计算 | 求值要随机数 → **不可实时** | **全部** | Heitz 2016 |
| ② 精确闭式 | 无 | 便宜，但**无 roughness 参数** | 全部散射阶 | Dupuy 2026 |
| ③ 查表 lobe | 新增 ≈4KB 表 | 多次采样 + 一个 lobe | **任意 BRDF、任意光源** | Kulla-Conty 2017 |
| ④ 复用 LUT | **零** | 几次标量 + 复用 irradiance | ⚠️ **只 IBL**；两端同修 | **Fdez-Agüera 2019（今日入库）** |
| ⑤ 缩放 lobe | **零** | **一条乘加** | ⚠️ 只 IBL；只补高粗糙端 | Lagarde/Turquin（Filament） |

- **🔴 今天最值钱的判断**：**成本与覆盖面严格反向** —— ⑤ 最便宜、范围最窄；③ 最贵、范围最广。**"要不要开"不是 yes/no，而是"你愿意为哪一块面积付钱"。**
  而且 **④⑤ 在已经跑 Sky Light 的场景里边际成本约等于 0** → **这类"几乎免费的正确性"应当默认开启，而不是当成分档项。真正值得当分档项的只有 ③。**
- **第二条判据（与上面并列）**：**"补能量"与"推输运"是两件事。** 前者只补**一个标量**、**不依赖任何物理假设** → 永远"对"，但分布可能是编的；后者**从假设推出分布** → 分布对，但假设错了就全错。**①②是后者，③④⑤是前者。**
- **PBR 收口清单仍为 25 条，不变**。今天的两篇**不计入清单**（它们不是引擎里"必开"的项），但它们是**清单外那条缺口的"真值参照系"与"落地手段"**。
- **🔴 唯一待做的实测题（今天升级为"两项检查"）**：
  1. 纯金属球 + Roughness 0→1 + 只有环境光 → **粗糙端是否整团变暗**；

- **[[Heitz — Multiple-Scattering Microfacet BSDFs with the Smith Model (2016)]] 的 user_level 标为 Hard，但它是"结论可为 Normal"的典型** —— 推导（自由程分布、相位函数、微片辐射度量学）确实是 Hard，**但四条结论不需要任何推导就能拿走**（"被挡住≠被吸收" / 它不可实时 / 成本随粗糙度上升 / 按事件序列分解 lobe）。**本笔记明确分列了这两层，不必为了 Hard 的部分停住。**

## Technology Evolution

```text
微面能量账本的"最后一段"：从真值到落地

2016  Heitz et al.   ① 精确真值（随机游走，能量守恒是副产品）
        ↓            作者自述："unsuitable for real-time"

        ↓            代价：新增 4KB 表；path tracing 语境
2018  Hill           更准（逐次弹射模拟）但每次弹射一张表，且不处理 IBL
2018  Lagarde/Turquin ⑤ 连新项都不加，只缩放已有 lobe（与 DFG 表共享同一个 r）
        ↓
★ 2019  Fdez-Agüera  ④ 缺的信息就在已有的表里 → E_ss = f_a + f_b
        ↓            零新增资源；**且第一次处理了"低粗糙度端超额能量"**
2026  Dupuy          ② 所有散射阶的精确闭式（代价：没有 roughness 参数）
        ↓
```

## Important Relationships

- [[Heitz — Multiple-Scattering Microfacet BSDFs with the Smith Model (2016)]] ⟷ [[2026-09-18-An Elementary Expression for Multiple Scattering in Homogeneous Microflake Media]]：🔴 **同一问题、同一理论通道（微面↔微片）、两种答案** —— Heitz：精确 + 全参数，**无闭式**；Dupuy：精确 + 闭式，**无参数**。**两者相隔十年，都长在"把表面写成体积"这根枝上。**
- [[Fdez-Agüera — A Multiple-Scattering Microfacet Model for Real-Time Image-based Lighting (2019)]] → [[Split-Sum Approximation]]：**不是"引用关系"，是"提取关系"** —— 它**从 split-sum 的产物里取出了第二份信息**（$E_{ss}=f_a+f_b$）。**所以 Split-Sum 从"一个近似"升级为"一个可以重复提取的固定资源"。**
- [[Heitz — Multiple-Scattering Microfacet BSDFs with the Smith Model (2016)]] → [[Kulla-Conty — Revisiting Physically Based Shading at Imageworks (2017)]]：**因果关系明确** —— 前者的"不可实时"是后者存在的理由。
- [[Heitz — Multiple-Scattering Microfacet BSDFs with the Smith Model (2016)]] ⟷ [[Marschner — Light Scattering from Human Hair Fibers (2003)]]：🔴 **跨领域合流（今日新发现）**：**R/T/TRT/TTR（微面输运）⟷ R/TT/TRT（纤维散射）** —— 两个不同物理场景独立收敛到"按事件序列分解 BSDF"。**这条把 [[Hair Rendering]] 的分档判据升级为通用手法。**
- [[Fdez-Agüera — A Multiple-Scattering Microfacet Model for Real-Time Image-based Lighting (2019)]] ⟷ [[Kulla-Conty — Revisiting Physically Based Shading at Imageworks (2017)]]：**同一条思路（补标量）的两种成本** —— 一个新增 4KB 表覆盖任意光源，一个零新增只覆盖 IBL。**这是本库目前最清晰的一张"预算 vs 修正范围"权衡表。**
- [[2026-09-16-Gaussian Process Implicit Surfaces as Participating Media]] → [[Heitz — Multiple-Scattering Microfacet BSDFs with the Smith Model (2016)]]：**同一个等价关系的两侧** —— GPIS 从随机几何**推导** Smith 假设，Heitz **使用**同一等价关系（早十年的版本）。**相隔四天在库里相遇。**

## Emerging Trends

1. **🔴 "精确 / 便宜 / 有参数"三样只能拿两样 —— 这条判据今天得到完整验证。** 五条路线各自交出了不同的一样：Heitz 交参数、Dupuy 交参数、Kulla-Conty 交分布精度换成本、Fdez-Agüera 交覆盖面、Lagarde 交成本。**没有一条全拿。** 这条从 9-19 的"三条路线观察"升级为**贯穿整条技术史的规律**。
2. **🔴 "更准"和"能用"第三次、第四次分家。** 本库已有两台证据（Heitz 2016 更准但不可实时；Karis 2013 明说第一误差源不是 split-sum 而是 $n=v=r$）；今天再添两台：**Hill 2018b 比 Fdez-Agüera 更准，但每次弹射一张表且不管 IBL**；**Heitz 2016 比 Kulla-Conty 更准，但连求值都不行**。**这不是巧合，是渲染领域的结构性事实：评价轴不止"准确度"一条。**
3. **🔴 产业侧的档位结构正在被顶掉（今天最重要的产业判断）。** 《控制：共振》把 PT + GI 做成**所有光追档位的公共底座** → **"档位=降分辨率/降效果"的默认假设失效，档位变成"管线切换"**。同期 TweakTown 的评述把升频定性为"基线优化工具而非可选加成"。**你的五档矩阵需要为此留一列。**
4. **神经层的"预算维度"从两条扩到三条。** 帧时间（DLSS 5 每帧 +15 ms 量级）→ 功耗（+32~131 W、接近 12V-2x6 上限）→ **今天是第三条：整机功耗墙的重新切分**（Auto SR 的 NPU 与 CPU/GPU 共享功耗预算，移动端会升温/掉续航）。**移动端尤其要注意：这条约束可能先于算力约束生效。**
5. **"注入式神经层会破坏玩法"再添一例（且与昨天呼应）**：Auto SR **缩放了 UI 与文字**导致小字发虚，且不支持 DX9/Vulkan/OpenGL 与 HDR —— **"神经层需要一个愿意配合的宿主管线"这条判断，今天在 OS 层与游戏层各有一个实例。**

1. **今天没有前沿论文 —— 这不是缺口，是正确的行为。** 周末 arXiv 无 listing，9-14~9-18 已全清。**按 No-Filler Rule 空转前沿线，把注意力给经典与产业信号。**
2. **今天最重要的产业判断（也是唯一有结构性后果的一条）**：**画质档位正在从"性能阶梯"变成"渲染管线切换"。**《控制：共振》把 PT + GI 做成所有光追档位的公共底座 —— **中间档消失了**。**你的五档矩阵需要为"换管线"而非"换参数"的差异留一列。**
3. **今天最值钱的一句判据（由 9-19 扩展而来）**：**成本与覆盖面严格反向。** 从 ③ 到 ⑤，成本递减、覆盖面递减。**"要不要开能量补偿"不是 yes/no，而是"你愿意为哪一块面积付钱"**；而 **④⑤ 在跑着 Sky Light 的场景里边际成本约等于 0 → 应当默认开启，不该当分档项。**
4. **第二条并列判据**：**"补能量"与"推输运"是两件事。** 前者只补一个标量、不依赖物理假设（永远对，分布可能是编的）；后者从假设推出分布（分布对，假设错了全错）。**看到任何能量方案先分类。**
5. **一条可直接用的实现**：**缺口 = 1 − (EnvBRDF LUT 两通道之和)。** 论文自带 GLSL、零新增资源、不改管线 —— **本库目前"研究 → 引擎"距离最短的一篇**。**顺手的动作是：跑一次 furnace test，看引擎当前开了没有。**
6. **一条跨领域的方法论收获**：**"按散射事件序列分解 BSDF"在微面输运（Heitz 2016 的 TRT/TTR）与纤维散射（Marschner 2003 的 R/TT/TRT）两个场景独立出现。** 所以 [[Hair Rendering]] 的"TRT 先砍、TT 最后砍"**不是毛发专属判据** —— 通用判据是**事件序列的可见性**。
