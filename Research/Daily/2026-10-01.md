## Frontier Research

### [[2026-09-29-Length-varying Neural Motion Stitching via Cluster Transition Graph]]

**Why this matters**：**运动缝合的"长度问题"被图解决了**——两段动作先经 CVQ-VAE 聚成离散动作块（簇），簇构成**转移图**；在图上找**最短路**，路径长度**隐式决定过渡长度**、路径本身当**引导序列**喂 Transformer，并预测第二段的**根目的地**。别人把过渡长度当超参（固定 / 手动 / 显式回归秒数），本文把它当**路径搜索的副产品**。

- **与经典的直接血脉**：最小转移长度 **0.3 秒**，"following Kovar et al. (2002)"——**固定 1/3 秒混合窗（2002）→ 自适应变长转移（2026）**；
- **数据**：推理 **14.5 ms 单次缝合**（寻路 6.3 + 生成 8.2，RTX 3090，1000 条测试输入）——在 60 FPS 帧预算（16.7 ms）之内；LAFAN1 训练，LAFAN1 / 100STYLE / Mixamo 免重训测试；行为样本：脚相位不同 → 64 vs 80 帧（自动补一步）；
- **对库**：[[Motion Matching]] 瓶颈线新材料——"过渡三问"（在哪切 / 切多久 / 怎么接）第一次在库内有可对照的**两代答案**（见 Classical 段）；KAIST VML（Junyong Noh 组）。

### [[2026-09-29-Gaussian Stippling — Efficient Sorting-Free 3D Gaussian Rendering]]

**Why this matters**：**"取消排序"线第 5 个节点**——随机透明不再"单选一条流"：**fragment-based**（成本 ∝ 光栅覆盖）与 **primitive-based**（成本 ∝ 采样数）**按成本结构分拣路由**（判据 = 不透明度 × 投影足迹），噪声用**跨场景时空重建网络**偿还（当前帧 + 前向重投影历史帧 + 高斯感知描述子）。

- **数据**：1080p **2.3–2.7× 标准 3DGS 吞吐**（1-spp 紧凑配置，renderer-only 880 FPS vs 3DGS 122）；16-spp 大幅配置 PSNR **反超**标准 3DGS（29.08 vs 28.90）；**移动端 540p：92.6 FPS 裸渲染 / 73.2 FPS 含 NPU 重建**（FP16 MLP 跑 MediaTek NPU + Vulkan compute 渲染，帧间重叠）；
- **直接吃未修改 3DGS 资产**（零资产改动）；**"1/4/16-spp" 天然三档**——GS 管线里的"档位 = 采样数"现成语言；
- **对库**：[[Gaussian Splatting]] 排序线全景表（① 优化排序 → ② 顺序无关 → ③ 重设计基元 → ④ 随机光栅化全删 → **⑤ 混合路由**）已沉淀进概念笔记；移动端实测数据对 Android 三档稀缺。

### [[2026-09-29-Texture Space Material Diffusion]]

**Why this matters**（NVIDIA，Munkberg / Kocsis / Hasselgren —— nvdiffrec 一作团队）：**把材质生成整个搬进纹理空间（UV 2D 域）做**——微调视频扩散 Transformer，靠"**图像→纹理的投影是已知的**"这一归纳偏置，直接生成 PBR 五通道（basecolor / height / roughness / metalness），并做**材质升分**（UV 图集超分，推理时扩到 **8K + 100+ 视图**）。

- **"换空间"家族第 2 例**（[[2026-09-17-PBR-Latent — Physically Based Rendering in the Latent Space|PBR-Latent]] 把渲染方程写进潜空间；本条把材质生成写进纹理空间）——**一致性由空间保证，而非由学习保证**；
- **三步抽象**：① 已知投影当归纳偏置（确定性变换进结构、不进损失）；② 2D 化换先验复用（降维给视频 DiT 权重迁移开门）；③ 训练规模 ≠ 使用规模（推理时增强扩规模）；
- **成本形态**：离线内容工具——多视图重建 17 视角 @2K 约 **130 s（GB300）**；训练 15k iter / 32×A100。

## Classical Research

### [[Kovar — Motion Graphs (2002)]]

**Historical Role**：**数据驱动动画"图时代"的开山论文**（同年 Lee 2002 / Arikan 2002 三组独立工作之一）。把"再捕捉一批数据"变成"搜索已有数据"——**动作合成的第 0 章**。

- **四步结构**：① 候选过渡点 = 全帧对相似度矩阵（点云窗口 + 闭式刚体对齐，O(F²)）的**局部最小值**；② 阈值过滤（**按动作对分别设**——"走路人人天天见 → 阈值最严；芭蕾少见 → 可松"，**观察频率决定验收严格度的 2002 年表述**）；③ 过渡生成 = 短窗混合（根 lerp + slerp + C¹ 权重）+ 约束/标签传播；④ **SCC 剪枝**（删死胡同与沉没点）；
- **提取框架**：用户提供误差函数 g(w,e) + 停止条件 → **分支定界搜索**"图行走"（源文件：分支定界 + 增量搜索 80–120 帧窗口）；
- **数据**：78.5 s 走路数据 → "Hello"连笔路径 54.9 s 动画 / 58.1 s 计算；空手道 87.7 s / 15.0 s 计算（1.3 GHz Athlon）；6000 帧图 ≈ 候选点 25 min（**离线重活 + 在线轻活**）；
- **与产业**：对照 move trees（Mizuguchi 2001）的三件手工活（手工捕捉 / 手工混合 / 手工图）——**它把三件事全部自动化**；"motion dumping"（AI 定路径 → 动画铺结果）**就是现代 NPC 动画架构的原始表述**；
- **对本库**：动画线**此前零经典**（最老是 2020 的 LMM）——今日补齐"图时代"这一章；与今日前沿构成 **24 年对子**。

### 知识图景：过渡三问的两代答案（今日沉淀）

| 子问题 | Kovar 2002 | NMS 2026 | 变化 |
|---|---|---|---|
| **在哪切** | 相似度局部最小值（帧级，O(F²)） | 簇图最短路（簇级） | 单位从"帧"升为"语义簇" |
| **切多久** | **固定** ≈1/3 s 混合窗 | **路径长度决定**（0.3 s 仅下界） | ★ **默认值 → 估计量** |
| **怎么接** | 线性 / slerp 混合 + 标注修补 | Transformer 生成 + 根目的地预测 | 混合 → 生成；对齐自动化 |

- **⟷ 同日对子（教科书级）**：[[Kovar — Motion Graphs (2002)]]（固定 1/3 s 窗）与 [[2026-09-29-Length-varying Neural Motion Stitching via Cluster Transition Graph]]（变长转移）——**同一问题的两代答案，24 年**；且后者**显式引用前者数值作最小块**（血缘闭合）。

- **⟷ "换空间"家族第 2 例**：[[2026-09-17-PBR-Latent — Physically Based Rendering in the Latent Space|PBR-Latent]]（潜空间）⟷ Texture Space Material Diffusion（纹理空间）——**"把问题搬到性质天然成立的坐标里"**。

## Emerging Trends

- **"成本互补 → 按成本路由"**：当同一问题的两条解法成本函数方向相反（覆盖 ∝ vs 采样 ∝），最优解可能是"**分拣**"而不是"选边"——Gaussian Stippling 给出的新句法；
- **"固定默认值 → 自适应估计"**：过渡长度（今日）、上采样倍率（XeSS 3）、功耗预算（ControlGS）——**"把超参变成结构量"的连环样本**；
- **离线重活 + 在线轻活**的形态在动画侧重现（Kovar 2002 vs NMS 2026 的图都在离线建、在线查）。
