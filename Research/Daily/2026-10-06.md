## Frontier Research

### [[2026-10-03-Neuroll — Real-Time Neural Strand-Based Hair Simulation via Simulator-in-the-Loop Unrolling]]

**Why this matters**：**毛发线的"仿真轴"第一节点**——库内此前毛发全部是渲染侧（1989→2026 五节点），这篇回答另一半："**头发怎么动**"。做法一句话：**神经时间积分器"镜像"经典积分器的输入输出**（前状态 + 刚度 + 边界条件 + 外力 + 碰撞几何 → 下一状态），用**模拟器在环 + 随机视界展开**训练——不生成任何数据集；网络是 1.63 MB 的 MLP，不用 GRU/GNN。数据：3000 股 **0.460 ms/帧**（比经典 Cosserat 模拟器快 **2 个数量级**+，比前作 Quaffure 快 7.7×），**连续动态帧数 2000 打满**（Neuralocks 仅 131 帧就衰减）；免重训扩到 **12 万股**、泛化到未见发型/动作/体型乃至"重力训练、风力推理"。

**Personal Relevance**：
- **"分工判据"第 2 样本（今日主线）**：**替代数值积分、保留经典 I/O 语义与显式物理状态**——"学什么、不学什么"在仿真域的第一个完整答案；
- **"表示即先验"量化样本**：全部输入放**发丝局部坐标系**（strand space）——世界系变体运动比 0.342 vs **0.632**、穿插 11.45% vs **0.001%**（本库该家族最干净对照之一）；
- **对分档**：毛发档位新增两只旋钮=仿真模式（off / 准静态 / 动态，**一个网络三态**）+ 刚度标量（连续可调）——与渲染侧（发片/发丝/光追基元）**正交**；配合巫 3 实测（HairWorks 开关 30 vs 44 fps）"毛发重项"首次有两根可分别调档的轴；
- **与你的 VFX 域**：逐发丝独立 + 密度无关 + 线性扩展 = 与粒子系统同构的成本结构——[[Neural Physics Simulation]] 从"纯概念"变为"有可指向的角色级原型"。

### [[2026-10-03-CurveCodec 2 — Skeleton-agnostic Animation Compression with a Learned Entropy Model]]

**Why this matters**：**库内新域 [[Animation Compression]] 的开线之作**——动画数据的"存与传"第一次进库。**两阶段**：有损阶段（逐关节、闭环、经前向运动学验证地"决定哪些样本不编码"——经典算法）+ 无损阶段（**108 K 因果 Transformer（870 KB）只做熵编码**，整型推理跨平台位精确）。结果：**0.01 cm 最坏情形契约下 0.37× ACL 字节；0.1 cm 平均契约下 0.22×**；解码单核 8,700 fps（55 关节）；~2 bits/关节样本（≈ float32 的 1/100）。

**Personal Relevance**：
- **"分工判据"最干净的反例向样本**：三组测量证明——**"从自身历史预测"最值钱（2.3–3.0×）；"学式补帧"全军覆没（百万样本最近邻 oracle 都不如线性插值）；网络只该接管"残差分布"**。"一个更小的流需要'编码什么'的不同决定，而不是更好的后端"；
- **"误差契约"进入预算语言**：0.01–1 cm **连续误差界 = 档位**；逐片段验证 + **不达标回退 + 回退率计数**——"预算可认证性"的第三种形态（Ward 容限 / Budgeted-GS 对偶证书之外）；
- **直击引擎内存账**：ACL 是行业事实标准（UE 插件生态）——项目页收录 **ACL 作者 Nicholas Frechette 邮件原文**（一手）："update pass 延迟约束 vs evaluate pass 吞吐约束"、"旧 UE5 编解码器压 1–2 分钟过场要 45–90 分钟"、"现代项目 >100k clips"——**编解码器的三本账：内存 / 解码 / 导入**；
- **两个细节值得记住**：① 同一批动作换骨架后压缩率好 **2.2–2.3×**（"关节曲线里有一部分是身体，不是动作"）；② 熵模型泛化到**未见物种**（狗，13.9×）。

## Classical Research

### [[Majercik — Dynamic Diffuse Global Illumination with Ray-Traced Irradiance Fields (2019)]]

**Historical Role**：**把"预烘焙的静态光照探针"改造成"每帧用硬件光追增量更新的辐照度场"——第一个真正可出货的动态漫反射 GI 探针方案**（JCGT 8(2), pp. 1–30）。三件套：① **紧凑编码**（每探针 = 8×8 八面体辐照度 `R11G11B10F` + 16×16 距离/距离² `RG16F`，打包图集）；② **摊销更新**（每帧 m 探针 × n 射线 → surfel 着色 → 按滞后 α∈[0.85, 0.98] 混入；多弹射跨帧累积）；③ **可见性加权查询**（8 探针 cage + 背面软剔除 + 感知抑制 + **Chebyshev 矩可见性** + 法线偏置——五级权重专治探针法的"漏光"老毛病）。1080p 全 GI **6 ms/frame**（2080 Ti），对照离线路径追踪 1 min/frame；间接光组件合计 2.6 ms（Table 2 逐项可查）。

**Knowledge Graph Role**：**[[Global Illumination]] 谱系表第 6 行（缓存族）第四节点 + 第 6/7 行合流点**——与 [[Ward — A Ray Tracing Solution for Diffuse Interreflection (1988)|Ward 1988]]（接收侧答案）/ [[Keller — Instant Radiosity (1997)|IR 1997]]（光路顶点）/ [[Dachsbacher-Stamminger — Reflective Shadow Maps (2005)|RSM 2005]]（光源视野像素）合读 = **缓存族四种记账齐**；**[[Neural Global Illumination]] 桥的经典侧自此完整**（四源 + 三图解：双源 / Ward / DDGI）。

**Related Concept**：[[Global Illumination]] · [[Neural Global Illumination]] · [[Real-Time Global Illumination]]（Technology）· [[Shadow Mapping]]（Chebyshev 矩与 VSM 同源）

**四条可直接拿走的结论**：
1. **"探针数量比探针分辨率更重要"**——调参次序的实证（先加数量、再加精度）；档位旋钮 = 探针数 × 分辨率 × **更新率**；
2. **"收敛可以从空间维度挪到时间维度"**——滞后摊销 = 预算的第二根轴；"固定样本预算"家族补 2019 节点（**每帧 m×n 射线**：1978 每灯 → 1997 每 VPL → 2005 每像素 ~400 → **2019 每帧 m×n** → 2026 MegaLights 每像素预算）；
3. **方法论原句**："**把光追当作光栅化的补充，而不是替代**"——混合渲染的分工范式（今日主线第 1 样本）；
4. **产品线**：RTXGI SDK 产品化——2020 《逆水寒》（首个游戏实装）→ ICARUS（无限滚动）→ THE FINALS → 2026 ARC Raiders（"以 RTXGI 替代 Lumen"样本，二手待核）；**SDK v2.0（2024）把 NRC/SHaRC 与经典探针并入同一产品**——"经典与神经并置"的活样本。
