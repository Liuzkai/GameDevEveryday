Hammon 2017 — 漫反射能量账本与那个「4」

PBR Diffuse Lighting for GGX+Smith Microsurfaces · GDC 2017 · Respawn（Titanfall 2 生产研究）· 193 页幻灯片 · 2026-10-05 入库（原文阻塞 16 天后解除）

一句话：与 GGX+Smith 镜面同源地重做漫反射 —— 数值求解发现单次散射最多丢一半光； 顺手给出两个著名问题的答案：「PBR specular 的 4 从哪来」与「理想 Lambert 少了 5%」。

一、那个「4」从哪来 —— 一次测度变换

PBR 镜面公式 $F D G \,/\, 4(N\cdot L)(N\cdot V)$ 的分母里有个 4，很多人以为它来自"除以 π 之类的归一化"。真相是：它是从立体角测度变换里掉出来的雅可比系数。

1归一化约束：∫ ρ·cosθ_V dV = 1 —— 但 δ 函数只在 m = H 处非零，必须把积分换到 dm 域才有意义
▼ 需要 dV/dm
2把 dV 移到 (L+V) 方向球上：dV = (H·V / |L+V|²) · dm
▼ 代入几何关系
3L+V = 2(H·V)（半程向量定义）→ |L+V|² = 4(H·V)² ⇒ dV/dm = 4(H·V)
▼ 回代
4k · (H·V) · 4(H·V) = 1 ⇒ k = 1/(4 H·L H·V) —— "This 2 squared is specular BRDF's 4!"

一句话4 = 2²，来自 |L+V| = 2(H·V) 的平方。它回答的其实是一个"为什么不是 π"的疑问——它根本不是面积归一化因子，而是坐标变换的代价。

二、漫反射丢了多少 —— 单次散射最多丢一半

把漫反射写成微面上的 λ=1/π 反弹、路径追踪微面间的多次弹射（同 Oren-Nayar 方法但换到 Smith+GGX 假设下），得到的分账：

Direct only

只算直接光 + 单次散射 → 高粗糙度、掠射角处明显发暗。这就是旧模型的真相：丢光。

Direct + indirect

加入微面间多次弹射 → 亮回来了。原文结论句："Up to half the light was missing!"

Indirect only

把多次弹射单独看 → 它自己就是一笔可观的能量账（尤其是粗糙端）。

与镜面侧的平行镜面侧的故事是「被挡住 ≠ 被吸收」；漫反射侧的版本是「光进表面不是终点，还会带着 Fresnel 弹回来」——单次散射把它当成了终结。

三、新 G2 近似 —— 和 UE 里那个 k=α/2 同源

精确 Smith G1（GGX）

G1 = 2N·V / ( α² + (1−α²)(N·V)² + N·V )

分母里 N·V 的平方项是精确的，但每帧要开方级别的运算。

lerp 放松 → 与 UE 相同的形状

G1 ≈ 2N·V / ( N·V(2−α) + α ) = 2N·V / lerp(N·V, 1, α) + N·V 的变形

把 (N·V)² 放松为 lerp(N·V, 1, α) —— "Turns out, identical to Unreal's Smith"（k=α/2）。UE 里那个经验常数其实可以从 Smith 推导出来。

height-correlated 的新 G2（工程选型）

G2(L,V) = 2(N·L)(N·V) / lerp( 2(N·L)(N·V), (N·L)+(N·V), α ) 组合进完整 specular BRDF 时分子抵消： BRDF = F·D / [ 2 · lerp(2·N·L·N·V, N·L+N·V, α) ]
形式成本质量
G1(L)·G1(V)（uncorrelated）~4 cycles掠射 + 高粗糙度端偏暗
新 G2 近似（correlated）~6 cycles粗糙电介质掠射端显著改善；"只有可忽略的额外成本"

附赠 shader 恒等式：不构造 H 直接求 N·H、L·H —— 19 cycles → 7 cycles（省 7-10 cycles / light）。

四、Lambert 的账：为什么加上 Fresnel 后是 1.05/π

1余弦衰减的真相：不是"能量随角度变少"，而是几何——内部光束各向同性，表面按 cosθ 切割光束、按 1/cosθ 缩放面积
▼ 对称性要求
2出射也要有 Fresnel：1−F = (1−F0)(1−(1−N·V)⁵) —— 光路可逆，进和出必须同等对待
▼ 内部反射光会被弹回表面、再次获得逃逸机会
3归一化：2πk·∫(1−(1−cosθ)⁵)·cosθ·sinθ dθ = 1 ⇒ k = 21/20π = 1.05/π —— 理想漫反射比 Lambert 大 5%

五、最终模型（全部闭式）

facing = 0.5 + 0.5·(L·V) rough = facing^(0.9 − 0.4·facing) · (0.5 + N·H) / (N·H) smooth = 1.05 · (1−(1−N·L)⁵) · (1−(1−N·V)⁵) single = (1/π) · lerp(smooth, rough, α) ← α=0 时退化为 5% 修正 Lambert multi = 0.1159 · α ← 多次弹射能量补偿（一行线性项） diffuse = albedo·single + albedo·multi

两个零售版本：hybrid（smooth 换 Disney fd90）· cheaper（smooth 换 Lambert）。数值求解先行、拟合在后 —— "tried tons of random equations until ones that I liked"。
