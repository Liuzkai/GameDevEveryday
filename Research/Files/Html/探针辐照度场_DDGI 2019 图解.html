辐照度场：DDGI 2019 —— 缓存族在光追时代的合流点

Majercik / Guertin / Nowrouzezahrai / McGuire · JCGT 8(2), pp. 1–30, 2019 · 图解与核对：2026-10-06

一句话：把"预烘焙的静态光照探针"改造成每帧用硬件光追增量更新的辐照度场——第一个真正可出货的动态漫反射 GI 探针方案。三件套 = 紧凑编码 + 摊销更新（滞后混合）+ 可见性加权查询（专治漏光）。

谱系位置：缓存族（Ward 1988 接收侧 / IR 1997 · RSM 2005 光侧）的第四节点，也是"缓存族 × 硬件光追"的合流点——NRC（2021）要替换的"缓存介质"，在产品线上正从这里开始。

12019 年的三角困境（为什么需要它）

探针法

IBL 探针在游戏里无处不在，但三个老毛病从未同时解决：手动放置 + 代理几何（反射错位）、漏光/暗漏、静态（只在初始化烘一次）。

屏幕空间

SSGI / SSR：便宜的代价是屏幕外几何一律丢失，且视角相关 → 时间不稳定。

体素 / 光追

VXGI 类：几何表示（八叉树）与参数化耦合，泄漏难治；离线路径追踪质量最好，但离实时差 3–4 个数量级。

目标

动态物体 + 动态光照下的实时漫反射 GI，无需手动放置，对几何与辐射复杂度都鲁棒。

2编码：一个探针 = 两张八面体小图

数据格式分辨率（八面体）用途
球面辐照度GL_R11G11B10F8 × 8漫反射间接光查询
平均距离 + 距离平方GL_RG16F16 × 16可见性（Chebyshev 矩）

所有探针打包进一张 2D 图集：gutter 边保证双线性插值不出缝，探针按 4×4 写边界对齐。深度值经 cosine-power 加权后锐化；低于阈值（0.001）的 texel 不更新。

格式结论（原文 Figure 12）：R11G11B10F = 16 位浮点保真度、省 45% 存储；8 位整型出伪影；深度从"前作 128×128×6 高精度 cube map"降到 16×16——省下来的底气来自查询侧的加权方案。

3更新：每帧一轮"探针-射线批"，滞后混入

低频、视图无关的量——贵的东西用便宜的时间常数摊销（"时间是第二根预算轴"）

4查询：8 探针 cage + 五级权重（治漏光的核心）

对每个着色点，取包围它的 8 个探针（cage），按序加权：

#权重治什么
1软背面剔除（法线 · 指向探针方向 平滑淡出）截断下方探针的贡献
2感知抑制（暗区极低辐照度 < 5% 强度按单调曲线压低）人对暗区漏光最敏感（HVS 依据）
3Chebyshev 矩可见性（平均距离 + 距离平方 → 上界）把"探针看不到的着色点"权重压下去（VSM 同源）
4法线偏置（按法线与探针方向偏移）避开阴影/非阴影边界的权重失真
5三线性插值（着色点 ↔ 探针中心距离）平滑空间过渡

成立前提（原文写出）："着色点处的入射光 ≈ 包围它的探针处的入射光——当且仅当二者互相可见"。探针越稀，假设误差越大（漏光来源）；消融链（Fig 7）：传统探针 → +背面剔除 → +可见性 → +法线偏置 → 逼近路径追踪。

6谱系带：缓存族 → 合流 → 产品线

1988 Ward 接收侧缓存→ 1997 IR（VPL）→ 2005 RSM（每像素固定样本）→ 2019 DDGI：增量更新 + 滞后 + 矩可见性→ 2020 RTXGI v1 · 《逆水寒》首发→ 2021 Scaling for Production · DDGI Resampling→ 2024 RTXGI v2 并入 NRC / SHaRC→ 2026 ARC Raiders 等采用（二手）

"固定样本预算"家族在此多出一个节点：每帧 m 探针 × n 射线（1978 每灯 +1× → 1997 每 VPL 一遍 → 2005 每像素 ~400 → 2019 每帧 m×n 射线 → 2026 MegaLights 每像素采样预算）。

7对分档工作的三条借条

① 调参次序

"数量 > 分辨率"——预算先加在"探针数（网格密度）"上，再加"每探针精度"上。

② 第二根预算轴

"收敛可以从空间维度挪到时间维度"——每帧射线数不足时，用滞后（时间滤波）跨帧摊销。

③ 互补而非替代

原文方法论："光追是光栅化的补充，不是替代"——只在非相干可见性查询上动用 RT 核。

档位旋钮

DDGI 的档位 = 探针数 × 分辨率 × 更新率——"档位 = 多个正交子系统的组合"的 GI 域实证。
