双散射 — 全局 · 局部 · 一条原型路径

Dual Scattering Approximation for Fast Multiple Scattering in Hair · Zinke / Yuksel / Weber / Keyser · ACM SIGGRAPH 2008 · TOG 27(3)

它要解决的问题：浅色头发必须算多次纤维散射（光穿透深、多散射主导发色），但 2008 年时： 路径追踪单帧 7.8–22 小时；光子映射数十分钟且吃内存；实时做法把多散射当成"半透明阴影 + 手工 diffuse"， 复现不了方向性 / 色彩偏移 / 连续模糊三种现象，还要反复调参。

它给出的答案：把多次散射拆成两半——

Ψ(x,ωd,ωi) = ΨG(x,ωd,ωi) · (1 + ΨL(x,ωd,ωi))

  • ΨG 全局：光穿过发束体积、到达 x 邻域——近似为"沿单条阴影路径的事件序列统计"， 实现上"非常类似标准半透明毛发阴影技术"；
  • ΨL 局部：到达邻域之后的多次回散射——建模为不含位置的材质属性 fback，查预计算表。
一句话：全局管"光怎么走到这里"（输运），局部管"到了之后怎么散开"（响应）—— 两半分别用各自最便宜的技术（阴影式管线 / 材质式查表）。

1核心图：一条阴影路径代表全部路径

沿一条原型路径统计"每个散射事件的衰减与扩散"两个标量——路径的几何细节被统计量吸收
为什么一条路径能代表全部路径？两条原文假设：① 散射事件统计独立——光到达某点的能量 "不依赖实际路径，而依赖路径上散射事件的质量"；② 相邻发丝方向强相似（真实发型的最强统计特征）。

2前向 / 后向散射：两类光路，两种技术

散射类型物理成分划给哪个分量工程形态
前向（前半锥） ≈ TT（透射两次），浅色发下显著更强 全局 ΨG：忽略双后向及以上路径，只保留前向散射 "加强版半透明阴影"：光视角分层图，每层存 7 值（RGB·Tf + RGB·σ̄²f + direct fraction）
后向 R / TRT 类回散射；概率低（ā b 小）→ 只计 1 次与 3 次 局部 ΨL：fback(ωi,ωo)，不含 x "材质属性"：预计算表 Āb(θ)、Δ̄b(θ)、σ̄²b(θ) 查值

局部回散射的级数闭式（1 次与 3 次后向）：Ā1 = āb · ā²f / (1 − ā²f)、 Ā3 = ā³b · ā²f / (1 − ā²f)³——等比级数求和直接闭式化，"更多次"物理上可忽略。
