计算条件：各向同性 GGX、height-correlated Smith、Schlick Fresnel、α = Roughness²、均匀单位环境光；LUT 由数值积分预计算。数值是论文公式的教学近似，不是 UE 实机输出或论文测速。F₀≠1 时能量可被吸收，结果不应强行等于 1。

关键区分： E_ss(μ,r) 是单次散射 BRDF 在白色半球环境中的积分。1 − E_ss 在 F=1 时正好对应遗漏的多次散射能量；但补多少能量并不能唯一决定补偿项朝哪些方向反射。这正是各方案真正分叉的地方。

02 / SELECTED METHOD · 2017

Kulla–Conty / Additive BRDF

在不改变原单次 GGX BRDF 的前提下，额外构造具有方向性、互易性的能量补偿项。沿用 Kelemen & Szirmay-Kalos 2001 的补偿思想，通过方向反照率 E 和半球平均值 E_avg 近似多次散射的方向分布；不需要模拟实际反弹轨迹。

f_total = f_ss + f_ms f_ms ∝ (1−E(μi))(1−E(μo)) / [π(1−E_avg)]
完整 roughness 范围近似角分布互易性

UE 4.26 / 4.27：单次散射 + Split-Sum 基线

LEGACY DEFAULT LIT · CONCEPTUAL

// 直接光：Cook–Torrance GGX + Smith Specular = SpecularGGX(D, G, F); // IBL：预过滤环境 + BRDF LUT SpecIBL = PrefilteredEnv * (F0 * A + B); // A/B ≠ 自动包含完整微面多次反弹

传统 Split-Sum BRDF LUT 预计算的是单次散射积分。它减少实时计算开销，但不能仅因为查了 LUT，就认为微表面多次散射已经补齐。

验证方式：针对实际 UE4 分支检查 BRDF.ush、ShadingModels.ush 以及项目修改项。

UE 5.x：镜面补偿与漫反射能量分配

MODERN SHADING PATHS · VERSION / MATERIAL DEPENDENT

// 示例函数名；以实际分支为准 terms = ComputeGGXSpecEnergyTerms(...); Specular *= ComputeEnergyConservation(terms); Diffuse *= ComputeEnergyPreservation(terms); // Conservation: 补偿镜面多次散射 // Preservation: 控制 diffuse / specular 分配

在对应实现中，镜面多次散射补偿体现为对原镜面贡献的调整，形态上更接近 Turquin 式缩放；这不等于 UE 完整照搬某篇论文的全部公式。Substrate、Legacy、Path Tracer 的路径不能混为一谈。

可检查：ShadingEnergyConservation.ush；r.Shading.EnergyConservation、r.Shading.EnergyPreservation。开关存在与默认值需按具体版本确认。

重要边界： 这里讨论的是材质内部微表面尺度的多次散射补偿；Lumen/Path Tracer 对场景中不同物体之间的多次光照反弹属于另一层问题。并且“能量保持”不意味着所有金属都应反射 100% 的白色入射能量：Fresnel 与吸收仍然决定实际亮度。
