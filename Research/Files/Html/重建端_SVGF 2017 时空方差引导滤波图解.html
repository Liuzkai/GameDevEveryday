谱系（1990 → 2026）：
  1990s 非线性滤波萌芽 → 1998 双边 → 2004 交叉双边（"边缘停止"语言）
  → 2010 Dammertz à-trous（结构前身）→ 2014 TAA 普及
  → ★ 2017 SVGF（1 spp + 时域 + 方差引导 → 10 ms 实时）
  → 2018+ A-SVGF 等 → NVIDIA 实时降噪器产品线
  → 2020s 神经重建接管（DLSS RR 等）——库内 GS 续线：SteadySplats / Stochastic GS Denoising / Tabula Rasa
  ——骨架不变：时域 + 可信度 + 边缘感知
对分档的直接映射：历史不足 → 空间回退——"高质量来源不可用时退回廉价来源、恢复后再切回"，实时系统的标准降级形态。
