潜空间渲染（Latent Rendering）—— 管线 · 三项修改 · 成本账本

Radovanovic · Gupta · Gruson · Hua — Pacific Graphics 2026 Journal Track（Computer Graphics Forum）· arXiv 2609.21054 · 入库 2026-09-21（同日补录）

核心思想：把渲染方程改写成能在 VAE 潜空间里求解的形式，让路径追踪直接输出 latent 图（而非 RGB），再经"精化网络 + 解码器"还原画面。 关键在于：潜空间与光传输之间确有桥（结构 / 反射 / 角度依赖被保留），但也有三处不守物理（带符号发光 / 平响应 / 遮挡增亮）—— 这三处必须被显式建模成方程项，而不是交给网络隐式吸收。

① 管线对照：把物理渲染器接在潜空间上

传统路线（baseline）—— 想拿 latent，必须"渲染 RGB + 再编码"

场景 + 材质→ 路径追踪渲染方程（Kajiya 1986）→ RGB 图→ VAE 编码器每换一次场景参数就要再编码一遍→ latent

本文路线（latent rendering）—— 编码器整段删除，渲染器直接说"潜空间的语言"

场景 + 材质→ 修改的渲染方程带符号辐射 + 平响应项 + 遮挡项（Mitsuba + PRB 可微优化）→ latent 图128×128×16→ 精化网络只预测残差（边界 / 高频）→ VAE 解码器评估一次 = 主导成本→ RGB 图 解码器成为新瓶颈

训练对象：单张渲染图（每场景）；场景参数 3000 迭代 + 精化网络 3000 迭代；Cornell Box 在 RTX 4090 上各约 5 分钟。

② 潜空间里的"三个不守物理" → 方程的三项修改

观察（§4，SD 3.5 的 VAE 上）对渲染方程的修改（§5.1）要点
发光是带符号的
物理渲染假设辐射度非负；latent 的发光值可正可负		 Ĩᵉ 带符号辐射与反射
（式 4：带符号光传输方程）		 允许发射器发出带符号辐射 L̃e；BSDF 求值允许带符号；纯镜面材质不改
部分通道"平"
不同表面不忠实反映材质差异，塌缩成近似常数		 Ĩᵃ 平响应项
（式 5）		 显式控制"保留材质差异 ↔ 塌缩为常数"的比例
遮挡区可增亮 / 变号
物理上遮挡只会减少能量；latent 里遮挡区甚至比未遮挡区更"亮"		 Ĩᶜ 遮挡项
（式 6）		 只在着色区域额外贡献：相机子路径末端 + 光源可见性函数 V
合成 —— 潜空间渲染方程（式 7）： Ĩ = Ĩᵉ + Ĩᵃ + Ĩᶜ  ·  保号 gamma 校正（式 8）：g(x,γ) = max(x,0)^γ − max(−x,0)^γ，γ = 2.2

有效性（Table 1 消融 · Cornell Box · 相机变化，LPIPS）： 仅带符号发射器 0.502（差且不稳）→ +平响应 0.228 → +遮挡项 0.213 → +精化网络 0.075。  结论："非物理偏离"不是噪声、是必须显式建模的一等结构；且渲染 latent 质量差时，精化网络救不回来。

③ 成本账本：计算搬家，不消灭成本

本库定位："分层收敛"模式目前走得最深的样本 —— 物理渲染器做决定性骨架（"most of the work is done by the rendered latents"），网络只补残差；两层交换的界面第一次从"像素"压到了"表示"。  ·  一句话：要让物理在别的表示里成立，必须先显式建模那个表示"不像物理"的部分。
