细分曲面 — 求值（Stam 1998）与生产化（DeRose 1998）

Stam《Exact Evaluation of Catmull-Clark Subdivision Surfaces at Arbitrary Parameter Values》（SIGGRAPH'98, pp.395–404）
+ DeRose / Kass / Truong《Subdivision Surfaces in Character Animation》（SIGGRAPH'98, pp.85–94）· 同届双节点：算得出来 × 用得起来

1核心反转：递归逼近 → 特征基直接求值

旧路径（1978–1997 的唯一选择）：递归细分

给定 (u,v) 想知道曲面点？只能把网格多细分几次，逼近极限面。

新路径（1998 Stam）：展开成矩阵幂 → 特征分解

细分是线性变换 → 一切指数化 → 曲面 = 特征基函数之和。给定 (u,v) 一次算对。

k = Ak·v0 = V·Λk·V-1·v0 p(u,v) = Σ λin·φi(u,v)·ci n = ⌊min(−log₂u, −log₂v)⌋ —— 层级由 (u,v) 直接算出，不细分
论点反转（原文）："我们推翻了一个在图形学界广泛流传的信念——Catmull-Clark 曲面无法在任意参数值处直接求值。" 求值成本 ≈ 双三次样条（多一个 log₂ 和一次整数幂）。—— "我们把一个理论工具升级成了非常实用的工具。"

2Stam 求值三步（实现 = 一张表 + 两个函数）

单位参数域被分成无穷层瓷砖：每层 3 个规则象限（直接是 B-spline 片）+ 1 个更小的中心；层号由 (u,v) 直接算。

三个值得记住的结构事实

  • 7 个共享函数：任意价的特征基里最后 7 个恒相同——正是"外层 7 个控制点"的 B-spline 张量基（外圈影响与价无关）；
  • n=4 时特征基 = 幂基（power basis）——本文明首次指出；奇异点的特征基 = "幂基的推广"（分片双三次，一般不是多项式）；
  • 预计算资产：每个价（到 NMAX=500）一张 EIGENSTRUCT 表——特征结构只算一次，运行时只查用。
读法（≈25 分钟）：摘要 → §1 → §4 结论段 → §5 代码（ProjectPoints + EvalSurf）→ §6 曲率图与"奇异点曲率无穷大"。

3DeRose 1998：半锐折痕（把"锐度"做成连续谱）

同一个立方体棱边的五种锐度（Figure 7 的二维读法）：0 全光滑 → 1/2/3 逐步收紧 → ∞ 完整直角。

机制：混合细分（hybrid subdivision）

不推导"权重随锐度变化的规则"，而是：前 s 步用"无限锐规则"，之后切换光滑规则——"光滑性只取决于第二套规则"；锐度随细分"消化一层"（子边 s−1）。非整数锐度 = 上下整数版本线性混合。非整数且沿折痕变化 → 附录 B（Chaikin 式 3:1 传播）。

为什么不做参数化规则：折痕破坏"循环重索引对称性"（DFT 类证明失效）+ 规则会爆炸成"动物园"。先锐后滑 = 把连续谱缩回两个已解决问题。

产品性关键句：半锐折痕的法线跨折痕平滑变化——沿法线置换（displacement）时，无限锐会撕裂，半锐不会。"数学正确"与"生产可用"的距离，常常就在这样一个具体下游操作里。

另外两件套（同一篇论文）

障碍方案一句话
布料物理能量泛函三件套：抗拉伸（边弹簧）/ 抗剪切（对角弹簧能量之积）/ 抗弯曲（虚拟线角度项）织物经纬 ↔ 网格边方向——域对齐；虚拟线过奇异点"顺时针偏移 ⌊n/2⌋ 条边"
碰撞检测粗化层级："反着建树"（合并面 → superface → 单一根）没有全局 (s,t) 平面 → 向"粗"建无限细分的逆层级（逆操作给出结构）
纹理/着色标量场 = (x,y,z,s,t) 五维一起细分（附录 C 证明）纹理坐标与几何同规则细分 → 光滑；现代形态 = OpenSubdiv 的 face-varying 通道
