细分曲面 — 1978 正问题 与 2026 逆问题

Catmull-Clark《Recursively generated B-spline surfaces on arbitrary topological meshes》（CAD 10(6), 1978）
与 SubDGuide《A Modeler-Inspired Agentic Workflow for Mesh-to-SubD Reconstruction》（2026）· 一条隔了 48 年的"反向弧线"。

1正问题（1978）：cage → 曲面 — 三条规则

一次细分的三件套：每个面收缩出一个面点、每条边收缩出一个边点、每个旧顶点被邻居拉向新位置——全部是局部平均。

三条规则（任意拓扑）

A 面点 = 该面全部旧顶点的平均
B 边点 = 旧边中点 与 相邻两面点平均 的平均
C 顶点 = Q/n + 2R/n + S·(n−3)/n
Q = 相邻面点平均 · R = 相邻边中点平均 · S = 旧顶点 · n = 价

四个结构性质

① 一次细分后全部面变四边形
② 新顶点价恒为 4 → 奇异点数冻结
③ 规则点附近 = 标准 B-spline 片（切/曲率连续）
④ 奇异点：G¹ 为经验观察——1978 年无解析证明

规则是怎么定下来的？（原文原话） 顶点规则最初试的是 Q/4 + R/2 + S/4（"alternate"），但四面体案例"too pointy（太尖）"——于是重新找，换了 Q/n + 2R/n + S·(n−3)/n。作者自己写道："更好的规则集、甚至比'图像定性外观'更好的评判标准，都有待发明。" —— 先审美选规则，数学论证跟在后面。

2逆问题（2026）：稠密网格 → cage — 两权分离

SubDGuide 的工作流

Stage A（规划）：读多视角几何证据 → 紧凑计划（cage 分辨率 / 特征映射 / 大体拟合）
Stage B（闭环）：检查表面 → 请求定向诊断 → 修复 / 回滚 / 停止
——"planner 只做决策，永不生成顶点/连接；几何工具执行并验证每一次改动。"

为什么不让 AI 直接生成几何？ 原文："把视觉判断与数值构建纠缠在一起，就没给验证留空间。" —— 判断归 planner、构建归工具、验证进结构（提案不通过就保留上一个 checkpoint）。
"有 cage 就能有曲面" ⇄ "有曲面怎么找回 cage"——
逆向之所以在今天成立，正因为 cage 的语义经受住了半个世纪检验。

348 年弧线：从渲染动机到找回设计结构

1974双源头：Catmull 博士论文（递归细分为渲染）+ Chaikin 切角法（曲线灵感）
1978 ★Catmull-Clark：任意拓扑规则（"Catmull 发明但无法证明、Clark 实现并泛化"）· 同刊下一篇 = Doo-Sabin 奇异点分析；"extraordinary points" 命名由 Coons 建议
1987 / 1998Loop（三角细分）· Stam 精确求值（不递归直接算极限点）· DeRose 角色动画（《Geri's Game》+ 半锐折痕）
2005Catmull / DeRose / Stam 获奥斯卡技术成就奖
2010sOpenSubdiv（Pixar 开源）→ 全部 DCC / 引擎 / 汽车型面设计的标准表示
2026 ★SubDGuide：反方向——从稠密网格恢复 cage（"planner 判断 / 工具执行 / 验证回滚"）
论文自认的三个开放问题（1978）：① 奇异点连续性无解析证明（三处自我标注）；② 高价奇异点行为不佳（Sabin 建议的鞍面 z=xy 实验，8 价中心"not well behaved"——作者原话"还没找到最好的规则集"）；③ 结尾呼吁："任意拓扑网格上的近似格式需要统一的数学处理"——细分曲面整个理论领域的第一声。
