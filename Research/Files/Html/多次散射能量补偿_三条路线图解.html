多次散射与能量补偿

为什么微面 BRDF 天生少收一笔能量，以及三条把它补回来的路 · 2026-09-19 建立

一句话：微面 BRDF 的 D·G·F 只算一次弹射。"被挡住"在单次散射里被当成"被吸收"处理 —— 但在真实微结构里，被挡住的光会弹到旁边的微面，最终仍有机会离开表面。这笔丢失的能量随粗糙度上升、在掠射角最严重。

1 · 先能量化：方向 albedo 与 Furnace Test

把 BRDF 按余弦加权在整个入射半球积分，得到 方向 albedo：

E(μo) = ∫₀²π ∫₀¹ f(μo; μi, φ) · μi dμi dφ    理想值（纯反射表面）= 1

Furnace Test（炉膛测试）：把表面放进一个完全均匀的辐射场。纯反射表面应当完全消失，与背景不可分。E < 1 时它会显出一团灰影 —— 这就是"能量丢了"的肉眼可见形态。

2 · 三条补法，各自缺一角

目前没有任何一条路线同时拿到"精确 + 便宜 + 有参数"三样东西。这是一个被三篇论文从三个方向逼近、但都还差一角的三角形。

① 随机真值 Heitz 2016

  • 精确 有参数
  • 求值也需要随机数
  • 原文定性："found ground truth but only as a stochastic model"
  • 被弃用理由（Kulla-Conty 原话）："Poor fit for our rendering architecture"

② 账平近似 Kelemen 2001 → Kulla-Conty 2017

  • 便宜 有参数
  • 分布是近似（只补方向 albedo 这一个标量）
  • 额外假设：多次散射是漫射的
  • 成本：32×32 表 ≈ 4KB（float）+ 32 项 1D 表

③ 精确闭式 Dupuy 2026

  • 精确 便宜
  • 没有 roughness 参数
  • 额外假设：Smith 独立性 + 一个特制 NDF
  • 作者自述："it lacks the typical roughness parameters"

3 · 账平近似为什么成立（5 行数学）

Kulla-Conty 补的那一项叫 f_ms：

f_ms(μo; μi) = (1 − E(μo)) (1 − E(μi)) / [ π (1 − E_avg) ]   ，  E_avg = 2 ∫₀¹ E(μ) μ dμ

算它的方向 albedo，会看到中间那个积分按定义就等于 E_avg，与分母相消：

  1. E_ms(μo) = 2π ∫₀¹ [(1−E(μo))(1−E(μi)) / (π(1−E_avg))] μi dμi
  2. 　　　　 = [(1−E(μo)) / (1−E_avg)] · 2∫₀¹ (1−E(μi)) μi dμi　← 与被积函数共享因子，可提出
  3. 　　　　 = [(1−E(μo)) / (1−E_avg)] · (1 − E_avg)　← 按定义
  4. 　　　　 = 1 − E(μo)　← 恰好等于原 BRDF 缺的那一份
作者自己强调的两点（speaker notes 原文）：
① 这个公式在 Kelemen 论文里只给结论、不给证明（"stated without proof"）；
② "I haven't made any particular assumption about the BRDF. This method always works." —— 它对任何 BRDF 都成立。推论：它同样可用于你没有闭式的 lobe。

4 · 精确闭式长什么样

Dupuy 2026 在一条特制的一维单侧二次 NDF 上，把所有散射阶求和后得到一个初等形式：

f_r(ωi, ωo) = (z_i + z_o) / [ π (1 + ωi · ωo) ]   ，  z = cosθ = n · ω

这条公式的两个极限值，正好解释了它为什么"看起来像漫反射、但又不完全是"：

情形代入结果外观
法向入射z_i = z_o = 1，ωi·ωo = 12 / (π·2) = 1/π完全等于 Lambertian
掠射入射z_i → 0分母 (1+ωi·ωo) 只有在 ωo 接近镜面方向时才小能量向镜面方向收拢

注意这一条与 9-18 的对照：Karis 2013 在 IBL 里为了能提出 F₀ 而用的 n = v = r 假设，效果是把掠射反射抹平。Dupuy 的新解在掠射端反而向镜面收拢 —— 方向恰好相反。同一处物理，两种处理。

5 · 现在就能做的一件事

步骤做法看什么
1. 造一个纯反射球Metal = 1，无贴图，BaseColor 白—
2. 只留环境光关掉所有方向光 / 阴影 / 后处理曝光自适应球应当几乎看不见
3. Roughness 扫 0 → 1截图每个档位粗糙端是否整团变暗
4. 切换引擎侧的多次散射补偿开 / 关 各一遍差异就是这篇论文在处理的东西
做完这一步，本概念可从 Normal 升 Easy。理由：它把"能量守恒"从公式问题变成了一个你亲手看见过的现象，而且顺带验证了引擎侧的默认行为。这也是整个 PBR 自测清单里唯一的引擎侧实测题。

6 · 带走的两条判据

判据 A（审近似）：看到一个"补能量 / 预计算 / 闭式化"方案，先问 —— 为了让结果可预存或可求值，它额外假设了什么？这个假设在哪个角度或参数区间会肉眼可见？

· Kulla-Conty：假设多次散射是漫射的 → 高粗糙度掠射端可能偏平  · Dupuy：固定 NDF → 完全没有粗糙度自由度  · Karis 2013：n=v=r → 掠射反射被抹平（作者自认第一误差源）

判据 B（审"更真"）："物理更真实"和"工程更可用"是两条独立的评价轴。

最干净的证据就在这四篇里：Heitz 2016 被 Kulla-Conty 弃用的理由不是"不够准"，而是准了但求值要随机数，不适配光栅管线。
